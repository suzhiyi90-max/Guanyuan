## 一、结论先行

### 1.1 三个必须分开的判断

| 判断 | 问题 | 例子 |
|---|---|---|
| **能不能** | 有足够的人、物、武力或程序去执行吗？ | 有衙役、有牌票，能去拿人 |
| **可不可** | 这个身份、这个场合、这道程序允许吗？ | 知县可自理笞杖，徒以上须通详 |
| **该不该** | 做了之后，名分、舆论、上官与责任会如何反应？ | 无案由收押会留下滥权痕迹 |

**三者不能合并成一个“权力值”。**

- 能而不可：可以强行做，但属于越权；
- 可而不能：有名义，没有执行资源，需要请人、借势、筹钱；
- 可而该不该：合法，但政治代价高；
- 不能、不可、也不该：普通民人闯内堂，被门吏挡住。

### 1.2 权力的最小公式

```text
权力效果
= 身份权利束
× 当前授权（印信/牌票/口谕/委任）
× 场景承认（谁在场、公开还是私密、是否上司在场）
× 资源与关系杠杆
× 对象的服从/抵抗
− 程序缺口与留痕代价
```

这不是一个显示给玩家的数值公式，而是规则层判断“为什么这件事能办成/办不成”的分解方式。

### 1.3 阶级感的来源

不是“官大一级压死人”的单一等级条，而是：

1. **谁可以进入**；
2. **谁可以先开口**；
3. **谁可以坐着**；
4. **谁可以让文书生效**；
5. **谁可以让别人承担代价**；
6. **谁会被记下来**。

## 二、历史锚点：哪些是制度，哪些是游戏化

### 2.1 州县官的司法边界

清代州县是第一审级。户婚、田土、钱债及笞杖轻罪，通常可由州县自理；徒以上案件须逐级审转，经府、道、臬司，直至督抚或中央。不同材料对具体审级和程序有细节差异，但“**轻罪自理、重罪通详**”是设计可用的硬边界。

设计含义：

- 知县可以当场处理笞杖、治安、词讼等轻罪；
- 涉及徒以上、命盗重案，不能一拍了事，必须进入详文、会勘、审转与上报；
- “用刑”不是无限权力：笞杖与非法非刑之间有边界，越界会留下伤单、口供、见证与参劾风险。

> 史源：S1、S7、S8。置信度 A/B。

### 2.2 衙署空间就是权力图

以现存县衙为例，典型空间序列是：

```text
头门（街面）
→ 仪门（礼仪之门，平时闭，侧门出入）
→ 大堂（发布政令、重大典礼、公开审案）
→ 宅门 / 屏门（内外衙分界）
→ 二堂（日常审案、预审、会客）
→ 花厅 / 内宅（私人、亲近、非请勿入）
```

不同来源对门的名称、开闭规则和具体仪注有差异，但共同点是：**越往里，越不是普通人能随便进的地方。**

设计含义：

- 门不是装饰，是权限检查点；
- 大堂是公开权力，二堂是日常权力，内宅是私人权力；
- 客人的身份会改变“轿子停在哪、主人在哪等、哪扇门开”；
- 端茶可以送客，屏门可以表示亲疏，座位可以表示高低。

> 史源：S2、S3、S4。置信度 B/C。

### 2.3 仪仗、称谓与座次

品级带来不同的轿、伞、扇、旗、牌、随从与称谓。具体器物数量在不同年代、不同记载中有出入，不能用一份清单套所有场景。

设计原则：

- 只做**相对差异**，不把仪仗数量当硬数值；
- 知县、知府、道台、督抚的出巡差异，应能被玩家一眼看出；
- 晚清越制是真实存在的社会现象，可成为案件、风评与参劾材料；
- 轻车简从可以是一种选择，不是“低配外观”。

> 史源：S4、S5。置信度 B/C。

### 2.4 吏役的实际权力

书吏、差役不是官，却掌握案牍、档册、缉捕、催粮、门禁等具体环节。他们可能“执例弄权”“舞文作伪”，也可能被长官责罚、被差役体系反噬。班房、管押等非正式羁押，在制度上常处于灰色地带；地方官和差役可以借它制造恐惧，但它也会留下口供、伤单、家属上控与上官查卷的痕迹。

设计含义：

- 不能把“权力”只给官；书办、门子、差役、粮商、士绅都有实际杠杆；
- 无案由收押可以存在，但它不是“合法按钮”，而是高风险行为；
- 记录、见证和上级审查必须能追上。

> 史源：S5、S6、S7、S8。置信度 B/C。

### 2.5 一条历史边界

古代没有现代意义上的“普通人权”。本作使用 **“通用人身权限”**，指在那个时代普通人仍可进行的行走、买卖、劳作、告诉、作证、求告等行动能力，不表示现代法律权利。

“民”也不是同质的：性别、年龄、财产、宗族、良贱、主仆关系都会改变实际处境。M1 只做角色粗分；M2 再讨论更细的社会身份，避免用一个“民”字抹平所有差异。

## 三、权力链：对象必须是人或人控制之物

```text
权力主体
  人 + 当前身份/职位 + 授权 + 资源 + 关系
        ↓
权力依据
  名分 / 印信 / 牌票 / 文书 / 人情 / 银钱 / 武力
        ↓
权力对象
  人 / 人控制的物 / 文书 / 场域中的制度
        ↓
权力动作
  命令 / 请求 / 传唤 / 收押 / 签押 / 征用 / 封门 / 用刑
        ↓
对象反应
  立办 / 拖延 / 讨价 / 阳奉阴违 / 拒绝 / 反制 / 上控
        ↓
直接后果
  人的行动、物的状态、文书的效力
        ↓
场域后果
  价格、秩序、人流、风气、恐慌
        ↓
制度记忆
  文书、账册、碑刻、礼簿、口供、考语、惯例
```

**场域不是直接被命令的。**
要改变一个场域，必须改变其中的人、物或制度。这个约束是防止游戏滑向“点一下按钮，全县变样”的关键。

## 四、身份就是权利束

### 4.1 五类权利

每个身份都要回答五个问题：

| 权利类型 | 问题 | 示例 |
|---|---|---|
| **可为权** | 能直接做什么 | 知县可亲勘、签押、笞杖自理 |
| **须为权 / 义务** | 必须做什么、走什么程序 | 徒以上通详、河工银按审批链 |
| **禁为权** | 即使能做也不能做什么 | 越级、私调河兵、擅动跨汛大工 |
| **礼仪权** | 别人欠你什么姿态 | 座次、称谓、先行、受拜、仪仗 |
| **责任权** | 出事谁承担 | 保固、参劾、连坐、赔补、乡评 |

身份不是“知县 = 权力 80”，而是：

```text
知县（正七品正印官）
可为：亲勘、签押、传唤、雇募、笞杖自理
须为：报灾、保固、徒以上通详、河工按程序
禁为：越级、私调河兵、擅动跨汛大工
礼仪：主位、受拜、称“大人”、出巡仪从
责任：河堤保固、考成、参劾、赔补
```

### 4.2 六类角色（M1 粗分）

| 角色 | 正式命令权 | 资源 | 信息 | 名分/舆论 | 主要弱点 |
|---|---|---|---|---|---|
| **正印官（知县/知州）** | 对吏役、保正、夫头有命令权 | 公帑、雇募、仓粮 | 依赖书办与口供 | 正印名分 | 上官、程序、考成 |
| **佐贰（县丞/主簿）** | 会勘、移会、点卯、监盘 | 部分钱粮、仓储 | 账册与流程 | 佐贰身份 | 不能独断、怕担责 |
| **吏役（书办/差役/门子）** | 无独立命令权，掌握执行环节 | 低 | 档册、门禁、现场 | 低 | 被官责罚、被反查 |
| **士绅** | 无正式官权，有宗族与地方影响 | 土地、捐输、人脉 | 乡评、传闻、宗族 | 地方体面 | 无法定强制力、怕丢面子 |
| **商（粮商/当商）** | 无官权，有交易与断供能力 | 粮、银、货、船 | 行情、商路 | 商业信用 | 官府征税、旧欠、市场反噬 |
| **仆役/家人** | 家庭内部服从关系 | 家务、门房 | 内宅消息 | 依附主人 | 被驱逐、被牵连 |

**M1 建议只启用：正印官、书办、差役/工头、士绅、粮商。**
县丞、主簿、家人按现有切片存在，但不扩展为完整身份系统。

**v0.14 口径澄清：** 本表的六类是 M1 权力权限粗分用的「角色原型」，不是完整人物分类，也不是互斥身份枚举。一个 Person 可同时具有多个身份轴（社会职业、制度资格、家庭出身、组织归属、当前处境）；身份标签与正式职位/授权必须分离。七人是首个验证场景的样本，不是社会人口上限。详细规则以根目录《设计总纲.md》3.8、4.9–4.12 为准；完整展开见《人物分类与社会关系网络系统设计规范-v0.1.md》。

### 4.3 同一个人，不同场合身份不同

| 场合 | 知县的有效身份 | 权力变化 |
|---|---|---|
| 本县大堂 | 正印官 | 可传、审、签、罚 |
| 知府衙门 | 属官 | 只能禀、详、候、拜 |
| 河堤 | 河工主持人 | 可亲勘、调夫，受河厅程序约束 |
| 内宅 | 丈夫/父亲/族人 | 官阶退后，辈分与亲疏上位 |
| 士绅宴席 | 宾客 | 不能带衙役入席、当场拿人 |
| 庙会 | 地方官 | 可维持秩序，不能取代庙祝的宗教权威 |

**“不同身份带来不同权利”不是换角色卡，而是换有效权限、称谓、座位、程序和责任。**

## 五、互动大全：先做文法，不做按钮堆

### 5.1 五层互动

| 层 | 内容 | 说明 |
|---|---|---|
| **通用人身互动** | 看、听、走、等、问、答、买、卖、借、还、求、谢、拒、吃、住、行、递状、作证、逃 | 普通人也有的行动能力，但受门禁与法律约束 |
| **社交八动词** | 问、查、托、请、压、保、赏、荐 | 沿用既有设计，不另造同类动词 |
| **身份权能** | 传、召、签、印、征、派、押、审、刑、封、放、逐、赦/保/荐 | 由身份、授权、场合共同决定 |
| **场域互动** | 入衙、候见、升堂、巡街、设卡、封门、开仓、赴宴、留宿、进香、过渡 | 先过门禁，才谈动作 |
| **越轨互动** | 贿赂、伪造、威胁、私放、隐匿、诬告、越级、闯衙、无案由收押 | 不是没有，而是有见证、有追责、有长尾 |

### 5.2 动作不是“名词列表”

每个动作都应带五件信息：

```text
动作：传
主体：知县
对象：书办
依据：正印官身份 + 公事
场合：县衙二堂，书办在值
反应：立办 / 拖延 / 讨价 / 阳奉阴违
留痕：传票、门簿、在场衙役、书办记忆
```

**同一个“传”，在县衙、在内宅、在知府面前、在庙会上，结果完全不同。**

### 5.3 “互动大全”在 UI 里不是全部铺开

- 点击人物，默认只显示 3–6 个当前可用动作；
- 不可用动作可以显示，但必须给“为什么不能 / 缺什么 / 找谁”；
- 高风险动作放入“非常手段”，先显示代价与见证；
- 完整动作表只用于设计、调试和规则查表，不直接变成主界面按钮墙。

## 七、三尺度：一人、一场、一世

### 7.1 一个人的变化

权力作用于人，首先改变的是**行动、姿态、称谓和拒绝成本**：

- 他是否起身、是否让座、是否退半步；
- 他称你“大人”“老爷”“先生”还是直呼其名；
- 他先说还是后说，能不能打断；
- 他照办、拖延、讨价、阳奉阴违，还是拒绝；
- 他是否把这件事告诉别人。

不要只用“好感 +1”表达。
**权力让人服从，不一定让人亲近；恐惧和怨恨可以同时增长。**

### 7.2 一个场域的变化

场域变化必须通过人、物、文书：

```text
命令门吏关闭东门
→ 门吏执行/拖延
→ 商贩改道
→ 粮价变化
→ 有人传“县衙要封城”
→ 士绅上控
```

场域的权力状态：

| 状态 | 谁做主 | 可见迹象 |
|---|---|---|
| 官府控制 | 正印官/差役 | 门开合、告示、巡役、封条 |
| 士绅影响 | 宗族/士绅 | 祠堂、捐输、宴席、乡评 |
| 商人影响 | 牙行/商帮 | 行市、断供、赊账、码头 |
| 宗教/庙会 | 庙祝/香社 | 香火、庙市、仪式 |
| 失控 | 谣言/匪警/灾民 | 关铺、抢购、逃难、闭门 |

### 7.3 一个世界的变化

不是“天下威望 +10”，而是**制度记忆**：

- 一次临时加派 → 下一季成为“旧例”；
- 一次无案由收押 → 家属上控、士绅传话、上官调卷；
- 一次修堤 → 保固一年、碑记、料账、后续赔修；
- 一次保荐 → 门生、人情债、下一次调任的班底；
- 一次越制仪仗 → 风评、参劾材料、同僚效仿或嘲笑。

**世界不是被玩家直接按按钮改变，而是被记录、模仿、传播、制度化。**

## 八、三个关键场景

### 8.1 普通民人进入县衙/府衙

**入口动作：**

- 可做：`递状`、`求见`、`喊冤`、`候门`、`离开`
- 不可做：`直入内堂`、`传唤`、`用印`

**若强闯：**

```text
门吏阻挡
→ 玩家选择：解释 / 递状 / 求见 / 硬闯 / 离开
→ 硬闯：衙役上前，进入“被执”场景
→ 可解释、求饶、行贿、请保人、被押候审
```

**设计要点：** 不是简单“游戏结束”，而是让玩家亲身经历“门是权限”。普通人的通用权限到门口为止。

### 8.2 知县出巡带仆从

**可带：** 仆从、轿夫、差役、伞扇、牌具。
**代价：** 路费、速度、体力、显眼、被围观、被提前通报。
**收益：** 开道、递帖、看管行李、显示身份、震慑地方。

**选择：**

| 方式 | 效果 |
|---|---|
| 全套仪从 | 体面、威慑、慢、贵、消息先到 |
| 轻车简从 | 快、省、不显眼、可能被门房轻视 |
| 便服私访 | 信息更真、身份更低、被冒犯风险更高 |

**权力展示本身也是信息暴露。** 队伍越显眼，越难看到真实的地方。

### 8.3 知县无案由收押一个普通人

这个动作**应该存在**，但不能是免费按钮。

```text
知县签牌票
→ 衙役执行
→ 无案由/无口供/无见证：标记“无凭据收押”
→ 被押者家属上控
→ 书办留下牌票与门簿
→ 士绅传话、茶楼议论
→ 知府可调卷、传询、参劾
```

- **能**：有衙役、有牌票、有暴力；
- **可**：有法定权限与程序；无案由时是越权；
- **该**：有政治、道德、名分后果。

**玩家可以做一个滥权的官，但世界不会当作没发生。**

## 九、UI 与交互

### 9.1 不做一个“权力值”

主界面只显示：

- 当前身份、品级、差遣；
- 当前授权（印信、牌票、委任）；
- 当前场合（大堂/二堂/内宅/街市/河堤）；
- 当前可用的 3–6 个动作；
- 被挡住的动作及原因；
- 本次动作的见证、留痕和可能后果。

### 9.2 人物交互

点击一个人，先显示：

```text
身份差：你是正印官，他是书办
关系：公事上下级 / 同乡 / 债主 / 姻亲
场合：二堂，公开/私密，是否有他人在场
他能：查档、拟稿、拖延
他愿：不愿担责
他敢：不敢单独拒绝，但敢阳奉阴违
```

再给动作。
**不要先给“好感度”，再让玩家猜这个人怕什么。**

### 9.3 场域交互

- 门：谁能进、谁在门内等、谁被挡；
- 座：谁坐主位、谁坐侧位、谁站着；
- 称：谁先称呼、谁改口、谁被忽略；
- 签：谁可以碰印、谁可以签字；
- 记：谁写账、谁作证、谁传话；
- 罚：谁能让谁付代价。

### 9.4 越权动作

放在“非常手段”而不是普通动作栏：

- 先显示“无凭据 / 越级 / 程序缺口”；
- 显示见证人、可能的上控与上官反应；
- 允许玩家做，但不替玩家洗白；
- 不把暴力做成爽感特效，重点放在后果与记忆。

- `traces`：文书、见证、传闻、债务、伤单等，供世界记忆使用。

## 十一、范围与验收

### 11.1 M1 只做薄片

- 只覆盖正印官、书办、差役/工头、士绅、粮商五类；
- 只做县衙/河堤/夜书房/街市/内宅的入口与 3–6 个关键动作；
- “无案由收押”可作为一次性事件或高风险动作，不做完整监狱系统；
- 不做完整良贱、性别、宗族法律地位；
- 不新增独立“权力值”资源。

### 11.2 M2 再扩

- 完整身份权利束；
- 吏、役、绅、商、仆的分化；
- 仪仗、称谓、座次、门禁的全场景投影；
- 越权、滥权、上控、调卷、参劾的完整长尾；
- 身份与场域的冲突（公事/私情/家族/同年）。

### 11.3 验收标准（建议）

- 玩家能说出：谁能进内堂、谁只能候门、谁能签押、谁能收押；
- 同一个动作，对不同身份有不同可用性与后果，而不只是换文案；
- 被拒绝时，玩家能知道“缺什么/找谁/换什么程序”；
- 越权动作不是被系统隐藏，而是显示风险并可执行；
- 一次命令能在人、场、世界三个尺度上留下可追溯痕迹；
- 玩家不能靠一个“权力值”解释所有结果；
- UI 不出现单一权力条、官威光环或稀有度边框。

## 十二、需要设计人拍板的问题

1. **无案由收押是否开放？**
   建议：开放，但只作为“越权/滥权”，必须有见证、牌票、上控与上官审查。M1 可先做成一次性剧情事件。

2. **M1 身份粗分到什么程度？**
   建议：官/吏/役/绅/商/民/仆七类，不做完整良贱、性别、宗族法律地位；M2 再扩。

3. **历史仪注复刻到什么程度？**
   建议：保留相对等级（轿、伞、门、座、称谓），不逐项复刻所有器物数量；具体数字标为待考，不把一种地方志当全国通例。

4. **“普通人权”如何命名？**
   建议：使用“通用人身权限/通用互动”，不使用现代“人权”概念，避免历史语义错位。

# 世界生命、全人物状态与自由人生模拟系统设计规范 v0.1

> **性质：** 正式游戏核心规则专项展开稿；规则权威仍归仓库根目录《设计总纲.md》。
> **目标：** 将“官员人生为主题、自由古代人生为广阔空间、AI 驱动动态世界”落实为可验证的世界模拟规则。
> **边界：** 本文描述正式游戏，不以当前前端预览的页面、数据或施工范围限制系统设计；界面只读取规则结果，不反向定义世界。

---

## 0. 核心裁决

1. **这是一个持续运行的古代社会人生模拟世界，不是任务列表，也不是 NPC 对话合集。**
2. **所有人物都是完整生命体。** 玩家、官员、士子、家属、商人、农户、差役、工匠、仆役等共享统一人物内核，具有出生/既往经历、年龄、身体、心理、认知、身份、关系、资源、目标、日程和死亡状态。
3. **官员人生是主题主轴，不是唯一合法人生。** 科举、入仕、任官、治理、考成、升迁、调任、致仕构成重点体验；游学、谋生、经商、置业、婚姻、家族、交往、迁徙、隐居等人生路径必须可以独立成立。
4. **AI 负责动态性，规则负责可信性。** AI 生成候选人物、意图、事件提案和自然表达；制度规则、时间、资源、生命状态、因果校验和事件账本决定什么真正发生。
5. **世界不围着玩家转。** NPC 有自己的生命历程、目标、关系、家庭、工作、风险和行动；玩家不参与时，世界仍按合适的模拟精度推进。
6. **不把“全人物状态”误解为每个人每秒都运行完整 AI。** 所有人共享完整状态模型，模拟频率按距离、重要性、事件临近度和玩家可观察性分层。
7. **预览不是产品边界。** 前端原型只验证信息呈现和交互理解；正式规则、数据模型、世界规模与 AI 驱动能力以总纲和本规范为准。

## 1. 游戏定位与体验承诺

### 1.1 核心定位

玩家进入一个具有明确朝代、年代、地域、制度与社会结构的古代世界，以一个具体人物的处境开始人生。默认主线入口为科举前后的人生阶段，围绕读书、应试、结交、入仕、任官和官场治理展开；玩家可以偏离、放弃、失败、转行或重新开始新的社会路径。

“官员模拟器”意味着官制、仕途、权力、行政、财政、文书、考成、政治关系具有较高系统深度；“自由古代人生”意味着玩家不被官职、主线任务或固定结局锁死。

### 1.2 体验承诺

- 玩家能够解释自己为何获得某个身份、机会、职位、名声或关系。
- 玩家能够看到人物随着年月真实变化，而不是只在任务触发时换台词。
- 人物会因年龄、健康、家庭、财富、知识、职位、关系与时代变化而改变行动能力。
- 人物死亡、离任、迁徙、失势、婚姻、家族变化会改变社会结构，并留下历史后果。
- 玩家可以追求仕途，也可以追求家业、学问、名声、安稳、自由、关系或其他自定目标。
- 世界能产生玩家未预设的合理事件，但不能用随机噪声取代因果。

### 1.3 不承诺

- 不承诺所有历史人物都能无限细节实时模拟。
- 不承诺玩家可以违反物理、制度、时间和资源约束。
- 不承诺 AI 每次都自由发挥；高风险、不可逆、制度性结果必须由规则裁决。
- 不承诺所有人生路径在首个可玩版本都有同等内容密度；但架构不得把非仕途人生设计成死路。

## 2. 统一人物生命模型

### 2.1 人物是持续实体

Person 是唯一人物实体。人物不会因为离开场景、退出关系网络、卸任或玩家不再关注而消失。其生命周期记录持续存在；当前状态是历史事件在某一时点的投影。

人物数据分为四类，禁止混成一个可随意改写的“人物属性包”：

| 类别 | 内容 | 变化方式 |
|---|---|---|
| 固有与出身 | 出生来源、遗传/家族背景、籍贯、出生年代、先天体质倾向、早期环境 | 原则上不可改；发现错误以更正事件留痕 |
| 长期形成 | 教育、能力、性格倾向、习惯、创伤、声望、技艺、人生经验 | 由长期经历、训练、环境和事件逐步变化 |
| 当前状态 | 年龄、健康、伤病、疲劳、情绪、饥饱、居所、现金、库存、职位、关系状态、认知、日程 | 随时间和事件变化 |
| 历史记录 | 出生、学习、考试、婚姻、任职、迁徙、疾病、诉讼、奖惩、死亡等事件 | 追加式记录，不覆盖 |

### 2.2 全人物状态域

所有人物共用下列状态域。某些字段可以因身份/生活阶段而为空或不适用，但不得因为 NPC 不在屏幕上就不存在。

| 状态域 | 最小内容 | 影响 |
|---|---|---|
| 生命 | 出生时间、年龄、生命状态、死亡时间/原因、寿命风险因素 | 是否能行动、代际更替、继承与历史连续性 |
| 身体 | 健康、体力、疲劳、伤病、慢性病、残疾、营养、恢复、衰老影响 | 行动速度、工作能力、旅行、判断与寿命风险 |
| 心理 | 情绪、压力、恐惧、欲望、执念、心理负荷、应对方式 | 选择偏好、风险承受、关系回应 |
| 性格 | 稳定倾向、价值取向、习惯、脾气、处世风格 | 行为倾向，不直接决定必然行为 |
| 能力 | 学识、行政、财政、司法、工程、交涉及时代/职业相关技艺 | 可做什么、做得多好、学习速度 |
| 教育与知识 | 读写、经学/算学/律例/医术等知识、师承、学习经历、已知事实 | 资格、判断、职业与信息理解 |
| 身份与资格 | 家庭/社会身份、职业、户籍/籍贯、科举资格、功名、官职、品级、任职资格 | 制度入口、礼仪、资源、责任 |
| 人生阶段 | 幼年、受教育、成年、求学、谋生、成家、任职、失业/失势、养老等阶段标记 | 可用活动与内容权重；不得成为硬性脚本 |
| 家庭与亲属 | 父母、配偶、子女、兄弟姐妹、宗族、监护、扶养、家产责任 | 家庭义务、继承、情感与社会网络 |
| 关系 | 多重关系、方向、事实/认知、有效期、来源事件 | 合作、冲突、信息、社会资本与风险 |
| 组织 | 官署、家族、师门、商帮、行会、地方团体、军伍等成员身份 | 集体目标、资源、规则与行动 |
| 经济 | 现金、资产、土地、房屋、产业、收入、支出、债务、担保、信用 | 生活维持、投资、婚姻、旅行、政治行动 |
| 认知 | 知识、信念、误解、传闻、秘密、证据、信息来源和可信度 | 决策与信息不对称 |
| 目标与计划 | 长期目标、阶段目标、短期意图、计划、承诺、风险评估 | 自主行动与人生轨迹 |
| 日程与位置 | 当前地点、移动计划、工作时段、休息、出行、可联系状态 | 接触可达性、时间成本与场景 |
| 名声与社会评价 | 清名、能名、声望、风评、污名、社会认知 | 机会、婚姻、信用、任用与政治风险 |
| 法律与风险 | 诉讼、处罚、通缉、处分、保结、担保、政治风险 | 行动限制和后续后果 |
| 物品与生活 | 衣物、工具、书籍、交通工具、住所、饮食与日常用品 | 生活质量、工作条件和社会表现 |

**完整不等于每人每项都有值。** 未知必须存为未知；不适用必须显式区分；不能用默认值伪造人生经历。

### 2.3 状态值的语义边界

- **属性**描述相对稳定的个人倾向或能力；**状态**描述当前时点；**事件**描述发生过的事实；**认知**描述某个人如何理解事实。
- 健康不是单一“血条”：至少区分基础体质、当前健康、急性病伤、慢性问题、疲劳与营养。
- 性格不是固定脚本：性格影响行为倾向，具体行为仍由目标、认知、资源、风险、关系和情境共同决定。
- 能力不是官职：任官资格、实际授权和工作能力必须分离。
- 名声不是客观能力：社会评价可能滞后、失真或被操纵。
- 关系不是好感总分：多重、方向不对称、随时间变化，详见人物社会关系规范。
- AI 生成的描述不能直接覆写结构化状态。

### 2.4 状态更新规则

每次更新必须归属于以下来源之一：时间自然变化、生命/身体规则、人物自主行动、外部事件、玩家行动、制度判定、经验证据纠错。每次更新记录：subject_id、字段/状态域、变化前后、有效时间、cause_event_id、rule_id 和可见性。

无来源的状态跳变不允许提交。纯叙事润色不得产生状态变化。

## 3. 寿命、出生、衰老与死亡

### 3.1 出生与进入世界

人物来源至少包括：
- 开局时已存在的历史/随机人物；
- 模拟世界中按家庭、婚姻、生育和人口规则出生的人物；
- 科举、学校、军伍、官署、商号、宗族、行会等制度或组织中出现的人物；
- 因迁徙、旅行、通信、交易、诉讼、灾害、战争等事件进入玩家可接触范围的人物。

人物“被创建进数据”不等于“出生事件发生在当前游戏时间”。开局已成年人物必须有可追溯的出生年代、家庭/成长背景和既往履历摘要；无法确定的内容标记为未知或生成设定，不得伪称史实。

### 3.2 年龄与生命阶段

- 年龄由出生时间和世界时间计算，不通过每回合随意加一。
- 采用朝代/地域可配置的历法、纪年、节气、年龄称谓和礼制口径；虚岁/周岁等展示口径不能混淆内部实际时间。
- 人生阶段是状态标签，不是强制剧情。相同年龄的人可因出身、教育、战争、疾病、家庭责任而处于不同阶段。
- 学习、婚姻、生育、任官、养老等年龄门槛按具体时代制度配置，不写成跨朝代通用硬编码。

### 3.3 寿命与死亡

死亡必须是世界的真实规则，而不是只发生在剧情角色身上的剧情开关。

死亡原因至少分类为自然衰老、急病、慢性病、伤害、生产/灾害事故、战争/暴力、司法处决及其他经规则允许的原因。死亡判定受年龄、健康、体质、疾病、营养、环境、医疗可及性、劳动强度、灾害暴露等因素影响。

规则约束：
1. 不为所有人物指定同一个固定寿命；采用时代/地域/阶层/环境可配置的寿命分布与风险曲线。
2. 寿命模型不是“到某年龄必死”的倒计时；风险随条件变化，具体参数须历史研究和玩法验证。
3. 重大疾病、事故、战乱和灾害可以显著改变风险，但需有事件原因、预警或可解释的风险暴露。
4. 玩家人物与重要 NPC 适用同一生命规则，不因主角身份永久免死；关键不可逆风险应给出足够可感知的线索，但不保证玩家能避免。
5. 死亡事件提交后，人物转为 deceased，不再执行普通日程；遗体、财产、债务、亲属、职位、组织成员、未竟承诺和社会关系按各自规则处理。
6. 死亡不能删除人物历史；已知人物档案、行状、文书、家谱和关系史保留死亡状态与时间。
7. 不能把“关系终止”“失联”“迁徙”“隐退”误判为死亡；需要证据或可信事件。
8. 任何复活/替身机制均不属于本作默认规则。

### 3.4 衰老与身体变化

衰老影响体力恢复、疾病风险、感官、行动速度、工作负荷和恢复时间；但个体差异必须存在。能力经验可能增长，身体表现可能下降，两者不能合并成一个等级。高龄人物仍可能有经验、威望和社会资源，但身体限制会改变其行动方式。

### 3.5 家庭、出生与代际延续

婚姻、生育、收养/认养、监护、扶养、继承、分家、丧亲等均由时代规则与人物行动共同决定。不得默认所有婚姻都生育、所有子女都存活、所有家产都由长子继承。亲属关系、法律身份、实际扶养和情感关系应分开记录。

玩家可以选择成家或不成家；不婚、无子、离家、过继、家族断绝等都可以成为合法人生状态。家族传承是长期内容，不是强制终局。

## 4. 时间、身体与生活循环

### 4.1 多尺度时间

世界时间必须支持短时行动与多年人生：
- 微观：对话、文书、短时互动；
- 日内：工作、用餐、休息、拜访、宴饮；
- 日/旬/月：公务、工资、租税、账目、通信、疾病恢复；
- 季/年：科举、任期、农业生产、婚姻、迁徙、考核；
- 多年/代际：衰老、子女成长、家族兴衰、组织变迁、历史回声。

现行 B+ 四时段是首个验证场景的操作节奏，不得把它误认为生命模拟只能每四段推进。长动作和跨年结算须由统一时间引擎推进，并保持事件顺序和因果一致。

### 4.2 每日生活

人物日程至少考虑工作/学习、休息、饮食、照护、社交、出行、家庭责任与个人目标。日程是计划，不是保证；疾病、天气、事件、资源短缺、临时差事和他人行动可以打断或改变计划。

### 4.3 身体状态的持续影响

疲劳、饥饿、疾病、伤痛、睡眠不足、营养和压力应影响行动成本、失败风险、恢复速度和信息判断。不能只在玩家人物上生效；NPC 也会因过劳、生病、年老、受伤而缺席、迟延或改变行为。

### 4.4 生活维持与经济压力

每个人物根据家庭规模、身份、地域、季节、生活方式和财富状况产生生活消耗与收入来源。不得为所有 NPC 生成同样的账本颗粒度；重要人物详细记账，远端人物按汇总账和状态阈值模拟。破产、负债、饥困、失业、依附、迁徙和改善生活都应是可发生的变化。

## 5. 官员人生主轴

### 5.1 仕途是一条完整人生链

科举准备与资格 → 报名/应试 → 放榜与功名 → 拜师/举荐/候选 → 入仕与初任 → 任官履职 → 考成与升降 → 调任/外放/入京 → 失势/被参/处分/复起 → 致仕/养老/身后评价。

此链条是产品重点，不代表每位玩家或 NPC 必然走完。每一环均允许失败、延误、拒绝、错过、转向和重新选择。

### 5.2 官职与实际人生分离

官职、品级、资格、实际权力、工作能力、社会声望和个人财富是不同对象。获得官职不自动获得足够资源、能力、同僚支持或社会信任；失去官职也不意味着人物生命与玩法结束。

### 5.3 官场系统与全社会系统互相影响

任官影响收入、住处、日程、风险、家庭迁徙、社会交往和信息渠道；家庭与身体影响履职能力；名声和关系影响机会但不能越过法定制度；地方治理会改变百姓生活、经济、治安、迁徙和社会评价。

### 5.4 仕途以外的可持续路径

玩家不入仕或离开仕途后，仍可通过教育/著述、经营产业、商贸、土地经营、幕友/师爷、地方公益、家族事务、游历、婚姻与社会交往等维持目标和长期变化。具体职业按时代和地域配置，不要求首版全部深做，但必须有可继续的人生退路，不能只剩“重新参加科举”。

## 6. 自由人生与玩家自主权

### 6.1 玩家可以自定目标

目标可以来自系统建议，也可以由玩家自由表达。AI 将自由表达解析为目标候选、计划和约束；玩家确认后才成为玩家意图。系统不得把玩家未选择的“中举、入仕、升官、结婚、生子、置产”等目标自动设为主线。

### 6.2 自由不等于无约束

行动受到时间、身体、金钱、身份、制度、地点、信息、能力、风险和他人意愿约束。系统应解释“不能、不会、不愿、不敢、暂时不能、尚未获知”的差别，并提供合法替代路径，而非简单拒绝。

### 6.3 失败与人生转向

落第、革职、破产、关系破裂、疾病、丧亲、诉讼、迁徙等都可能发生。失败必须改变局势，但不能默认结束人生。每种重大失败至少设计即时后果、长期后果、玩家仍可做的事、可利用的新机会、无法挽回的损失，以及可恢复但需要代价的部分。

### 6.4 不替玩家做重大决定

AI 可以建议、劝说、警告和展示后果；不得擅自替玩家作出不可逆的婚姻、重大财产处分、官职接受/辞拒、政治承诺、迁居、犯罪或生命风险行动。玩家沉默只表示未行动，不自动视为同意。

## 7. AI 社会世界驱动器

### 7.1 驱动器输入

每轮从权威状态读取世界时间、朝代/地域规则、季节、天气、灾害与公共事件；人物生命、身体、心理、身份、能力、家庭、经济、认知、关系、组织、目标、日程和位置；机构、职位、权力、法律、行政、市场、交通和通信规则；已提交事件、待执行承诺、事件时钟、资源约束；玩家当前可见范围与玩家认知快照。

### 7.2 AI 候选输出

AI 可以提出人物的短期意图与长期目标变化建议；人物相遇、通信、交易、求学、应试、任职、婚姻、冲突、疾病就医等候选事件；人物关系、身份、组织成员和认知变化候选；新人物候选及其生成依据；对话、文书、传闻、场景细节和事件叙事。

每个候选必须包含行动者、目标、动机、前置事实、时间地点、渠道、成本、风险、预期影响、来源引用、可见性与置信度。

### 7.3 规则校验与事件提交

统一顺序：
1. 检查候选是否重复、过期或与已发生事件冲突；
2. 检查人物是否存活、在场/可达、具备相应身份资格与行动能力；
3. 检查时间、日程、身体、资源、交通、通信和制度前置条件；
4. 检查行动者掌握的信息是否足以产生该意图；
5. 检查关系、家庭、组织和事件变化是否满足各自形成条件；
6. 计算成本、风险、执行偏差与结果；
7. 生成唯一 Event ID 并提交事实；
8. 更新人物状态、关系、组织、认知、账目、日程与后续计划；
9. 仅向有来源渠道的观察者传播信息；
10. AI 根据提交结果生成叙事。

AI 不得跳过规则层直接写入事实。规则校验失败的候选应拒绝、延迟或退回补充，不得以“剧情需要”强行通过。

### 7.4 自主行动与动机

人物行动至少考虑生存与身体、家庭义务、经济利益、职业/仕途、名声、情感、信仰/价值、组织责任、承诺、恐惧与机会。不同人物权重不同，且随人生阶段变化。NPC 不需要每轮都做显著行动；维持现状、休息、等待、犹豫、拒绝、观察也都是合法决策。

### 7.5 动态事件生成

事件由规则自然事件（时间、季节、身体、经济、制度和环境变化）、人物意图事件（人物自主行动与互动）、外部世界事件（朝廷政令、战争、灾害、市场波动、社会风潮等）共同驱动。事件必须满足因果链与世界约束。AI 可创造新情境，但不能任意创造不符合年代、地理、制度和资源条件的事件。

### 7.6 幂等、预算与降级

- 同一候选重试不得重复结算；候选 ID、规则版本、输入快照和事件结果必须可审计。
- AI 调用失败、超时或成本超预算时，使用规则模板、预置意图或延迟队列；世界时间不能因模型故障而失控。
- AI 生成频率按事件重要性、玩家接近度和模拟 LOD 控制；不能每个 NPC 每个时段都进行一次完整大模型调用。
- 模型输出不稳定时，以结构化候选验证器拒绝不合规内容，不允许“尽量相信模型”。

## 8. 世界模拟精度与人口规模

### 8.1 全人物统一模型，分层运行

| 层级 | 对象 | 模拟粒度 | 目的 |
|---|---|---|---|
| L0 近场 | 玩家当前场景、直接互动者、当前案件关键人物 | 完整状态、细粒度日程、行动与认知更新 | 保证即时交互与因果 |
| L1 关系圈 | 玩家已知人物、近期通信对象、重要关系人 | 定期更新目标、位置、健康、关系、重要行动 | 保证社会关系持续性 |
| L2 地域圈 | 同县/同府/同区域的普通人物与组织 | 汇总状态、抽样事件、关键节点精算 | 形成地方社会生态 |
| L3 远端世界 | 跨地域普通人口、未接触人物 | 人口/组织统计、重大事件触发、按需实例化 | 保持世界广度与可扩展性 |

LOD 只影响计算频率和细节，不改变人物作为完整生命体的定义。任何从低精度升级到高精度的人物，都必须继承既有状态与历史，不得重新随机生成一套人生。

### 8.2 人口与人物生成约束

人物生成受地域人口、家庭结构、职业需求、组织容量、科举名额、迁徙、交通、事件和当前场景候选上限约束。不得为每次对话临时无限造人；也不得因为玩家未接触而把世界人口当作不存在。

### 8.3 重要人物精算规则

玩家本人、直系家庭、重要关系人、关键官员、当前事务参与者和重大事件当事人应保留可追溯的精确状态。普通人物可采用汇总模拟；一旦进入重要场景，必须通过一致的实例化规则补齐必要细节。

### 8.4 世界持续推进

玩家等待、旅行、睡眠、读书、经营或专注公务期间，世界按时间推进。推进内容由当前时钟、人物意图、制度日程和外部事件决定；不为了制造戏剧冲突而保证每天发生重大事件。

## 9. 事件账本与历史连续性

### 9.1 事件为事实源

人物状态、身份、关系、组织成员、职位、家庭、经济、疾病、死亡、认知和位置变化必须能追溯至事件或明确的开局事实。当前快照是事件流投影，不是第二套可独立修改的真相。

### 9.2 事件最小契约

每个影响世界状态的事件至少记录 event_id、event_type、schema_version、occurred_at、resolved_at、effective_from/to、actors、subjects、targets、location、channel、preconditions、rule_ids、input_snapshot_hash、costs、risks、outcome、state_deltas、evidence/source_refs、visibility、knowledge_updates、parent_event_ids、causal_links、idempotency_key，以及后续更正/撤销事件引用。

### 9.3 历史更正

世界事实可能被误报、伪造或后来证伪。更正不得删除旧事件，而应新增更正/裁决事件，保留“当时人如何相信”与“后来确认了什么”的区别。

### 9.4 身后与职位交接

人物死亡或离任后，未完成事务、职务、债务、产业、亲属责任和组织关系分别按制度处理。不能简单将全部状态复制给继承人或继任者。

## 10. 朝代、地域与史实配置

历史制度、科举规则、官制、婚姻、继承、户籍、税制、医疗、交通、通信、年龄礼制和生活习惯必须按朝代、年份、地域配置。不得把明清官制与其他朝代规则混用，也不得把特定时期的座师、同年、保结、任官程序当成所有时代普遍规则。

配置应包含生效时间与地域范围、规则来源和史料置信等级、强制制度/地方惯例/社会习俗/玩法抽象的区分、允许的例外和裁量主体、版本号与变更记录。史实不足时标注为“设计抽象/待考”，不得伪装成确定史实。

## 11. 与既有系统的边界

| 系统 | 负责 | 不负责 |
|---|---|---|
| Person / LifeState | 人物实体与生命状态 | 不决定制度权力 |
| Identity / Office / Authorization | 身份、职位、资格与权力 | 不决定私人信任 |
| Relation / Organization | 个人关系与集体结构 | 不替代法定程序 |
| Goal / Intention / Schedule | 人物目标、计划与日程 | 不直接确认事实结果 |
| Body / Health | 身体状态和生理约束 | 不将所有疾病简化为随机扣值 |
| Economy / Household | 家庭经济、产业、收支与责任 | 不与官府财政混账 |
| Knowledge / Belief / Exposure | 信息与认知 | 不全局广播 |
| Event Ledger | 世界事实、因果与历史 | 不负责自然语言叙事 |
| AI Narrative | 对已发生事实进行表达 | 不反向创建事实 |
| Frontend Preview | 验证信息层级、交互与可理解性 | 不定义生命规则、人口规模或系统上限 |

## 12. 验收标准

### 12.1 人物完整性
- 任取玩家、官员、普通百姓、家庭成员和远端 NPC，均可读取统一状态域。
- 未知、不适用、未生成与空值能明确区分。
- 年龄由出生时间推导；身份、健康、关系、职位变化均可回查事件。

### 12.2 生命连续性
- 至少纸面推演出生/开局既有人物、成长、疾病、衰老、死亡及身后处理。
- 死亡不会删除人物历史；债务、职位、亲属、产业和组织成员按不同规则处理。
- 玩家与 NPC 适用同一生命规则；不得主角豁免。

### 12.3 自由人生
- 至少跑通科举成功、科举失败、放弃科举/改途三条人生路径。
- 每条路径都存在可继续的行动、目标和事件，不强制回归仕途。
- 玩家未确认的重大决定不得由 AI 代做。
- 非仕途路径可以产生持续的家庭、经济、关系、名声和人生变化。

### 12.4 AI 驱动可信性
- AI 候选未通过规则校验不得改变世界。
- 同一事件重试幂等；状态变化均有事件来源。
- AI 故障时规则与模板仍可推进。
- 至少出现一次 NPC 自主行动、一次拒绝/延迟、一次无显著事件的正常时段。
- 玩家不知道的 NPC 关系、秘密和行动不得进入玩家认知视图。

### 12.5 模拟规模与性能
- L0–L3 同一人物升降级后状态连续。
- 普通 NPC 不需要每时段完整 AI 推理也能保持合理生活状态。
- 关键人物的行动和位置可以回放，汇总模拟可以解释误差范围。
- 人口、事件和模型调用都有预算与上限，超限时优雅降级，不丢事实。

## 13. 必须纸面推演的场景

1. 一名读书人落第后回乡、谋生、再试，数年间身体、家庭经济、学习和关系如何变化。
2. 一名官员升任外地，家庭是否随迁、旧关系如何维持、通信如何延迟。
3. 一名 NPC 官员病重、缺席公务、被替代、最终死亡，职位、文书、债务和亲属如何处理。
4. 一名普通商人经历交易、负债、婚姻、迁徙和死亡，其家产与关系如何变化。
5. 玩家在数月内只读书/休息/经营，不主动社交，世界仍有合理变化但不强行制造重大剧情。
6. 玩家不入仕，选择经商或游学，仍可持续推进人生。
7. 玩家人物死亡或被迫退出仕途，世界继续运行，历史档案保留。

## 14. 未决与禁止提前冻结的参数

寿命分布、疾病率、死亡风险、出生率、婚育年龄、家庭规模、医疗效果、生活成本、NPC 更新频率、人口上限、AI 调用预算、远端模拟精度均为待史料研究、性能测试和 M0/M1 验证的参数。本文冻结的是对象边界、因果原则、生命连续性、自由人生与 AI/规则职责，不是未经验证的数值。

# 场景美术资产矩阵 v0.1

> 性质：**非规范性内容包**，不构成规则，不进入主设计单。与 `特殊场景与地方胜迹清单-v0.1.md` 配套；场景是否“内容特殊”与是否“美术独占”分开判断。
>
> 一句话：**特殊场景独占美术；功能相同的地方共用母版；地方差异靠 overlay，不靠重复画底图。**

---

## 一、资产档位

| 档位 | 定义 | 是否跨城复用 | 典型数量 |
|---|---|---|---|
| **EX · 专属** | 只此一处、具有独特空间身份、历史身份或剧情关键性的场景 | 否 | 少而精 |
| **SH · 共享母版** | 功能相同，可跨府、县、镇复用的场景 | 是 | 主要资产量 |
| **HY · 混合** | 共享母版足够成立，但必须保留一个专属物/专属锚点 | 底图是，overlay 否 | 少量 |
| **BG · 背景** | 只作远景、过场或氛围，不进入场景交互 | 是 | 按需 |

**判断顺序：**

1. 功能是否与已有母版相同？
2. 相同 → 用 `SH`，最多加 `HY` 的一个专属 overlay。
3. 不同 → 才允许新建母版。
4. 只有“独特空间身份 + 剧情/历史不可替代”时，才做 `EX`。
5. 只为“这里也该有个房子”而新建底图，拒绝。

## 二、资产规格

### 2.1 底图

- 画面比例：16:9。
- 生产源：2560×1440 或更高，分层源文件。
- 游戏交付：1920×1080 WebP；保留无损母版。
- 画面内不烘焙：汉字、地名、数字、价格、官衔、NPC 人脸、UI、任务标记。
- 中央与四角留出 3–6 个锚点空间；同一母版的锚点位置固定。
- 纸纹、旧边、雨线、灯光、灰尘等优先做可复用的叠层，不重复绘制进底图。

### 2.2 叠层

| 层 | 用途 | 示例 |
|---|---|---|
| `light` | 晨/午/暮/夜、局部灯光 | 县衙晨光、夜书房烛光 |
| `weather` | 雨、雪、洪水、烟尘 | 东堤暴雨、渡口涨水 |
| `local` | 地方差异 | 招牌文字、酒旗、香烛、粮袋、地方物产 |
| `event` | 事件状态 | 接风宴、庙会、抢护工地、验尸/审案 |
| `people` | 固定人物、来客、无名背景 | 可换装、可换站位 |

### 2.3 命名

```text
scene_ex_east_dike_base.webp
scene_sh_yamen_county_base.webp
scene_sh_teahouse_base.webp
scene_hy_yamen_county_night_base.webp
overlay_light_dusk.webp
overlay_weather_rain.webp
overlay_local_jiangnan_incense.webp
```

- `ex`：专属；`sh`：共享；`hy`：混合；`bg`：背景。
- `base` 只用于底图；`overlay` 不得混入 base。
- 资产单另记：来源、授权、生成工具、提示词、人工修改、审核、版本。

- 同一地点不同事件用 event overlay，不重建场景。

## 八、验收规则

1. **同功能不重画**：两个县的县署、茶楼、城隍庙必须引用同一个母版 ID；例外需写明功能差异与资产理由。
2. **特殊才独占**：EX 必须能回答“为什么不能用 SH + overlay”；回答不了，降级。
3. **文字不烘焙**：所有地名、匾额、数字、价格、官职由 UI 渲染。
4. **锚点稳定**：同一母版在晨/午/暮/夜与天气变化下，锚点位置不变。
5. **一屏可读**：进入后 3 秒内能辨别地点、时辰、在场人物与最该处理之事。
6. **可回滚**：每次资产更新保留旧版，场景配置能回退；资产单记录来源、授权与版本。

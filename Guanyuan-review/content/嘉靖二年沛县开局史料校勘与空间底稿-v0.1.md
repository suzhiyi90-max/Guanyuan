# 嘉靖二年沛县开局史料校勘与空间底稿 v0.1

> 性质：**非规范性历史研究底稿**，用于 M1 沛县历史原型的内容核验；不构成游戏规则，不修改《设计总纲》、程序、地图、Schema、事件账本或存档。
> 时间锚点：明世宗嘉靖二年（1523）。
> 当前范围：沛县县治、运河闸段、河患事实、嘉靖二十二年（1543）地方志的使用边界。
> 美术：本文件不生成、不替代正式美术资产；任何地图/场景美术须待历史空间验收后由项目负责人生成。

## 0. 本轮交付结论

1. **取得嘉靖二年当年《明世宗实录》直接证据**：嘉靖二年十月戊戌，户部会议次年漕运事宜时，记“沛县以南湖陵城至黄家八闸，近黄水涌入，俱没水底”，并议暂革沽头主事及各闸官吏、每闸留夫十名看守。该条将1523年河患影响落实到沛县以南一段漕运闸区，不只是后世方志的概括。
2. **纠正此前“黄家八闸缺少史料支持”的结论**：该名称确见于嘉靖二年《明实录》原文。当前可确认它是当时漕运奏议使用的地名/闸段称谓；原文没有逐一列出八座闸的名称、位置或坐标，因此不得自行拆成八个可定位设施。
3. **1543年《嘉靖沛县志》不能直接充当1523年地图**：该志编成于嘉靖二十二年；后出《沛县志》编年记载嘉靖二十一年（1542）迁儒学、筑昭阳湖围堤、丈湖田，嘉靖二十二年春修志、筑土城成，冬沽头城成。故1543年的县境图、县市图、县治图、县学图和沿革图均是1523年之后的空间快照。
4. 1543年志书仍是下一轮最重要的近时材料：它可用于提取地名、设施沿革、乡镇、户口、赋役、职官和交通线索，但必须逐项回溯始建/迁建/裁撤年代，不能整图或整表倒灌到开局。
5. **本轮不批准制作1523年完整县城地图或完整河网图**。现有证据足以建立若干有向关系和受灾区段，尚不足以给出所有河渠、闸座、村集的精确坐标。

## 1. 嘉靖二年当年直接证据：运河闸段受淹

### 1.1 原文与出处

《大明世宗肃皇帝实录》卷三十二，嘉靖二年十月戊戌条，户部会议嘉靖三年漕运合行事宜，其中记：

> 沛县以南湖陵城至黄家八闸，近黄水涌入，俱没水底。

同一议项随后提出：

> 乞将沽头主事并各闸官吏暂革，每闸量留夫十名看守。

出处：识典古籍《大明世宗肃皇帝实录》卷三十二，嘉靖二年十月戊戌条：
https://www.shidianguji.com/book/LS0026/chapter/1k6toaxbwmhwm

证据等级：**A（当年官修实录原文）**。该条是户部会议漕运事项的奏议/议覆记录，不是后世地方志追记。

### 1.2 可以锁定的事实

| 事实项 | 可确认内容 | 证据边界 |
|---|---|---|
| 时间 | 嘉靖二年十月戊戌 | 不把后世公历换算误差带入游戏日期 |
| 受影响空间 | 沛县以南、湖陵城至黄家八闸这一漕运闸段 | 只锁定文字描述的区段，不推定现代坐标 |
| 水患表现 | “近黄水涌入，俱没水底” | 说明闸段被水淹没；不等于全部闸体冲毁 |
| 河务/闸务人员处置 | 沽头主事及各闸官吏暂革 | “暂革”须结合后续制度记录理解，不等于永久废除全部河务 |
| 留守力量 | 每闸酌留夫十名看守 | 这是当次议覆所定的临时留守配置，不是常年定额 |
| 政务背景 | 户部讨论次年漕运事项 | 说明河患已进入漕运行政处置层面 |

### 1.3 对此前错误结论的更正

此前研究曾写“未找到可靠史料支持‘黄家八闸’这一总称”。该结论现予撤销。

正确表述为：

- “黄家八闸”作为一个当时文书中的称谓，有嘉靖二年《明实录》直接证据。
- 但当前尚未取得逐闸名录，不能把“八闸”自动拆解为八个已经确定名称、位置、建成年代的独立地图实体。
- 后出地方志所列湖陵城闸、金沟口闸、谢沟闸、留城闸等，应继续逐项核对是否属于该奏议中的闸段及其嘉靖二年运行状态；不能仅凭名称相近就认定对应关系。

### 1.4 游戏内容可用边界

允许作为嘉靖二年开局事实：
- 沛县以南漕运闸段遭黄水侵入并被淹。
- 漕运管理部门需要处理闸段失效、留守看护与人员裁撤问题。
- 河患不只是农田受灾，也影响国家漕粮运输和闸务管理。

暂不允许：
- 直接指定决口口门坐标。
- 宣称湖陵城至黄家八闸全部闸体被冲毁。
- 宣称1523年整个京杭运河全线断航。
- 将八闸分别命名、定位或分配官员，除非获得逐闸原始记录。
- 将嘉靖五年（1526）庙道口—鸡鸣台—昭阳湖的具体水路，提前作为1523年已证实的洪水路线。

### 2.3 1543年地图的关键年代陷阱

后出《沛县志》卷一编年记载：

- 嘉靖二十一年（1542）：迁儒学；筑昭阳湖围堤；丈量湖田。
- 嘉靖二十二年（1543）：春修县志成、筑土城成；冬沽头城成。
- 嘉靖二十六年（1547）：筑砖城成。

出处：清李棠《沛县志》卷一，识典古籍：
https://www.shidianguji.com/book/NLG312001076291/chapter/1ljlv7qn1d0d7

对应原文位置可见“二十一年，迁儒学，筑昭阳湖围堤，丈湖田”及“二十二年春，修县志成，筑土城成。冬，沽头城成”。这是后世方志对早期事件的编年追记，证据等级B；但其年代顺序清楚，足以构成地图使用的强制过滤条件。

**裁定：1543年县治图不能直接用作1523年县治图。**

理由：
- 1543年地图绘制时，沛县土城已于1543年筑成；1523年开局早二十年。
- 儒学在1542年发生迁建；1543年县学图也不能直接投射回1523年。
- 昭阳湖围堤在1542年已筑；不能将该堤防状态放入1523年开局。
- 沽头城在1543年冬才成；不得进入嘉靖二年场景。
- 砖城在1547年才成；更不得提前使用。

因此，1543年五幅图只能作为**嘉靖中期空间对照资料**。若要提取1523年空间，必须先对图中每个实体做“始建—迁建—毁坏—重修—裁撤”时间过滤；无法确定年代的对象标为待考，不进入开局事实层。

### 2.4 四座城门名称的处理

现有二手网络文章转述《嘉靖沛县志》记载四座城门楼及其名称、匾额，但该文章并非原志影印或校勘本，且四门对应的是1543年筑土城后的城防语境。

处理规则：
- 不将永清门、会原门、恒休门、拱极门及其匾额写入1523年开局地图。
- 可把这组信息留在“嘉靖二十二年（1543）城防资料待核”条目。
- 必须取得原志县市图/县治图和建置志原文后，才能确认门名、位置及其对应关系。

## 3. 1523年空间底稿：当前可锁定与不可锁定

### 3.1 可锁定的空间关系

| 节点/关系 | 当前结论 | 状态 |
|---|---|---|
| 行政关系 | 南直隶徐州直隶州—沛县 | 已由《嘉靖南畿志》支持 |
| 沛县旧城 | 嘉靖时期旧城已废；不能假定1523年已有1543年土城 | 已锁定年代边界 |
| 县署 | 县级行政机构仍在；“城墙已废”不等于县署不存在 | 已锁定功能存在，精确坐标待核 |
| 1543县治图 | 反映筑土城、迁儒学等变化后的空间快照 | 禁止直接套用1523 |
| 运河受淹区段 | 沛县以南湖陵城至黄家八闸 | 嘉靖二年《明实录》直接记载 |
| 河务/闸务处置 | 沽头主事及各闸官吏暂革；每闸留夫十名看守 | 嘉靖二年《明实录》直接记载 |
| 1523精确决口口门 | 现有直接记录未提供 | 待考 |
| 1523八闸逐闸名录与坐标 | 现有直接记录未提供 | 待考 |
| 1523乡镇、村庄与渡口完整名单 | 1543志书有相关门类，但尚未逐条核原文与年代 | 待考 |

### 3.2 县治设施的施工过滤

当前不把1543年县治图上的设施自动复制到1523年。逐项采取以下判断：

- **县署**：县级官署存在可确认；旧址和院落布局仍需查明。
- **儒学**：1542年有迁建记录；必须找迁建前位置与嘉靖二年状态。
- **土城/城门**：1543年筑土城，1523年禁用其城防形态。
- **昭阳湖围堤**：1542年筑堤，1523年禁用该堤防。
- **沽头城**：1543年冬建成，1523年禁用。
- **砖城**：1547年建成，1523年禁用。
- **仓储、驿站、递运所、桥渡**：需逐项核始建、迁建和裁撤时间，不因其在1543年志书出现就认定1523年存在。

## 4. 对M1开局事件与玩法的直接影响

本节是内容设计建议，不是新增规则。

### 4.1 允许进入开局的事件事实

- 1523年十月，沛县以南湖陵城至黄家八闸一段闸区受黄水侵入并被淹。
- 漕运部门需要重新安排闸务人员和看守力量。
- 河患已经影响漕运行政决策，不应只表现为县境内农田积水。
- 县令可能接触到灾情报告、漕运催办、地方运输受阻、闸务留守与民生压力等不同来源的信息。

### 4.2 不得预设玩家县令的权限

《明实录》这条记录是户部会议漕运事项，并不授权沛县知县独立处置整段漕运闸区。县令可以参与本县灾情查勘、民情安抚、地方秩序与协办事项；闸务人员裁革、漕运安排和跨县河工决策属于更高层级的制度链条，必须另查官制与具体差遣。

### 4.3 不得预写的结局

- 不预写整个运河完全断航。
- 不预写八闸全部毁坏。
- 不预写所有村庄受灾或人口流亡规模。
- 不预写县令已经决定某项河工工程。
- 不把嘉靖五年（1526）之后的水路变化和治理方案提前结算。

## 5. 本轮史料纠错记录

| 旧表述 | 修正后表述 | 原因 |
|---|---|---|
| “黄家八闸”缺少可靠史料支持 | 嘉靖二年《明实录》已出现“湖陵城至黄家八闸” | 找到当年官修实录直接记录 |
| 1543年《嘉靖沛县志》地图可作为1523空间复原底图 | 1543地图为嘉靖中期快照，必须先过滤1542—1543年新增/迁建设施 | 1542年迁儒学、筑湖堤；1543年筑土城 |
| 县城旧城已废，因此县治不存在 | 旧城废弃不等于县级官署不存在 | 区分城防与行政机构 |
| 1543年地图上的城门可直接进入开局 | 城门属于筑土城后的城防语境，1523年禁用 | 年代不符 |

## 6. 下一批原始材料的实际核验顺序

不再泛泛列研究方向，下一批逐项处理：

1. **先核1543年原志卷二《建置志》**：县署、公署、学校、置邮、桥梁、堰、堤、津渡；为每个条目建立始建/迁建/修复/裁撤时间。
2. **同步核卷一《舆地志》**：乡镇、疆域、山川、湖泉；地名逐一标注首次出现年代及是否能证明1523年存在。
3. **核卷三《田赋志》**：户口、徭役、地亩、贡赋、驿传、课程；不将1543年数字直接作为1523年数字。
4. **核卷四与卷九**：官制、仕宦、闸官、驿丞、大使、灾祥；优先确认嘉靖二年知县与实际闸务交接。
5. **核原刻五幅地图**：逐图记录图上文字和空间实体；所有1523年未证实的内容维持待考。

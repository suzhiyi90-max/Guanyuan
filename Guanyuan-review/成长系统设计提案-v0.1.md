## 零、一句话与立场

**成长不是「角色变强」，是「我在这世上攒下了什么、能调动什么、留下了什么」。**

人物系统已把成长钉成「关系/债/风评/履历/执行条件的积累」（能力极难改变）。本提案给这套积累一个**统一的成长模型**：五条轴、一套 earned-only 机制、一条慢反馈循环、一个可继承的终点。它不新增平行养成系统，而是宏观人生层在统一人物/事件模型上的投影（P-12/P-21）。

成长公式（接自由度公式）：

```
成长 = 执行条件改善 × 关系资本 × 履历与名望 × 可打出的手段 × 可继承的遗产
```

每一项都必须：**有事件来源、有上限与代价、可解释、可被翻出、可继承**。

## 一、定位与边界

### 1.1 成长是什么

| 是 | 不是 |
|---|---|
| 长期改善 10.1 的投入度/资源/阻力 | 把能力值从 0 刷到 5 |
| 积累关系、债、门生、风评、履历 | 经验条/等级/每日打卡 |
| 挣得可打出的手段（政令牌）与机会 | 抽卡/付费强度/集齐换数值 |
| 升迁换更大的权力与更深的盲区 | 升迁=纯奖励、无代价 |
| 失败后换座位继续积累 | 失败=读档重来 |
| 留下可被下一代引用的遗产 | 转生刷点/数值碾压 |

### 1.2 与三层的关系

- **宏观人生**：成长的主战场——Goal/名望/仕途/Legacy；尺度章/季/任/生涯。
- **中观策略**：成长的兑现——Case/政令牌/机会；尺度日/章/季。
- **微观行动**：成长的来源——八动词/文书/证据/接触；尺度时段。

**成长不另起一套玩法**：微观行动产生事件 → 事件积累宏观资本 → 资本改变中观可选项 → 回到微观。三层同源（P-21）。

### 1.3 硬约束（与总纲/人物提案一致）

离散优于连续 · earned-only · 能力极难改变（+1–2 封顶）· 不抽卡/不内购/不数值堆叠 · 失败可恢复 · 继承非数值 · 行状优先 · B+ 时间 · 统一结算顺序 · 一切留痕。

## 三、成长五轴

> 每轴：积累什么 / 怎么涨 / 上限与代价 / 直观爽感 / 人物属性映射。所有变化走事件流。

### 3.1 能力轴（才干）

- **积累**：某项能力的师承进度、历练熟练度、著述固化。
- **怎么涨**：师承受教 / 历练复盘 / 著述讲学 / 稀有顿悟事件（人物提案第四节）。
- **上限与代价**：能力 0–5，**单项一生 +1–2 封顶**；耗时/人情/束脩/身体；老病衰退（发挥下降，非值下降）。
- **直观爽感**：能力称号阶梯（生疏→大家）+ 评语（「河工大家」）。
- **映射**：`capability`；主要改善 10.1 的投入度/阻力，而非只抬名义能力。

### 3.2 仕途轴（位与望）

- **积累**：实迹、考语、名望、推荐人、资格、空缺时机。
- **怎么涨**：办成事 → 考语（7.2）→ 进入视野 → 推荐（7.3）→ 候选竞争（7.4）→ 空缺事件 → 任命。
- **上限与代价**：升迁**换一套失真**（品级提案：权力↑、直接经验↓）；推荐消耗上司政治资本→人情债；卓异有定额。
- **直观爽感**：官阶印绶、名望刻度（无名→天下知名）、考语被引用、「巡抚记住了你的名字」。
- **映射**：`office`、`reputation`、Opportunity（7.7）；名望是派生量（人物提案 3.4）。

### 3.3 关系轴（人与债）

- **积累**：认可/信任/惧/欠、人情债、门生故吏、派系位置。
- **怎么涨**：八动词留痕（4.5）、共事、保举、履约、施压；债自动传播（4.3）。
- **上限与代价**：情分按季衰减（4.4）；债不衰减但可被索取；把柄用一次少一次、会反噬；雨露均沾则谁都不全力。
- **直观爽感**：关系网图、筹码手牌、「他肯为你担风险」、门生故吏遍天下。
- **映射**：`bonds`、Debt/Secret/Hook；债可转移给子侄门生（4.3）。

### 3.4 世俗轴（家与身）

- **积累**：私囊、家业、置产、收藏、身体、风评、家人。
- **怎么涨**：俸禄/养廉/馈赠/置产（M2/M3）；节制养身；赈济/诗文养望。
- **上限与代价**：体面线（消费与收入相称）；奢名/贪名→被参/抄没；酒色熬夜→身体；家人外溢惹祸。
- **直观爽感**：五本账可视化、家业扩张、风评印章组合、收藏（人物提案第五节）。
- **映射**：五本生活账（11.1）、`state`、`reputation`；贪腐链长尾（11.8）。

### 3.5 继承轴（身后与来世）

- **积累**：家族、门生、著作、碑记、口碑、旧案（Legacy）。
- **怎么涨**：一生事件沉淀；致仕/丁忧/革职/死亡触发继承（12.5）。
- **上限与代价**：继承的是**关系/债/秘密/风评/行状/著作/旧案，不是数值**；上一代的恩仇成为下一代的处境。
- **直观爽感**：「你父亲当年保过的人，如今是你的上司」；著作被后世引用；碑记/谥号。
- **映射**：Legacy（12.5）、家学/前缘（7.7，M3）、行状（16）。

## 四、成长机制（earned-only · 慢反馈）

### 4.1 积累对象（候选，挂事件流，不新增平行系统）

| 对象 | 字段（最小） | 来源 | 消耗/兑现 |
|---|---|---|---|
| **Mentorship 师承** | actor, mentor, capability, progress, sessions, cost | 拜师/受教事件 | 进度满 → 能力 +1（封顶）/ 解锁手段 |
| **Practice 历练** | actor, domain, reps, lessons, proficiency | 办事+复盘事件 | 熟练度↑ → 投入度↑/阻力↓；失败给教训 |
| **Writing 著述** | actor, title, basisEvents, status, readers | 著书/讲学事件 | 固化能力/风评/门生/政令牌灵感 |
| **Means 手段** | actor, token, source, validUntil, prereq | 幕友/考语/关系/事件/著作 | 打出 → 执行 Case（10.7） |
| **Renown 名望** | actor, tier, basisEvents | 风评+实迹+关系派生 | 影响机会/婚嫁/借贷；可升可降 |
| **Legacy 遗产** | actor, kind(家族/门生/著作/碑记/口碑/旧案), refs | 一生事件沉淀 | 继承时被引用（12.5） |

**约束**：这些对象都是**事件流的投影/累计**，不是独立刷的数值；无来源事件不变化；M0 通过前不作正式 schema。

### 4.2 慢反馈循环

```
微观行动（八动词/文书/接触）
   ↓ 规则结算（10.6 统一顺序）
事件（办成/办砸/拒礼/被参/举荐……）
   ↓ 积累
能力倾向 · 关系/债 · 履历/名望 · 手段 · 家业 · 身体
   ↓ 投影（人物面板/行状/图鉴）
称号 · 里程碑 · 筹码 · 名望刻度 · 收藏
   ↓ 兑现
机会（7.7）· 政令牌（10.7）· 升迁（7.4）· 继承（12.5）
   ↓ 调整
Goal 坚持 / 转向 / 放弃 / 失败 → 下一轮
```

**爽点在「兑现」与「被看见」**，不在中间数值跳动；延迟反馈是设计意图（自由度公式）。

### 4.3 失败如何转化为成长

- 失败不是清零：办砸留下「教训」（降低同类阻力）、留下债/把柄/风评、留下行状。
- 溃口/被参 → 退路（幕友/乡绅/教读/商/归隐，12.5）→ **换一种资本继续积累**（幕友攒人脉/教读攒门生著作/乡绅攒族产声望）。
- 责任共担（6.6）让失败可解释、可分担，不是单纯惩罚。
- **成长包含「如何失败」**：清名因揭弊被孤立也是一种被记住的人生。

### 4.4 衰退与上限（防膨胀）

- 能力单项 +1–2 封顶；老病衰退（发挥下降）。
- 情分按季衰减；名望可降；升迁换盲；家业可抄没。
- 手段有时限、每章/季 1–2 张；不是永久 buff 堆叠。
- **没有无限成长**：一生有天花板，终点是 Legacy 而非满级。

## 九、验收判据（可测）

| 项 | 判据 |
|---|---|
| 成长可解释 | 抽查 10 次成长变化，100% 有来源事件 |
| 成长可追踪 | 玩家能说出「我这任攒下了什么」（≥3 项，跨轴） |
| 有代价 | 每项成长能说出代价/上限；无免费成长 |
| 不刷 | 重复交谈/办事 100 次，能力/名望不自动上涨 |
| 爽感可指认 | ≥2/3 玩家指认一项称号/里程碑/手段/遗产并感到「攒出来的」 |
| 失败可继续 | 溃口/被参后 ≥1 退路可继续积累（非重试） |
| 可继承 | 遗产能被下一任/下一代引用（M3 纸面） |
| 升迁有失去 | 玩家能说出升一级失去了什么（直接经验/盲区） |
| 无 AI 可玩 | 成长反馈/称号/行状模板兜底 |

## 十一、风险与设计债

| 风险 | 症状 | 缓解 |
|---|---|---|
| **成长变刷级** | 盯进度条刷 | 离散+封顶+主要改执行条件；慢反馈 |
| **五轴变五套系统** | 各自独立养成 | 统一事件流投影；P-12/P-21 |
| **手段堆叠碾压** | 政令牌永久 buff | 时限+每章 1–2+不替代权限 |
| **继承变数值转生** | 下一代碾压 | 继承关系/债/著作/旧案，非数值 |
| **升迁无代价** | 纯权力幻想 | 换盲+人情债+卓异定额 |
| **反馈太延迟** | 玩家无感 | 里程碑/称号即时可见；长尾延迟 |
| **M1 过载** | 提前铺成长 | H7 后再扩；M1 只薄片 |

**设计债（v0.1）：**
1. 师承/历练进度曲线未定（+1 投入量）。
2. 名望派生公式与阈值未定。
3. 历练「改执行条件」的具体权重未定（投入度/阻力）。
4. 政令牌与师承/著作的解锁联结未定（M2）。
5. 五轴成长的 UI 成长页未设计（通过后同步前端）。
6. 继承的跨局引用规则未定（M3）。
7. 退路各自的资本积累玩法未细化（M2/M3）。

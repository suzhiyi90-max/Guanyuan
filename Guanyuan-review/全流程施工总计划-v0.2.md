## 2. 设计权威与施工纪律（不可破坏）

1. 权威层级：总纲 v0.16 > 专项规范/契约（未冻结者为候选）> 治理矩阵/裁决登记 > 台账/计划。冲突以总纲为准；候选不得误写为已批准。
2. 三层信息隔离：A 客观事实（EventStream 唯一权威）/ B 人物认知（holder 隔离）/ C 玩家可见（只读投影）。Projection 零写入；组件不 import 领域写路径；UI 不成为第二权威。
3. AI 边界：候选→确定性校验→回执→事件账本提交；未校验候选零写入；rejected 终态不产生 Event；叙事只读结算结果与观察者可知信息。
4. 引擎保护：不重写已验收的账本/genesis replay/原子投影/存档恢复基线（PR #81 红线）；W5 退壳适配仅限 import 路径与投影接线，数值零改。
5. 存档：guanyuan.save.v1 不读不写不删（原型档保留导出路径）；正式键 guanyuan-world-saves（已申报）；新增字段前必须先定权威对象/唯一写入者/生命周期/来源事件/时间语义/回放/迁移。
6. 美术：正式资产由**用户生成**；Agent 只提交资源清单＋完整生图提示词；不代码绘图/占位图冒充；沿用资产清单/hash/署名/fallback/截图验收（FE-169 流程）。
7. 分支纪律：独立分支、小范围可回滚、Draft PR 默认、未经用户授权不合并、不直推 main/feat/g1-engine、不覆盖本地未提交工作、不 reset --hard/clean -fd。
8. 测试纪律：真实命令＋退出码＋摘要；不为凑数加无价值测试；不以延长等待掩盖竞态；区分产品缺陷与测试脚本假失败。
9. 视觉纪律：不重设计现有页面、不降完成度、不改既定动效/布局/材质/层级；不留调试元素；三档 1440/1024/390 无溢出、焦点/触控/减少动效/print/fallback 回归。
10. 历史纪律：嘉靖二年方向（待 DEC-P1-01 批准）；不虚构县名/区划；不清制明用；不自创经济参数；未证实人物关系不写成事实。

## 8. 风险与处置

| 风险 | 处置 |
|---|---|
| 堆叠栈过深（~70 PR）合并冲突/验收疲劳 | 逐层小步合并＋每层 CI；必要时按域重组堆叠（owner 批准） |

| CI dev-server 依赖误用 preview 假失败 |  smoke 一律 dev server；文档写明 |
| 备案滞后于代码 | 五处备案随 PR 同交；check:docs 门禁 |
| 历史坐标未批准即建模 | DEC-P1-01 批准前只做研究/提案，不写制度代码 |

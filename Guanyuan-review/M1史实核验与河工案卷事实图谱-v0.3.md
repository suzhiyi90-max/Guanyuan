**M1 的七个人不是七个角色，是七个职位/身份；河工案不是一桩“谁偷了钱”的案子，是“同一个 300 两的窟窿在四本账上写法不同”的案子。** 先把这句话落地，品级与权力距离才有地基。

**要点：**

1. **知县是“兼管”，不是“专管”。** 沿河州县知县兼管河务，但专管是河厅同知/通判/州同/州判/县丞/主簿；“地方守令无兼河之责者不应办理河务”。这决定了知县可以办事，但不能独自定河工性质。
2. **县丞、主簿不是每县都有。** 多数县不设县丞、主簿；M1 若同时设两者，等于选了一个“佐贰齐全”的县，需在背景里说明，不能当作全国通例。
3. **书办是吏，不是官。** 不能标“未入流”；未入流是典史、驿丞等官的地位。书办应标“无品（书吏）”。
4. **“河工专家”不是官职。** 他只能是幕友、河厅差委的书办/效力人员，或河营武弁；这决定了他没有法定调度权，只能建议。若用“河厅差委书办”，必须写明他受河厅节制：他的技术判断可信，但他的立场不完全站在知县这边——这是 D2 信息距离的现成素材，不是 bug。

**读表注意：** “300 两”是 M1 的玩法定额（D），不是清代律例的普遍阈值；清代可查的硬界线是抢修/另案的 500 两（A/B）。“三日内补报”“十日内补报”等具体日数同样是 D：程序精神（先抢后报、事后补报）是 A/B，日数是为十日切片做的校准。不要把 D 当 A 写进设定集。

**四条硬边界：**

1. **知府不能批河工银。** 他能转详、加结、委员覆勘、揭报参处；批银在河厅/藩司。v0.4 6.2 已改，保留此条作为审查视角的底线。
2. **知县不能改委河厅汛员。** 河厅官员无地方之责，知县对他们“呼应不灵”；反之，河厅也不能直接调县的夫役。两边只能移会、详请、委员。
3. **“征发民夫”不是默认合法权限。** 康熙以后以雇募、河兵、堡夫为主；“征发”只能作为越权/苛派动作存在，不能写成常规四元组。v0.4 6.2 已改。
4. **十日窗口内，拆修不可能完工。** 拆修闸底需 10 日（C-002），洪水第 9 日到；且拆修要另案、估册、委员覆勘、河厅/藩司批，程序时间还未计入。**十日内唯一可行的工程动作是抢护**（临河截渗、抛石、埽工、帮戗），先把这一汛顶过去；拆修是汛后长尾。若叙事让玩家“十日拆修成功”，规则就假了。

**由第 4 条推出的叙事骨架：** 玩家识破闸底淘空，不等于能修好；识破改变的是**工法**（表面修补 → 抢护 + 报险 + 汛后另案），不是工期。表面修补省 300 两、3 日，第 9 日溃口；抢护花 8–10 垛、30–50 夫、3–4 日，能顶过第 9 日，但闸底仍在，必须报险并背汛后另案。**“看对了却修不完”才是 M1 的真实压力。**

**M1 的三个数字（v0.4 11.6 口径）：**

```
账面 4,500 两  —— 估册/领状上写的
实收 4,200 两  —— 河工专账/库房实际入账
报部 待定      —— 题销时二选一：4,500（做平，称运输损耗）或 4,200（自曝，承认 300 缺口）
```

**差额 300 两**是账面与实收的差，也是主簿领出、垫付上年夫役工食的那一笔；它不是第三个“数字”，而是三数之间必须解释的缺口。

**一笔 300，四本账：**

| 账 | 谁持有 | 怎么写的 | 这笔钱的真实位置 | 性质 |
|---|---|---|---|---|
| **河工账** | 主簿/库房 | 4,500 领出，300 记“运输损耗” | 已出库，无运输凭证 | 假科目，掩盖支出 |
| **主簿借领状** | 主簿 | 领 300，垫付上年夫役工食 | 已付夫役 | 真用途，程序有瑕 |
| **粮商旧欠票据** | 粮商 | 上年 20 垛料价尾欠 300（15 两/垛） | 未付粮商 | 真负债，未清 |
| **茶楼传闻** | 士绅/茶楼 | “县太爷挪去修衙署” | 无对应支出 | 假传闻，无文书 |

**为什么不是 600：** 4,500 两估册里只有**一笔** 300 两的旧欠额度；它本来要还粮商，主簿却先垫了上年夫役工食。于是夫役拿了这 300，粮商没拿到；县里只留下**一个** 300 的窟窿（粮商的债权），不是“运输损耗 300 + 旧欠 300 = 600”。玩家若把两笔都记成要补的现金，就会凭空造出第二笔 300——这是本案最容易犯的账法错误，也是主簿最希望玩家犯的错。

**报部口径是第二次选择：** 第 10 日先定题销口径：报 4,500 可以把账做平，但“运输损耗”要有凭证，且粮商的旧欠仍在地下；报 4,200 等于自曝 300 缺口，知府必须处理，但知县可能得一个“不欺”的考语。**做平与自曝，都有代价；不能两全。** 正式题销册走程序，是 M1 之后的长尾。

**置信度：** 四本账的“写法”（运输损耗、借领、旧欠、流摊）是 B（州县账法与陋规）；“4,500 里夹一笔 300 旧欠额度”是 D（为 M1 校准的设定），不要当成则例条文。史实能支撑的是“州县会用假科目、旧欠、流摊把窟窿挪来挪去”，不是“必须恰好 300”。

**规则：** 同一笔钱必须能在至少两本文书里找到；否则它就是孤证，不能作为定案依据。四本账里，河工账、借领状、旧欠票据三本文书必须能互相对上；对不上，就是新证据。

**流转规则：**

1. **详文不能越级。** 知县详知府，不能直接详督抚；要越级，只能用禀帖或密折（M1 不做密折）。
2. **有详必有批。** 批语是证据；批后详文发回，详册留上司。
3. **禀帖不能代替详文。** 公事应候批者，不得以禀代详；但禀帖可以更快、更私密，也更留把柄。
4. **每份文书要有副本与持有人。** 没有副本的文书，在冲突时不算证据。
5. **签押/用印/骑缝/挂号。** 谁签、谁用印、谁挂号，决定谁担责。

**考语的两层：**

```
公开格式：守 / 才 / 政 / 年 + 实迹（+ 六法，如不合格）
生成权重（四维核心 + 三调节）：
  核心：能力认可 / 绩效评价 / 私人信任 / 政治可靠性
  调节：提携意愿 / 实际影响力 / 风险与成本
映射：守←政治可靠性+私人信任（廉洁守约）；才←能力认可；政←绩效评价；
      年←人物年龄与任职年限（硬数据，不参与关系打分）
```

**M1 的正确说法：** 第十日上司来巡，写下的是**一次场景考语/密考**，不是大计。大计是三年时钟（寅巳申亥），不能塞进十日切片。v0.4 7.2、20.2 #5 已吸收这套双层模型；本节保留作为措辞库、六法口径与判据。

**考语的可玩性不在“打分”，在“引用”。** 一句“勤勉，然调度未纯”会在三年后挡掉一次题补；一句“才具尚可，河工未固”会在保固期内被翻出来。M1 只需让玩家看到这句话如何从事实、关系、风险三个来源生成，并留下可被引用的记录，不需要做完整的京察/大计系统。

### 2.9 数据结构与事件卡改造

这套 schema 不是为了写代码，是为了让策划、程序、叙事三方用同一组 ID 说话。**没有 ID 的内容，不进事件卡；没有证据的事实，不进 F；没有来源的认知，不进 K。**

#### 2.9.1 五层类型

```ts
type FactId = `F-${string}`;
type ClaimId = `P-${string}`;
type EvidenceId = `E-${string}`;
type PersonId = `p_${string}`;
type DocId = `V-${string}`;
type ConsequenceId = `C-${string}`;

type Confidence = 'certain' | 'believed' | 'heard' | 'doubted';
type Secrecy = 'public' | 'internal' | 'secret';
type M1Tier = 'core' | 'optional' | 'deferred';

interface Fact {
  id: FactId;
  subject: string;
  predicate: string;
  value: unknown;
  unit?: string;
  validFrom: string;
  validTo?: string;
  secrecy: Secrecy;
  evidence: EvidenceId[];      // 至少一条；否则不是 F
  m1: M1Tier;
}

interface Claim {
  id: ClaimId;
  factId?: FactId;             // 指向它声称的事实；可无
  text: string;
  truth: 'true' | 'false' | 'partial' | 'unverifiable';
  speaker: PersonId;
  motive: string;
  evidence: EvidenceId[];
}

interface Evidence {
  id: EvidenceId;
  kind: 'document' | 'physical' | 'testimony' | 'observation' | 'record';
  holder: PersonId | 'archive' | 'site';
  supports: Array<FactId | ClaimId>;
  reliability: 1 | 2 | 3;      // 1 硬证 / 2 旁证 / 3 口传
  cost: { time: number; silver?: number; risk?: string };
  forgeable: boolean;
}

interface Knowledge {
  person: PersonId;
  target: FactId | ClaimId;
  state: 'knows' | 'believes' | 'suspects' | 'unaware' | 'deceived';
  source: 'observed' | 'told' | 'document' | 'inferred' | 'rumor';
  confidence: Confidence;
  acquiredAt: string;
  secrecy: Secrecy;
}

interface DocumentVersion {
  id: DocId;
  type: string;
  author: PersonId;
  recipient: PersonId | 'yamen' | 'ministry';
  date: string;
  asserts: Array<{
    target: FactId | ClaimId;
    mode: 'assert' | 'omit' | 'soften' | 'shift' | 'forge';
  }>;
  signature: 'signed' | 'sealed' | 'countersigned' | 'none';
  copies: number;
  status: 'draft' | 'reviewed' | 'dispatched' | 'received' | 'returned' | 'archived';
  derivedFrom?: DocId;
}

interface Consequence {
  id: ConsequenceId;
  trigger: FactId | ClaimId | DocId;
  rule: string;
  effects: Array<{ target: string; delta: number | string; visible: boolean }>;
  delay?: string;
  m1: M1Tier;
}
```

**例外：** 场景元事实（F-015 十日/汛期）允许以设计单为来源，但必须标 `m1: 'core'`，且不进 NPC 对话；它不是世界内的 F，不能被人物“知道”。其余 F 至少一条 E，否则降为 P 或传闻。

| I-09 | 工程：拆修跨汛；十日内只能抢护；保固按工段 | 出现“十日拆修成功”的假路径 |
| I-10 | 传闻：无文书证据的说法不进 F，只进 P/K | 谣言被当成事实 |
| I-11 | 定性：挪移 vs 侵欺由上级定；知县只能揭报 | 知县越权定罪 |
| I-12 | 报部：题销只能选 4,500 或 4,200；不能两个都报 | 账实两头骗，系统无法结算 |

#### 2.9.4 AI 合同

1. **AI 不改世界状态。** 它只读 F/E/K/V/C，生成对话、考语、行状与批语。
2. **每句事实性文本必须带 ID 或标注“传闻/推测”。** 例：“账上写的是运输损耗（E-001）”，不能凭空说“主簿贪了三百”。
3. **NPC 只能说自己 K 里的内容。** 不知道的 F，不能“随口说中”；可以说错，但错信要有来源。
4. **文书生成必须带版本。** 同一份详文，草稿、定稿、批后发回是三个 V；AI 不能把批语混进原文。
5. **行状只引用已发生的事件与承诺。** 不预测、不虚构、不替玩家总结未做的事。

#### 2.9.5 结算顺序

```
玩家行动 → 权限/程序判定 → 事实变化（F）→ 新证据（E）→ 认知更新（K）
→ 文书生成/流转（V）→ 后果结算（C）→ 不变量校验（I-01..I-12）→ 三行日志/情报台账
```

**校验失败不回滚叙事，只标红。** 策划能看到哪条不变量被违反；玩家看到的是“账对不上/话对不上”的症状，而不是系统报错。

### 3.2 上级审查视角：知府能做什么

| 动作 | 他能做什么 | 他不能做什么 | 对县级的实际影响 | 史实依据 |

| **批驳** | 准/驳/查/饬/存；批语入卷 | 不能直接拨河工银 | 决定知县能否按原方案动工 | 详文有详必有批；知府不掌河库 |

**知府的三条边界：**

1. **有否决权，没有解决权。** 他能驳、能查、能参，但不能批银、不能替知县募夫、不能改委河厅。
2. **有记录权，没有终局权。** 考语入册，但大计要督抚注考；揭参要督抚/吏部。
3. **有自己的考成。** 他压案不是因为坏，是因为大计将届；这让他既可被说服，也可被要挟。

### 3.3 权力距离是否带来新决策

| 距离 | 新增动作 | 改变什么结果 | 若删除会失去什么 | M1 |
|---|---|---|---|---|
| **D1 亲证** | 亲查、亲问、探挖、私访 | 事实认定（闸底/料数/300） | 只能听口报，识破不成立 | 启用 |
| **D2 转呈** | 批驳、委员覆勘、调卷、传询、考语、揭参 | 工期、料源、定性、责任、考语 | 县级没有上级约束，考语变旁白 | 启用 |

**判据：** 若上级视角只增加 3 份文书、0 个新动作类型，则砍掉；若新增 ≥3 个能改变县级结果的动作类型，则保留。知府有五类（批驳/覆勘/调卷传询/考语/揭参），**通过**。

**但“动作类型”不等于“权力杠杆”。** 一个上级动作只有在改变县级的钱、人、料、工期、定性、责任或考语时，才算真决策；否则只是阅读量。按杠杆拆，知府实际握有五类：

| 杠杆 | 知府怎么用 | 改变县级哪个变量 | 玩家可观测 | 若删除会失去什么 |
|---|---|---|---|---|
| **定性权** | 批驳、覆勘，定官堤/民堤、成灾/不成灾 | 经费来源、是否另案、考成 | 批语、勘语 | 只能按县报，河厅不认 |
| **验勘权** | 委员覆勘、调卷、传询 | 事实认定（闸底/料数/300） | 勘语、口供、调卷清单 | 知县自说自话，识破不成立 |
| **人事调度权** | 委员、传询、记过、调委 | 谁办、办多久、能否换人 | 札、委牌、传询票 | 错的人继续办，换不掉 |
| **钱粮转圜权** | 转详、加结、驳、催 | 能否另案、何时拨、谁先垫 | 批、札、拨银札 | 钱只能县里找，另案无门 |
| **记录权/风险分配** | 考语、揭参、压案 | 后果由谁担、参还是弥缝 | 考语、揭参稿、批语 | 失败无长尾，十日结束就结束 |

**阅读量税（必须量化，防止“权力距离=多读公文”）：**

1. 计量单位不是“文书份数”，是**改变结果的决策数**。
2. 每增加一级，必须新增 ≥3 个能改变县级结果的动作类型；否则砍。
3. 每个动作至少改变一个可观测变量：钱、人、料、工期、定性、责任、考语。只产出文本、不改变变量的，记为“阅读税”，不计入验证。
4. 单次审查新增阅读 ≤2 页 / ≤400 字；超过则合并为一条批语或一份札，不另发文书。
5. M1 实测：覆勘/调卷改变事实；批驳改变工期/方案；考语改变仕途起点；揭参改变责任。**至少两类必须在一次试玩中真实触发**，否则上级视角不通过。

**但要注意：** 这五类里，只有“委员覆勘”和“调卷传询”直接改变事实认定；“批驳”改变程序，“考语/揭参”改变后果。若 M1 只做“批/驳”而不做“覆勘/调卷”，上级视角就会退化成阅读量。**M1 至少要让玩家触发一次覆勘或调卷。**

| **R-14** | 7.2 / 20.2 #5 | 7.2 列了七项生成权重（能力认可、绩效、私人信任、政治可靠性、提携意愿、影响力、风险成本），20.2 #5 却写“四维生成权重” | 收成“四维核心 + 三调节”：核心=能力认可/绩效评价/私人信任/政治可靠性；调节=提携意愿/实际影响力/风险与成本。措辞统一，别让“四维”与七项打架 |

### 4.4 不建议再改的（边界）

1. **河厅差委书办的人设不换。** 他的双重忠诚是特性，不是漏洞；换掉就少了一层 D2 失真。
2. **300 两限额保留，但标 D。** 不要为了“更史实”改成 500；500 是抢修/另案界，不是知县支取权界。
3. **揭参保留，揭帖冻结。** 两者不是一件事；不要因为“M1 不做揭帖”而砍掉审查视角的揭参。
4. **题销只给两个选项。** 4,500 做平或 4,200 自曝；不要再加“报 4,300”这种中间态，否则账法失去锋芒。
5. **四本账不扩成五本。** 第五本账（例如“幕友的私记”）可以作 DLC，不进 M1；M1 的识破必须收敛在一个 300 上。

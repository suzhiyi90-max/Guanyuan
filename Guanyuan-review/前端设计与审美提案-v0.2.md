## 零、一句话结论

**玩家看到的不是「古风界面」，是一张会被签押、传阅、抄没的纸。**

界面由三层组成：

- **案卷层：** 你正在办什么事，证据是什么，谁签了字。
- **人情层：** 谁在说、谁在骗、谁欠谁、谁握着谁。
- **生活层：** 这顿饭、这份礼、这个家人，花了多少、留下什么。

五条审美原则：

1. **纸优先于框。** 用纸面、界格、墨线组织信息，不用玻璃拟态、霓虹、黑金大卡片。
2. **字优先于图。** 先保证中文长文本可读，再谈插画与动效。
3. **印优先于色。** 朱砂只给印、批、危险与关键状态；不拿红色铺满屏。
4. **留白优先于装饰。** 官场不是影楼；空的地方是压力，不是待填的图。
5. **后果优先于动效。** 每个界面时刻都要能回答「我改了什么、谁记住了」，动画不改变业务状态。

## 一、目标与非目标

### 1.1 目标

| 目标 | 可测标准 |
|---|---|
| **3 秒读懂** | 玩家进入任一主屏，3 秒内能说出「现在什么时辰、本时段还能做什么、我最该处理什么、眼前这人想要什么」 |
| **时间可信** | 玩家能说出「本时段做了什么、下一个时段何时开始、长动作哪天完成」；界面不出现行动点计数 |
| **文书即玩法** | 玩家能在 20 秒内从一份呈文/账册里找出 4,500/4,200/300 中至少两个数，并指出一处矛盾 |
| **权力距离可见** | 委托预览能显示「合法/缺什么/需谁批」，玩家能说出「为什么我不能直接办」 |
| **世俗有代价** | 礼簿/夜场景的每个选择都显示至少两本账的变化影子（不直接给数值答案） |
| **志向可回看** | 章首定的目标在章末能逐条对账：做到/没做到/改变了什么；失败有退路，不是 GAME OVER |
| **移动端可读** | 390px 宽无横向滚动；正文 ≥16px；长文有横排释文 |
| **无 AI 可玩** | 关闭模型服务后，主流程与模板文本仍可完成 |
| **可访问** | WCAG 2.1 AA；键盘可操作；200% 字号不破版；状态不靠颜色单独表达 |

### 1.2 非目标

- 不做 3D 开放世界、自由行走到每个房间；场景用 2D 背景 + 人物卡 + 文书层。
- 不做卡牌抽卡/稀有度；人物卡不是收集品，官阶不等于精美度。
- 不做「黑金 + 金龙 + 红灯笼」的官场爽游视觉；不做日式江户/民国上海混搭。
- 不做纯数据仪表盘；账目用账册与对照，不用折线图堆满屏。
- 不做后宫收集、性内容、独立生活小游戏。
- 不把 AI 文案当事实；AI 只做表达层，UI 不读世界真相。

- **总纲是唯一规则源；本文件是 UI 投影。** 任何冲突，以总纲已批准条款为准。

## 三、审美命题

### 3.1 州县不是宫殿

本作是**架空晚清州县**，不是皇宫、不是王府、不是江湖门派。

- 空间：衙署、签押房、库房、宅院、街市、茶馆、戏园、当铺、码头、寺观、书院、河堤。
- 物件：案、椅、屏、书架、灯、轿、算盘、秤、斗、仓、封筒、拜帖、礼单、账册、朱印、笔架。
- 不要：金龙、凤纹、黄瓦、龙椅、太监、后宫、锦衣卫、飞鱼服、日式障子门、民国霓虹。
- 气质：**克制、旧、有人用过**；纸有折痕，桌有磨痕，印有缺口；不是全新渲染的“古风样板间”。

### 3.2 材质与色彩

**五种材质：** 纸、墨、朱印、木、布。

| 材质 | 用法 | 不要 |
|---|---|---|
| **纸** | 主背景、文书、卡片、礼簿 | 纯白、塑料光、玻璃拟态 |
| **墨** | 正文、线、界格、图标 | 纯黑大块、发光描边 |
| **朱印** | 印章、批语、危险、关键状态 | 大红铺底、红色按钮满屏 |
| **木** | 桌面、边框、导航底 | 高光木纹、红木土豪风 |
| **布** | 人物背景、屏风、包裹 | 花纹壁纸、绸缎渐变 |

**主色：**

- 纸：`#FBF7EE` / `#F3EBDD` / `#E8DCC6`
- 墨：`#1C1A17` / `#2E2A24` / `#5A5145`
- 朱砂：`#A33A2B`（印/批）；深朱 `#7E2A20`
- 黛蓝：`#2E4756`；青灰：`#778A7B`
- 暖金：`#B08A57`（只做少量分隔/重要节点，不做正文）
- 状态：警示 `#8A5A2B`、危险 `#8C2F2F`、通过 `#4F6B57`

**规则：**

1. 正文永远用墨色，不用彩色正文。
2. 朱砂只给印、批、危险、当前选中；一屏朱砂面积不超过 5%。
3. 暖金只做“时间/等级/重要节点”的细线或小字，不做大面积背景。
4. 状态不能只靠颜色：必须有文字/图标/纹理。
5. 深色模式不在 M1；如做，另立 high-contrast 纸墨方案，不简单反色。

### 3.3 参考与禁区

**可参考：** 清代州县公文、账册、函札、版刻、界格、骑缝印、签押、朱批、旧纸、墨迹、木器。

**不可照搬：** 故宫/皇家视觉、影视剧官场、日式江户、民国月份牌、现代极简到没有历史感、AI 生成的“古风大杂烩”。

**三条检查：**

- 这个物件在晚清州县会出现吗？
- 这个颜色/纹样有制度含义吗？没有就不要用。
- 去掉插画后，界面还像官场吗？如果不象，说明结构不对。

### 3.4 视觉层级

```
第一层：纸面/文书（我正在办的事）
第二层：人物与印（谁说的、谁签的、谁欠谁）
第三层：上下文/账目（为什么、代价是什么）
第四层：装饰（木纹、纸纹、远景）
```

**禁止：** 让装饰比文书更抢眼；让红色按钮比朱印更醒目；让人物立绘压过文字。

## 四、设计令牌（Design Tokens）

> 所有值都是提案；M1 先用最小集，M2 再扩。前端不得硬编码颜色/字号。

### 4.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--paper-0` | `#FBF7EE` | 主纸面 |
| `--paper-1` | `#F3EBDD` | 卡片/次级纸 |
| `--paper-2` | `#E8DCC6` | 按压/选中底 |
| `--paper-3` | `#D8C7A9` | 分隔/旧纸边 |
| `--ink-0` | `#1C1A17` | 正文/标题 |
| `--ink-1` | `#2E2A24` | 次级标题 |
| `--ink-2` | `#5A5145` | 辅助文字 |
| `--ink-3` | `#8A7E6C` | 禁用/水印 |
| `--cinnabar` | `#A33A2B` | 印章/批语/当前 |
| `--cinnabar-dark` | `#7E2A20` | 印章阴影/危险 |
| `--indigo` | `#2E4756` | 夜/远山/冷信息 |
| `--celadon` | `#778A7B` | 通过/平静 |
| `--gold` | `#B08A57` | 重要节点细线 |
| `--warning` | `#8A5A2B` | 警示 |
| `--danger` | `#8C2F2F` | 危险 |
| `--success` | `#4F6B57` | 完成 |

**对比度：** 正文 `--ink-0` on `--paper-0` ≥ 12:1；辅助 `--ink-2` ≥ 6:1；朱砂正文 ≥ 4.5:1；暖金只用于 ≥18px 或装饰。

### 4.2 字体

| Token | 字体 | 用途 | 许可 |
|---|---|---|---|
| `--font-doc` | 思源宋体 / Source Han Serif SC | 文书、标题、账册 | OFL，需确认打包 |
| `--font-ui` | 思源黑体 / Source Han Sans SC | UI 标签、按钮、表格 | OFL |
| `--font-letter` | 霞鹜文楷 / LXGW WenKai | 书信、批语、私信 | OFL，需确认 |

**字号（桌面/移动）：**

- 正文 16/28、16/26；文书 17/30；小字 13/20；标题 24/34；大标题 32/42。
- 中文正文每行 28–34 字；最大阅读宽度 680px；文书页 720px。
- 数字：UI 用等宽数字（`tabular-nums`）；文书用汉字数字；必要时提供“释文”对照。
- **最多三套字体**；不再加书法字体。禁止用未授权字库/系统“华文行楷”等做商用。

### 4.3 间距与栅格

- 8px 基准：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 桌面：左导航 88px；中栏 720–880px；右栏 320px；最大 1440px。
- 移动：左右 16px；卡片间距 12px；底部导航 64px。
- 圆角：2px（纸边）/ 4px（按钮）；不用 16px 大圆角卡片。
- 阴影：`0 1px 0 rgba(28,26,23,.08), 0 8px 24px rgba(28,26,23,.06)`；只做纸层，不做悬浮玻璃。

### 4.4 图标

- 24px 网格，1.5px 墨线；对象化：印、笔、账、封、灯、轿、秤、仓、门、书信、算盘、茶。
- 不用通用“齿轮/房子/心形”现代图标；不用彩色填充图标。
- 图标必须有文字标签；不靠图标单独表意。

### 5.1 五个一级入口与章节边界

**界面三层：** 案卷（公事）、人情（关系）、生活（世俗）。

3. **不出现死胡同**：空状态必须给下一步。
4. **不自动跳转**：事件暂停后由玩家选择；不抢焦点。
5. **不隐藏当前时间**：顶栏永远显示时段与最近期限；显示「本时段已用/未用」，**不显示行动点**。
6. **不隐藏志向**：章节内至少一个角标可回看当前 Goal；章末必须回到 S-14 对账。
7. **不假装全知**：接触记录只显示玩家可知的接触；未知显示「？」。

## 六、核心屏幕规格

### 6.1 S-01 今日案头

**目的：** 让玩家在 10 秒内知道“今天该先处理什么”。

```
┌──────────────────────────────────────────────┐
│ 第 3 日 · 暮 · 本时段已用  汛期 12 日  [志向印] │
│ 体面线：可见消费 ≈ 月入 60%  [详情]            │
├──────────────────────────────────────────────┤
│ 待决 3 件                                    │
│ □ 呈文：堤身渗水（书办）        [读] [问]     │
│ □ 粮商请见：旧欠 300          [见] [拒]     │
│ □ 士绅帖子：接风宴             [赴] [代]     │
├──────────────────────────────────────────────┤
│ 进行中：抢护 · 工头 · 第 4 日晨完成（占用 2 段）│
├──────────────────────────────────────────────┤
│ 今日三行                                     │
│ 办成：……                                     │
│ 卡在：……                                     │
│ 有人在传：……                                 │
├──────────────────────────────────────────────┤
│ [查账 0] [私访 1段] [写禀帖 1段] [回内宅] [结束今日]│
└──────────────────────────────────────────────┘
```

**组件：** C-02 时段条、C-04 待决卡、C-05 三行日志、C-08 权限/行动坞、C-15 体面线、C-21 志向印、C-22 长动作条。
**规则：** 待决不超过 5 件；超过则折叠为“其他”；不显示未接触的隐藏事件；**每段只有 1 个实质动作，0 费读取/寒暄不计；长动作占段并显示完成时段；界面任何位置都不出现「行动点」计数。**

### 6.2 S-02 案卷/文书

**目的：** 让文书成为玩法，而不是阅读障碍。

```
┌──────────────────────────────────────────────┐
│ 呈文 · 初稿         [对勘 V-002] [贴签] [记疑]│
├──────────────────────────────────────────────┤
│  某县为报事……                                │
│  ……堤身渗水四十步，请拨料抢修……              │
│  ……（界格/竖排，可切横排释文）                 │
│                                              │
│  [朱批] 委员覆勘，料价再核                    │
│  骑缝印 · 签押 · 三月十七                     │
├──────────────────────────────────────────────┤
│ 证据钉：E-001 账册 · E-007 探挖 · V-001 初稿  │
│ 疑点：呈文说“渗水”，探挖说“闸底淘空”          │
└──────────────────────────────────────────────┘
```

**三种视图：**

1. **原件：** 竖排、界格、朱批、印、签押；桌面默认。
2. **释文：** 横排、标点、可复制；移动默认，桌面可切。
3. **对勘：** 左右两版 V-001/V-002，差异高亮（删/改/留空），不自动判真假。

**规则：** 一页 ≤400 字；长文分页；证据钉可点开；不显示“真相”，只显示文本与证据。

### 6.3 S-03 人物/三问

```
┌──────────────────────────────────────────────┐
│ [肖像] 县丞 · 正八品 · 管河佐贰               │
│ 他想要：保河厅关系 / 不出事                   │
├──────────────────────────────────────────────┤
│ 能不能做？ 能协调，但不能定工法                │
│ 愿不愿做？ 愿，若你先报河厅                    │
│ 敢不敢做？ 不敢单独担责                        │
├──────────────────────────────────────────────┤
│ 债：你欠他 1（接风宴）                         │
│ 秘密：他知道县丞与士绅往来（未证实）           │
│ 接触：第2日 席上 · 第3日 河堤（亲见）          │
│ 最近：第 2 日在席上劝你“先报河厅”              │
├──────────────────────────────────────────────┤
│ [问] [请] [托] [压] [保] [查看关系]            │
└──────────────────────────────────────────────┘
```

**规则：** 三问必须给依据（最近 3 条）；不显示单一好感数字；未知秘密显示“？”而非内容；**接触记录只显示玩家可知的接触（c-23），不自动推出结论，也不把「接触」写成「知道」**。

### 6.4 S-04 委托/计划预览

```
┌──────────────────────────────────────────────┐
│ 委托：抢护（示例）                           │
│ 人：工头（能力 4 / 可用）                     │
│ 料：8–10 垛    夫：30–50    期限：3–4 日      │
│ 发起：1 段 · 执行：2 段 · 预计 第4日晨 完成    │
│ 监督：县丞会勘 / 书办点卯                     │
├──────────────────────────────────────────────┤
│ 合法性：合法（先抢后报）                      │
│ 缺口：料 2 垛 · 银 12 两 · 需保正具结          │
│ 风险：闸底仍在；保固只覆盖埽工/护岸            │
├──────────────────────────────────────────────┤
│ [改条件] [换人] [确认]                        │
└──────────────────────────────────────────────┘
```

**规则：** 只提示风险，不预告结果；缺口可点开解释；确认前二次核对预算/期限；**时间用「发起成本 + 执行时长 + 预计完成时段」表达，不用倒计时或行动点；长动作占段后不可再插入同段动作。**

### 6.5 S-05 情报台账

四档状态：**已核实 / 听说 / 推测 / 存疑**；来源与时间；矛盾并置。

```
[已核实] 实到 4,200 两        来源：库房账册（亲查）
[听说]   料场只到六成          来源：书办（怕担责）
[推测]   县丞与粮商有往来      依据：两次同日出现
[存疑]   上游今年不修堤        来源：士绅（与汛期矛盾）
```

**规则：** 四档状态与来源可信度分开；状态变化必须附新证据并保留历史（上调/下调方向以总纲 14.3 后续裁决为准）；玩家可“记下疑点”，不自动生成结论；**接触记录（C-23）只说明谁在何时接触到什么，不等于已读、已懂、已信。**

### 6.6 S-06 账房/三数/五账

**三个数字：** 账面 4,500 / 实收 4,200 / 报部待定。
**五本账：** 公帑/私囊/人情/身体/风评。

```
账面 4,500 ── 估册/领状
实收 4,200 ── 库房/料场
差额   300 ── 运输损耗？借领？旧欠？
[对账] [看流水] [看礼簿] [题销口径]
```

**规则：** 不直接给“真相”；玩家要通过对勘/证据得出结论；报部只能选 4,500 或 4,200，不能两个都报；三数不合时红色只标差额，不标“贪污”。

### 6.7 S-07 礼簿

```
礼簿 · 第 1 页        [未回] [高风险] [上司] [下属]
日期    送者   礼物      估值  事由    见证  回礼  状态
03-17  士绅   字画      20两  接风    县丞  未回  未回
03-18  粮商   绸缎       8两  旧欠    门房  已回  已回
03-19  委员   程仪      15两  覆勘    幕友  未回  高风险
```

**详情：** 收/拒/退/转/回；见证人；Secret/Hook；风险提示（不是判定）。
**规则：** 礼簿不是官文书；不能替代账册；记/不记是选择；高风险不等于有罪。

### 6.8 S-08 内宅（M2 完整，M1 只家人事件）

M1 不开放完整内宅；家人事件用 S-11 模态呈现，只给请求/代价/选择，不做家人列表与家用账。

- 家人卡：关系、需求、最近请求、秘密（已知才显示）。
- 家用：月度开销、婚嫁/丧葬/疾病大额。
- 仆役：门房/管家/厨子；门包/虚报/泄密。
- 规则：镜头停在门外；不显示私密细节；家人请求必须给“拒绝的代价”。

### 6.9 S-09 街市（M2）

- 地点：茶楼、酒肆、戏园、商号、当铺、码头。
- 人物：粮商、牙人、班主、讼师、脚夫。
- 动作：吃茶、听戏、买卖、借债、打听。
- 规则：信息有来源；传闻沿关系边传播；不显示全知地图。

### 6.10 S-10 考语/行状

- 一页纸：四格（守/才/政/年）+ 实迹 + 风评标签 + 一句考语 + 行状。
- 考语例：“勤勉，然调度未纯。”“才具尚可，河工未固。”
- 行状引用真实事件/承诺/家人；不编造；可分享长图。
- 规则：不显示生成权重；不显示分数；玩家可读、可引用、日后被翻出。

### 6.11 S-11 事件暂停

- 模态：发生了什么、谁在场、你知道什么、三个选项、代价提示（不是结果预告）。
- 不自动计时；不抢焦点；可回到案头再决定（若规则允许）。
- 规则：事件暂停不改变世界状态，只冻结时间。

### 6.12 S-13 知府审查（M1 叠层）

**目的：** 把「上面能卡我，但不能替我办」做成可操作的界面，而不是多读几份公文。

```
┌──────────────────────────────────────────────┐
│ 上宪来文 · 知府批                             │
│ 准 / 驳 / 查 / 饬 / 存                        │
│ 批语：委员覆勘，料价再核                       │
├──────────────────────────────────────────────┤
│ 可做：委员覆勘 / 调卷 / 传询 / 考语 / 揭参     │
│ 不能：批银 / 改委河厅 / 直接革职               │
│ 影响：工期 / 定性 / 料源 / 责任 / 考语         │
├──────────────────────────────────────────────┤
│ [批] [委员] [调卷] [传询] [考语] [揭参/压案]   │
└──────────────────────────────────────────────┘
```

**入口：** S-01「上宪来文」、S-02 批语、委员到县事件。
**五动作：** 批驳、委员覆勘、调卷/传询、考语、揭参/压案；每个动作显示「他能做/不能做/改变什么」。
**规则：**

1. M1 至少真实触发两类（建议：委员覆勘 + 调卷/传询）。
2. 不显示知府全知；他只依据自己的 K、批语、账册与幕友。
3. 批语入卷；揭参是高风险动作，二次确认；压案会留把柄。
4. 审查结果改变的是县级变量（工期/定性/料源/责任/考语），不是新增阅读量。

### 6.13 S-14 志向 / 章末尾声（M1 章节边界）

**目的：** 让玩家在章首自己定目标，在章末看到目标如何被公事、私事和时间改变；失败不是 GAME OVER。

**章首（5 分钟，纸面/薄片）：**

```
┌──────────────────────────────────────────────┐
│ 第一章 · 到任        书斋夜坐                 │
│ 你这一任，最想留下什么？                      │
│ ○ 政绩（保住东堤，拿到好考语）                │
│ ○ 清名（不沾陋规，账目干净）                  │
│ ○ 关系（站稳河厅/府/士绅）                    │
│ ○ 自保（不出事，平安离任）                    │
│ ○ 家业（私囊/家人/退路）——M1 只薄片           │
│ 自定义：________________（一句话，≤24 字）     │
│ 什么会让你改目标？________________            │
│ [定下]（不占十日时段）                        │
└──────────────────────────────────────────────┘
```

**章末（与 S-10 考语同页）：**

```
┌──────────────────────────────────────────────┐
│ 第十章 · 尾声        你的目标对账             │
│ 政绩：抢护成 / 闸底未修 —— 做到一半           │
│ 清名：拒了 2 礼 / 收了 1 程仪 —— 已有裂缝      │
│ 关系：县丞会勘 / 士绅记恨 —— 一进一退          │
│ 留下：一段埽工、一份揭、一个把柄               │
│ 下一任？[候补] [幕友] [乡绅] [教读] [归隐]     │
└──────────────────────────────────────────────┘
```

**规则：**
1. 章首 Goal 不占十日时段；只记录类型、一句话、优先级、复核点、可见性（私有）。
2. 章末逐条对账：做到/没做到/被什么改变；**不评分、不给“正确目标”**。
3. 机会（Opportunity）在章末以「风闻/举荐/空缺」呈现，必须附来源；不随机刷新。
4. 失败退路是选择，不是惩罚页；每条退路显示保留什么、失去什么。
5. 志向印在章节内可回看，但不显示隐藏进度条；NPC 不知道玩家 Goal（除非玩家说出）。

### 6.14 S-15 事务盘（M1 最小 / M2 完整）

**目的：** 让「同时办几件事」成为策略，而不是任务清单堆叠。

```
┌──────────────────────────────────────────────┐
│ 事务（2/3）                    [+ 开新案]     │
│ ● 河工案 · 办 · 工房 · 第10日验收             │
│   抢护（执行中，第4日晨） · 题销（未起）       │
│   偏差：料少 2 垛 / 书办说“够用”               │
│ ○ 接风宴 · 谋 · 人情 · 无期限                 │
│   已赴 / 礼簿 3 笔 / 欠士绅 1                  │
│ 提示：不办也会推进；第8–9日暴雨                  │
└──────────────────────────────────────────────┘
```

**规则：**
1. 活跃 Case ≤3；超过时不给「+」，要求先结/搁置，并显示搁置后果。
2. 生命周期：起 → 查 → 谋 → 办 → 验 → 结；每案当前阶段只有一个。
3. 任务异步：显示执行人、下一检查点、预计完成时段；**不把「提交委托」显示成「已完成」**。
4. 不办也推进：每案显示「若不管，下一次变化在何时」；不显示精确结果。
5. 偏差必须可见（人/料/钱/期限/信息），归因不预设腐败。
6. M1 只做河工案 + 1 条世俗/词讼支线；完整任务树、六房分工、政令牌留 M2。

### 6.15 S-16 政令牌（M2）

- 形态：**牌票/令**，不是稀有卡；无边框发光、无星级、无抽卡动画。
- 来源：只能由事件/考语/关系/章末结算挣得；每章/季 1–2 张；可排序、可组合、有生效时段。
- UI：牌面写「能做什么/何时失效/代价」；不写稀有度；不进入收集册。
- 规则：政令牌不替代权限链；不能凭空批银、越权、改事实。

### 6.16 S-17 生涯 / 继承（M3）

- 一页「卷宗合上」：家族、门生、著作、碑记、口碑、旧案六格；只显示已发生事件。
- 继承不是数值转生：下一任能遇到旧案、旧人、旧碑；不能直接继承官职/银两。
- 规则：Legacy 只消费事件流；不编造未发生的功绩；不做“转生刷点”。

## 八、内容、排版与文案

### 8.1 五种文本

| 类型 | 字体 | 排法 | 语气 |
|---|---|---|---|
| **公文** | 思源宋体 | 竖排 + 界格；可切横排释文 | 克制、程式化、少形容词 |
| **批语/朱批** | 霞鹜文楷 | 朱砂、短句、可贴在文书上 | 上司口吻，简短、可被引用 |
| **书信/私信** | 霞鹜文楷 | 横排/竖排均可 | 私人、带情绪、可说谎 |
| **账册** | 思源宋体 | 横排表格/四柱 | 数字准确、术语稳定 |
| **UI 文案** | 思源黑体 | 横排 | 清楚、短、不古风腔 |

### 8.2 数字

- **文书内：** 汉字数字（肆仟伍佰两），保留历史质感。
- **UI 内：** 阿拉伯数字（4,500 两），等宽，便于对账。
- **对照：** 文书旁可点“释文”显示阿拉伯数字；不在原文上直接改字。
- **差额：** 只标“差额 300”，不标“贪了 300”。

### 8.3 姓名与官职

- 列表用“短称”（姓名/职衔简称）；详情用全称。
- 长官职换行，不缩小字号；提供 tooltip。
- 不用缩写造词；不把“知县”写成“县令”。
- 人物未知身份显示“？”，不显示“神秘人”之类现代游戏词。

### 8.4 AI 文本

- AI 只做表达层；每句事实性文本必须有 ID 或标“传闻/推测”。
- UI 默认不显示 ID；点“依据”可展开证据链。
- AI 不道德说教；不生成现代词汇/网络梗/表情符号。
- 文本超长时截断 + “展开”；不撑破卡片。
- 关闭 AI 时，模板文本必须完整可玩。

### 8.5 内容长度

| 位置 | 上限 |
|---|---|
| 待决卡标题 | 24 字 |
| 待决卡摘要 | 60 字 |
| 人物卡一句话 | 40 字 |
| 文书页 | 400 字/页 |
| 批语 | 40 字 |
| 礼簿行 | 一行一礼；备注 ≤20 字 |
| 考语 | 一句 ≤40 字 |
| 行状 | 一页 ≤300 字 |

## 九、响应式、可访问性与性能

### 9.1 可访问性

- WCAG 2.1 AA；正文对比 ≥4.5:1；大字 ≥3:1。
- 键盘可达；焦点环 2px 朱砂；不依赖 hover。
- 屏幕阅读器：文书提供横排释文；表格有表头；图标有 `aria-label`。
- 200% 字号不破版；不用 `overflow: hidden` 切字。
- 状态不只靠颜色：文字 + 图标 + 纹理。
- 动效遵循 `prefers-reduced-motion`；不做闪烁/快速缩放。

### 9.2 性能

- 首屏（中端移动 4G）< 2s；主交互 < 100ms；动画 60fps。
- 纸纹用 CSS/SVG 微噪点，不用大图；人物图懒加载；文书文本不预渲染全部页。
- 不用持续粒子/视差；不在主线程做长任务。
- 关闭 AI 时无额外网络请求。

### 9.3 平台默认

- M1：响应式 Web（桌面 1440 / 移动 390），浏览器优先；不做原生 App。
- M2：如需 Steam/桌面封装，再评估 Tauri/Electron；UI 不绑定平台。
- 不做横屏强制；移动竖屏优先；文书可全屏横排。

## 十、前端架构与数据边界

### 10.1 分层

```
tokens → primitives → components → screens → flows
```

- `tokens`：颜色/字体/间距/动效；唯一来源。
- `primitives`：Paper、InkLine、Seal、Text、Stack、Grid。
- `components`：C-01..C-25（C-24 仅 M2）。
- `screens`：S-01..S-17（S-16/S-17 仅 M2/M3）。
- `flows`：委托、对勘、礼簿、夜结算、考语、章首立志、事务盘、章末尾声。

### 10.2 数据边界

- UI 只读 `WorldView` 投影；不直接读世界真相。
- 所有命令走 `CommandBus`；UI 不做权限/数值判定。
- `DocumentView`、`PersonView`、`LedgerView`、`ClaimView`、`GiftView`、`GoalView`、`CaseView`、`ExposureView`、`TokenView`（M2）、`LegacyView`（M3）等 view model 由规则层生成。
- **结算顺序（10.6）：** UI 不自行排序同刻事件；只渲染规则层提交后的阶段结果；提交中有 pending，失败可重试，**不做乐观更新**。
- **时间（9.1）：** UI 只读 `worldTime（day, period）` 与动作占段；不维护行动点，不在前端推算「还能做几件事」。
- **认知（3.5）：** `ExposureView` 只给玩家可知的接触；`Belief`/`Rumor` 不得显示成事实；未知一律遮罩。
- AI 文本是 `NarrativeBlock`：`text + factRefs + flavor`；UI 不把 flavor 当事实。
- 事件溯源：UI 状态由事件流/快照派生；不覆盖历史。
- 幂等：重复点击只提交一次；按钮有 pending 态。

### 10.3 目录建议

```
src/ui/tokens/
src/ui/primitives/
src/ui/components/
src/ui/screens/
src/ui/flows/
src/ui/content/
src/ui/testing/
```

### 10.4 测试

- 单元：格式化、状态映射、权限提示。
- 时间：长动作跨段、0 费动作不耗段、等待/模型延迟不推进、无行动点泄漏。
- 因果：结算顺序、幂等重放、pending/失败重试、不做乐观更新。
- 认知：接触记录不泄露未接触事实；四档状态与来源分开。
- 视觉回归：组件/屏幕/长文本/缺失图/空状态。
- 可访问性：axe + 键盘 + 200% 字号。
- 内容压力：20 个长姓名/官职、10 个缺图、5 份矛盾文书。
- 性能：首屏、交互、动画帧率。
- 规则一致性：UI 显示的数字/状态与 view model 100% 一致；不显示玩家未知秘密。

## 十二、风险与设计债

| 风险 | 症状 | 缓解 |
|---|---|---|
| **古风皮** | 只有纹样，没有官场结构 | 先做纸/文书/印，再做插画 |
| **文字墙** | 一屏几百字，玩家跳过 | 一屏一决策；≤400 字/页；渐进展开 |
| **仪表盘化** | 全是数字/图表 | 用账册/对勘/三数，不用折线图 |
| **抽卡化** | 人物卡稀有度/收集 | 官阶≠精美度；不做抽卡 |
| **移动端不可读** | 竖排+小字+横向滚动 | 横排释文；16px；卡片化 |
| **颜色过重** | 红金满屏 | 朱砂 ≤5%；暖金只做细线 |
| **字体侵权** | 用了未授权字库 | 只用 OFL；法务确认 |
| **AI 文案溢出** | 卡片撑破/事实混乱 | 内容 schema；长度上限；fact/flavor 分离 |
| **UI 泄密** | 显示玩家未知秘密 | knowledge gate；未知遮罩 |
| **动效过度** | 翻页/粒子/闪烁 | 微动效；reduced motion |
| **性能** | 纸纹/大图卡顿 | CSS 纹理；懒加载；预算 |

**设计债登记（v0.2）：**

1. 移动端礼簿表格的横向滚动方案未定（卡片化 vs 固定列）。
2. 长官职（>20 字）在 390px 的换行规则未做压力测试。

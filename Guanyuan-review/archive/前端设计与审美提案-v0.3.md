## 二、视觉与交互决策记录（在 v0.2 令牌内）

- 纸/墨/朱印唯一体系；朱砂仅用于印、批、危险与当前态；新增组件一律复用 token。
- 动效：纸落 240ms、印落 180ms `cubic-bezier(.2,.7,.2,1)`、面板 180–240ms；热点分层入场；按钮按压 `.97`；数字滚动 420ms；禁止 3D 翻页、常驻粒子、视差。
- 场景切换：照片 1.03→1 缓推 + 热点 stagger，不做翻页。
- 签押仪式感：发起文书 + 朱印落下 + 落款「第 N 日 · 时段 知县亲判」，随后进入事务执行中，**发起不显示为完成**。
- 断点：1500 / 1220 / 980 / 700；390 无横向滚动；手机保留汛期倒计时紧凑形式。
- 素材：`county-office-dawn.jpg`、`east-dike-dawn.jpg` 已接入；`study-night.jpg`、`sang-residence-night.jpg` 接口已留，缺图自动回退。

## 三、本节点（小推进）：S-14 章末志向对账薄片

- 夜结算（DaySummary）由「三行日志」扩为「更帖 + 对账」：保留成/卡/传，新增志向对账区。
- 对账按当前志向生成两至三条：做到什么 / 没做到什么 / 被什么改变；状态只分「进 / 改 / 缺」。
- 不评分、不给正确目标、不出现进度条与隐藏权重；志向仍私有。
- 文案须引用本局真实事件（签押、探挖、借领状、赴宴、问话），不编造。
- 验收：四种志向各能产出不同对账；未立志不显示对账区；390 不破版；`npm run smoke` 通过。

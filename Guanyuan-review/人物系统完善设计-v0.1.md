## 零、一句话与立场

**爽感不来自「数值变大」，来自「我被看见了、我攒下了一手牌、我遇到了谁」。**

人物系统 already 把成长钉成「关系/债/风评/履历/执行条件的积累」（能力极难改变）。本提案不推翻它，而是给这套积累**装上直观的反馈与收藏的外壳**：

- 属性要**一眼可读、有称号、有组合、有里程碑**——这是直观爽感。
- 历史人物卡要**能收集、有图鉴、有缘分**——但只能挣得，不抽卡、不付费、不碾压。

三条不可越的线（与总纲一致）：
1. **离散优于连续**：数值只留能力/资源/时间；其余状态词、标签、文书。
2. **earned-only**：属性变化与卡牌收录都必须有事件来源；不刷、不抽、不买。
3. **行状优先（D-006）**：成就感主载体仍是行状；人物卡是「你遇到过谁」的收藏册，不是强度来源。

## 一、设计目标与非目标

### 1.1 目标

| 目标 | 可测标准 |
|---|---|
| **属性一眼可读** | 玩家 3 秒内说出一个人「能不能办事、想要什么、怕什么、名声如何」 |
| **直观爽感** | 玩家能指出自己/人物的一项称号、一个里程碑或一手关系筹码，并感到「这是我攒出来的」 |
| **收集有动机** | 玩家能说出「我还想遇到/收录谁」，且知道靠什么途径（不是抽） |
| **成长可解释** | 任何属性变化都能点开看到来源事件；无来源不变化 |
| **历史可核查** | 历史人物卡标注史料出处与虚构边界；不虚构重大历史事件 |
| **无 AI 可玩** | 称号/评语/图鉴有模板兜底，关闭模型不阻塞 |

### 1.2 非目标

- 不做经验条/等级/刷属性；能力 0–5 极难改变（3.1）。
- 不做抽卡/十连/保底/付费强度/稀有度碾压。
- 不做「集齐换数值」「人物当资产刷」。
- 不做后宫收集/性内容；人物卡精美度不由官阶决定（16.2）。
- 不做与主线脱节的独立养成小游戏（P-19）。

## 二、属性体系完善（三层十二槽逐项）

> 沿用 3.1 三层十二槽，不新增平行属性系统。每项补「直观呈现」与「成长接口」两列，把隐性积累变成可见爽感。

### 2.1 Layer A · 硬约束（极难改变）

| 槽 | 取值 | 直观呈现（爽感） | 成长接口 |
|---|---|---|---|
| **identity** 身份 | 姓名/字号/年龄/籍贯/出身/科举/师承/履历 | 出身印（正途/异途/寒门/荫袭）、师承线（座师是谁）、履历时间轴 | 出身/座师 M2 构筑（7.7）；履历由行状累积 |
| **capability** 能力 | 行政/财政/工程/司法/交涉 **0–5** | **五维雷达 + 称号阶梯**（见 2.4）；每项一句评语（「钱谷老手」「刑名生疏」） | 极难改变；师承/历练可缓慢 +1（候选，见第四节） |
| **office** 职官 | 职位/品级/权限 ID/资格 | 官阶印绶视觉、权限范围图（能批什么/不能批什么） | 升迁换权限与视野（7.4；品级提案「升迁是换盲」） |

### 2.2 Layer B · 软约束（可被事件改变）

| 槽 | 取值 | 直观呈现（爽感） | 成长接口 |
|---|---|---|---|
| **needs** 动机 | 仕途/家族/财富/名声/安全/安逸 **0–3** | **动机雷达** + 「他最想要什么」一句话 | 局势/事件重算；不刷 |
| **bonds** 关系 | 对他人 认可/信任/惧/欠 **−3..+3** | **关系网图** + 三问答案 + 筹码可视化 | 行为/事件驱动；情分按季衰减（4.4） |
| **fear** 恐惧 | 最怕的一件事（自然语言） | 把柄提示（你知道他的怕 → 可用筹码） | 秘密/把柄系统（4.3） |

### 2.3 Layer C · 认知与状态

| 槽 | 取值 | 直观呈现（爽感） | 成长接口 |
|---|---|---|---|
| **knows / believes** | 事实 ID + 来源 + 可信度 / 错误认知 | 情报四档（已核实/听说/推测/存疑）；未知遮罩 | Exposure→Belief（3.5）；不自动推导 |
| **secrets / hooks** | 秘密 + 证据 + 见证 / 把柄 + 次数 + 反噬 | **筹码手牌**：你握着谁、谁握着你 | 用一次少一次；公开即风险（4.3） |
| **reputation** 风评 | 清/能/奢/贪/刻/懦（可组合） | **风评印章组合**（「能而贪」「清而刻」）+ 称号 | 事件/世俗累积；考语引用（7.2） |
| **state** 状态 | 疲劳/负荷/健康/欠债/承诺/日程 | 身体状态条（影响信息质量，不影响速度，9.5） | 睡眠/休息/节制；酒色熬夜有代价 |

### 2.4 能力称号阶梯（直观爽感核心，候选）

能力值仍是 0–5 整数，但每档给一个**称号词**，让「3」和「4」读起来不同：

| 值 | 称号 | 读感 |
|---|---|---|
| 0 | 生疏 | 完全不懂，会坏事 |
| 1 | 略懂 | 知道皮毛，需人带 |
| 2 | 熟手 | 能办常规事 |
| 3 | 能吏 | 独当一面 |
| 4 | 专精 | 一方好手，被人请 |
| 5 | 大家 | 稀缺，可定工法/可著书 |

- 称号由能力值 + 实迹共同渲染（有 4 无实迹 → 「纸上专精」；有实迹 → 「河工大家」）。
- **称号不是新数值**，是呈现层；底层仍 0–5。
- 五项可各有称号，组合出人物画像（「钱谷专精 + 刑名生疏」= 典型钱谷师爷）。

## 三、直观爽感层（呈现，不新增规则）

> 这个层只做「把已有积累看得见」，所有数据来自规则层 view model；不自行计算、不新增业务。对应 P-15 可读性优先。

### 3.1 称号 / 评语系统

- **能力称号**（2.4）+ **风评称号**（清官/能臣/酷吏/循吏/奢靡/懦吏…）+ **履历称号**（河工能手/赈灾活民/刑名老手…）。
- 由属性组合 + 行状实迹自动生成；AI 润色，模板兜底。
- 爽点：玩家看到自己**被一句话定义**，且这句话会被考语/行状/他人引用（7.2/16）。
- 约束：称号必须有事实支撑；不编造；可被翻旧账（「当年号称清官，如今礼簿被抄」）。

### 3.2 里程碑 / 行状条目

- 第一次办成、第一次拒礼、第一次被参、第一次举荐、第一次溃口…… → 行状条目 + 收藏标记。
- 爽点：**「这是我干出来的」**的可分享时刻（行状长图，16.1）。
- 与收集册联动：里程碑解锁对应人物卡/称号（见第五节）。

### 3.3 关系筹码可视化

- 一手「牌」：谁欠你（Debt）、你握着谁的把柄（Hook）、谁怕你（惧）、你欠谁（债）。
- 爽点：**权衡与掌控感**——我手里有牌，但每张都有代价/反噬。
- 约束：只显示玩家可知的筹码；未知遮罩；把柄次数可见（用一次少一次）。

### 3.4 名望刻度（候选，宏观爽感）

- 由风评 + 实迹 + 关系派生的**离散等级**，不是数值条：
  `无名 → 小有名气 → 一方闻名 → 士林皆知 → 天下知名`
- 影响机会/婚嫁/借贷/荐举（7.7 Opportunity 输入），不直接加能力。
- 爽点：给宏观人生一个**看得见的刻度**；可升可降（被参/奢名会掉）。
- 约束：派生量，不独立刷；变化必须有事件来源；M1 只做粗刻度或不做。

### 3.5 人物面板布局（接前端 S-03）

```
┌──────────────────────────────────────────────┐
│ [肖像] 姓名·字号 · 职官·品级 · 出身印          │
│ 称号：钱谷专精 · 能而贪 · 河工能手             │
├──────────────────────────────────────────────┤
│ 能力雷达（五项+称号）   动机雷达（六维）        │
├──────────────────────────────────────────────┤
│ 三问：能不能 / 愿不愿 / 敢不敢（各附依据）      │
│ 关系筹码：欠你1 / 你把柄1 / 你欠他1            │
│ 风评印章：能·贪·奢    身体：疲劳2             │
├──────────────────────────────────────────────┤
│ 最近共同经历（行状片段3条）  [收录] [查看关系]  │
└──────────────────────────────────────────────┘
```

- 一屏一决策；长文渐进展开；未知遮罩；状态不只靠颜色（WCAG AA）。

## 四、能力成长口径（守住「极难改变」）

**原则：能力不是刷出来的，是「熬」出来的，且有上限与代价。**

| 途径 | 机制（候选） | 代价/上限 | 阶段 |
|---|---|---|---|
| **师承** | 拜师/受教（座师、幕友、专家）→ 某项 +1 的长期进度 | 耗时/人情/束脩；一项一生 +1–2 封顶 | M2 |
| **历练** | 反复办某类事 + 复盘 → 进度累积 | 失败也累积「教训」但慢；疲劳/身体代价 | M2 |
| **著述/讲学** | 把经验写成书/教门生 → 固化能力 + 风评 | 耗时/清名/被议「好名」 | M2/M3 |
| **顿悟/事件** | 重大事件触发某项 +1（稀有） | 必须有事件来源；不可刷 | M2 |

**硬约束：**
- 能力上限仍 5；**单项一生涨幅有限**（如 +1–2），不允许从 0 刷到 5。
- 成长主要改善 **10.1 的投入度/资源/阻力**，而非名义能力（关系好→投入高；制度熟→阻力低；资源足→充足度高）。
- 年龄/身体会**衰退**（老病→能力发挥下降，不是值下降），与 9.5 一致。
- 所有变化走事件流、可追溯、可复现（10.6）；M0 纸面验证涨幅与节奏。

> 这一节是「成长系统」的人物侧接口；完整成长设计另见后续提案，本提案只钉住能力口径，避免刷属性。

## 五、历史人物卡收藏系统

### 5.1 定位：图鉴，不是强度

- 收藏册回答「**我这一生遇到过谁、与谁共事、受过谁影响**」，是行状的 companion，不是战力来源。
- 与 D-006 协调：**行状仍是成就感主载体**；人物卡是收藏/图鉴/关系档案（16.2 三种规格之一）。
- **不抽卡、不内购、不稀有度碾压、不集齐换数值**；精美度不由官阶（16.2）。

### 5.2 两册（兼容架空设定）

| 册 | 收录对象 | 获取 | 作用 |
|---|---|---|---|
| **当世人杰册** | 本作预设/动态人物（知县同僚、幕友、书吏、粮商、士绅、专家、工头、上司、家人） | 亲历/共事/结交/举荐/考证 | 关系网 + 行状 + 机会；你「攒下的人脉」 |
| **前代名臣册** | 历史人物（作为**原型/榜样/师承来源**） | 著作/碑记/传闻/科举背景/书院讲学解锁 | 知识/师承/政令牌灵感；**不直接介入虚构剧情** |

**架空兼容关键：** 本作是架空晚清、不虚构重大历史事件（总纲边界）。因此历史人物**不卷入本作主线事件**，而是以「前代名臣」身份进入图鉴，作为可研读、可师承、可引用的对象；若要用其经历，标注史料出处与「原型改编」边界。当世人杰才是亲历剧情的角色。

### 5.3 获取途径（earned-only）

沿用人才路径（5.2）：**发现 → 接触 → 评估 → 共事/结交 → 收录**。

| 深度 | 条件 | 卡面状态 |
|---|---|---|
| **闻名** | 传闻/著作/科举背景知道此人 | 剪影 + 名字 + 一句传闻（未证实） |
| **相识** | 真实接触（Exposure） | 肖像占位 + 身份 + 三问初值 |
| **共事** | 一起办成/办砸一件事 | 完整卡 + 共同经历（行状片段） |
| **深交/举荐** | 债/信任/举荐/连坐 | 典藏标记 + 关系里程碑 + 后续引用 |

- **收录必须有 Exposure 或事件证据**；不能凭空「抽到」。
- 闻名≠相识≠共事（认知链 3.5）；未证实的只显示传闻。

### 5.4 卡面结构

```
[肖像/剪影]  姓名·字号 · 身份·职官 · 出身印
称号：……（能力+风评+履历）
三问：能不能 / 愿不愿 / 敢不敢（附依据）
关系：认可/信任/惧/欠 · 你与他之间的债/把柄
共同经历：行状片段（真实事件，不编造）
史实来源：〔前代名臣册〕史料出处 + 虚构边界标注
收录深度：闻名 / 相识 / 共事 / 深交
```

- 列表卡/详情卡共用原画裁切（16.4）；文字 UI 渲染，不烘焙进图。
- 缺失肖像用占位/剪影，不阻塞收集。

### 5.5 稀有度兼容方案（待裁决）

不用付费稀有度。可选三种**叙事性分类**（不直接影响强度）：

| 方案 | 分类依据 | 爽点 | 风险 |
|---|---|---|---|
| **A 品类** | 名臣/能吏/循吏/酷吏/隐逸/外戚… | 「我集齐了一类人」的图鉴癖 | 需史实支撑分类 |
| **B 缘分深度** | 闻名/相识/共事/深交/连坐 | 「我和他有故事」 | 与获取途径重复 |
| **C 典藏叙事** | 主线/恩人/政敌/座师/门生 | 情感重量 | 易被误读为强度等级 |

**推荐 A + C 组合**：品类做图鉴格子，典藏做情感标记；**都不加数值**。B 作为卡面进度而非稀有度。

### 5.6 收集与成长联结（不碾压）

- 收录前代名臣 → 解锁**师承/著作/政令牌灵感**（7.7/10.7），是「机会与手段」，不是属性碾压。
- 收录当世人杰 → 关系网/行状/机会兑现（7.7）。
- 集齐某类 → 解锁**称号/行状专题/图鉴页**（叙事奖励），**不给能力值/资源加成**。
- 跨局继承（12.5）：上一代收录的人/著作/口碑，下一代可引用（「你父亲当年保过的人，如今是你的上司」）。

### 5.7 反模式（明确不做）

抽卡/十连/保底 · 付费强度 · 稀有度碾压 · 集齐换数值 · 人物当资产刷 · 官阶决定精美度 · 后宫收集/性内容 · 历史人物卷入虚构重大事件 · 无来源收录。

## 七、阶段切分

| 阶段 | 人物侧交付 | 不做 |
|---|---|---|

## 九、验收判据（可测）

| 项 | 判据 |
|---|---|
| 属性可读 | ≥4/5 玩家 3 秒说出一个人能不能办事/想要什么/怕什么/名声 |
| 爽感可指认 | ≥2/3 玩家能指出一项自己的称号/里程碑/筹码，并说「这是我攒的」 |
| 成长可解释 | 抽查 10 次属性变化，100% 有来源事件；无来源不变化 |
| 能力不刷 | 构造「重复交谈/重复办事」100 次，能力不自动上涨 |
| 收录有动机 | ≥2/3 玩家能说出「还想收录谁、靠什么途径」，且答案不是「抽」 |
| 历史可核查 | 前代名臣卡 100% 标注史料出处与虚构边界；不卷入虚构重大事件 |
| 无 AI 可玩 | 称号/评语/图鉴模板兜底，关闭模型全流程可完成 |
| 不泄露 | 抽查 10 张卡，不显示玩家未知秘密/未接触事实 |
| 收藏不碾压 | 集齐某类后，能力/资源无加成（只叙事奖励） |

## 十、风险与设计债

| 风险 | 症状 | 缓解 |
|---|---|---|
| **爽感变刷数值** | 玩家盯着能力值/名望条刷 | 离散+称号+极难改变；成长主要改执行条件 |
| **收藏变抽卡** | 稀有度/集齐换强度 | earned-only；品类/典藏只叙事；反模式清单 |
| **历史失真** | 历史人物卷入虚构事件 | 前代名册不介入主线；史料标注+原型边界 |
| **称号空洞** | 评语无事实支撑 | 称号必须有实迹；可被翻旧账 |
| **面板信息过载** | 一屏塞满雷达/标签 | 一屏一决策；渐进展开；P-15 |
| **与行状争位** | 人物卡抢了行状的成就感 | 行状优先；卡是收藏/关系档案 |
| **名望独立刷** | 名望变成第二条好感条 | 派生量；变化必须有事件；M1 可不做 |
| **能力成长破坏平衡** | 后期能力碾压 | 单项 +1–2 封顶；衰退；M0 校准 |

**设计债（v0.1）：**
1. 称号词表与风评组合规则未定（需纸面读感测试）。
2. 名望刻度的派生公式与阈值未定（M1 是否做待裁决）。
3. 师承/历练进度曲线未定（+1 需要多少投入）。
4. 前代名臣名单与史料出处未核验（需史实专项）。
5. 图鉴品类划分需史实支撑，避免现代分类穿越。
6. 收藏与政令牌/家学的解锁联结未定（M2/M3）。
7. 前端 S-03 面板与新增 S-18 图鉴屏未设计（通过后同步前端专项单）。

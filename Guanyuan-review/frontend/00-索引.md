## 一、这套单子是什么

前端施工的**设计参考 + 进度事实**，不是规则。规则以 `设计总纲.m107` v0.13 与 M1 事实图谱为准；本套单子只说明「界面怎么呈现、投影到什么程度、哪些东西不许发明」。

## 四、三条阅读路径

- **接手 / 复查**：`01-进度一览.md`（现状）→ 对应模块单（规格 + 实现清单）→ `15-施工台账.md` 该节点。
- **要改某个屏**：`03-信息架构.md` 找屏幕 → 对应模块单「设计规格」→ `04-设计令牌.md` / `05-组件库.md` 取料。
- **想美术**：`12-美术与资源.md` 的图位表与描述词 → 跑 `npm run art` → 回模块单登记。

## 五、每次施工必更五处

1. `15-施工台账.md`：开工前「推进前快照」，收工后「推进后结果」。
2. `01-进度一览.md`：当前状态、最近八轮、全部节点表（新行置顶）、模块→最近节点。
3. **对应模块单**：`## 三、实现清单` 增行（节点 / 版本 / 涉及屏幕 / 定向 / 明细链接）；有新形态则补进 `## 二、设计规格`。
4. `14-节点纪要.md`：新增一节 6.x，写清为什么、落哪几个模块、接口怎么兼容。
5. `16-Changelog.md`：一条版本记录；若新增屏幕、表面或模块文件，再更 `03-信息架构.md` 与本节文件地图。

## 六、编号与命名

| 前缀 | 含义 | 例 |
|---|---|---|
| `S-xx` | 屏幕 | S-01 今日案头、S-14 章末 |
| `C-xx` | 组件 | C-87 阅览偏好 |
| `FE-xxx` | 施工节点（一轮可含多个） | FE-076 阅览偏好 |
| `PS-xx` | 美术图位 | PS-07 骑缝半印 |
| `E-xxx` / `F-xxx` / `P-xxx` | 证据 / 事实 / 人物条目 | E-001 估册与领状 |
| `v0.xx` | 备案版本 | v0.75 |

锚点约定：节点用 `#fe-0xx`，屏幕用 `#s-01` 形式的标题锚点，附录保持原标题。

零既有 props / 回调签名改动；只加可选 props、本地 state、静态 `data-*`；不新增 `OverlayId`、一级入口、依赖。

## 二、设计规格

### 6.5 S-05 情报台账

四档状态：**已核实 / 听说 / 推测 / 存疑**；来源与时间；矛盾并置。

```
[已核实] 实到 4,200 两        来源：库房账册（亲查）
[听说]   料场只到六成          来源：书办（怕担责）
[推测]   县丞与粮商有往来      依据：两次同日出现
[存疑]   上游今年不修堤        来源：士绅（与汛期矛盾）
```

**规则：** 四档状态与来源可信度分开；状态变化必须附新证据并保留历史（上调/下调方向以总纲 14.3 后续裁决为准）；玩家可“记下疑点”，不自动生成结论；**接触记录（C-23）只说明谁在何时接触到什么，不等于已读、已懂、已信。**
**则例（FE-032）：** 四档筛选条上方加「四档状态 · 界面投影」与依 14.3 小签。
**回声（FE-031）：** 筛选条下方固定 C-42 四类受众回声（疑点焦点）：上司只读县呈与已入卷批答；同僚按夜查、传询或接触投影；士绅不闻此疑点即留白；百姓只列 P-006 茶楼转述且态度「未详」。没有见证与文书的疑点，不自动变成风声。

### 6.5.1 情报抽屉底纸与来源钉巡览（FE-134 · v1.32）

抽屉底材改由 PS-23 `intelbase` 承担（**FE-136 已接入**：跑 art 清角标、撤暂借小注；图实为横版 1280×720，`cover + left center` 保左缘包边防拉伸；cssFallback 留作缺图降级）。来源钉（`.clue-source`）单一 Tab 停靠 + 方向键 / Home / End 巡览，切筛选重停靠；只移焦点、不改回查回调与四档状态语义。描述词见 `12` 附录 Y。

### 6.6 S-06 账房/三数/五账

**三个数字：** 账面 4,500 / 实收 4,200 / 报部待定。
**五本账：** 公帑/私囊/人情/身体/风评。

```
账面 4,500 ── 估册/领状
实收 4,200 ── 库房/料场
差额   300 ── 运输损耗？借领？旧欠？
[对账] [看流水] [看礼簿] [题销口径]
```

**规则：** 不直接给“真相”；玩家要通过对勘/证据得出结论；报部只能选 4,500 或 4,200，不能两个都报；三数不合时红色只标差额，不标“贪污”。
**体面线（FE-043）：** 账房底部挂 C-59 `strip` 规格，只与 S-07 / S-08 同源，标「预览 · 规则未启用」；不把公帑、私囊、礼簿混成一条收支线，不给高低结论。

### 6.6.1 账房空态、卷末落款与印刷三栏（FE-121 ~ FE-123 · v1.19 ~ v1.21）

账房并置空态 `.selection-placeholder` 与证据板两处 `.chain-empty` 套 `.empty-slip`（`--paper-scroll` + 左 2px 朱砂刻口），**句子逐字未改**；账房页脚加 `.ledger-colophon`「卷末落款 · 账房三分签」，点按或 `Alt + ↑` 只把焦点送回账房卷首题签，不切账页、不改所选项。印刷侧，章末三向对读的账栏在 A4 版心下强制三列、去纸纹、栏内长账目不裁切；账房本身不在「印此页」范围。

### 6.6.2 账房与证据链印此页（FE-124 · v1.22）

账房标题区「印此页」走 `printSurface('ledger')`：三数、四本账、料账、并置空态上纸；页签、差额开关、并置按钮、对读窄条、体面线、最近看过与卷末落款不上纸，工作面上的双栏在纸上单列铺开。证据链头部「印此页」走 `printSurface('evidence')`：三枚证据钉、两问与并置疑点上纸；回文路径、来源展开、查所据与“记下 · 回到案头”不上纸。两处都用白纸、去纸纹，料账条与县印保留必要颜色。

### 6.7 S-07 礼簿

- **体面线（FE-043）：** 礼簿纸带下方挂 C-59 `full` 规格：粗墨线 + 三笔既有事实（私囊余 `state.privateFunds` / 礼簿已出 `state.giftEntries` / 家用归私囊 · 大额另记），逐笔给来源小签。不编收入字段、不给「太高 / 太低」判定、不新增数值；页眉标「预览 · 规则未启用」，不挂则例小签、不与 S-12 规则层混记。
- **债与礼（FE-037）：** 人情簿底栏「礼簿往来」与 S-07 同源，只列既有 `giftEntries`；空时写「接风帖仍在案角」，不补写礼数。

```
礼簿 · 第 1 页        [未回] [高风险] [上司] [下属]
日期    送者   礼物      估值  事由    见证  回礼  状态
03-17  士绅   字画      20两  接风    县丞  未回  未回
03-18  粮商   绸缎       8两  旧欠    门房  已回  已回
03-19  委员   程仪      15两  覆勘    幕友  未回  高风险
```

**详情：** 收/拒/退/转/回；见证人；Secret/Hook；风险提示（不是判定）。
**规则：** 礼簿不是官文书；不能替代账册；记/不记是选择；高风险不等于有罪。
**则例（FE-032）：** 账房标题挂依 11.6 小签；生活纸带上方标「礼簿与风评 · 界面投影」并挂依 13.5.1 小签。
**印象与回声（FE-031）：** 五本账下方加一条纸带：C-43 四种印象（名望/信任/畏惧/合法性各自为离散文字标签，附来源小签）+ C-42 同一场宴的四类受众回声（士绅按亲赴/代往/未赴给「认可/怨」，同僚只按原口供，上司与百姓不在场即「未详」）。四种印象永不合并成单一数值或进度条。

**长页书签带（FE-084 · v0.82）：** 账房四本账比屏高时，右缘挂一条窄丝带（C-95）：随滚动定位、点一下移一屏、按住可拖、聚焦后键盘可移；只读滚动位置，不改账目、差额与选证顺序，图未到以朱线素带兜底并标「暂借素带」。

**料账焦点与最近看过（FE-090 / FE-091 · v0.89）：** 料账三段焦点走既有 `viewMemory`，只存会话内，离开再回仍停在原段；账房底部复用 C-102「刚才」三签，当前表面不重复、至多三条、刷新即散。两者都不改账目、差额、报部待定与选证顺序，也不写存档。

**三向对读与同源批阅签（FE-092 / FE-093 · v0.91）：** 账房底部加 C-103「账 / 疑 / 礼」窄条，账列置为当前页、疑 / 礼列点回情报 / 礼簿；标题栏挂 C-104b「上次批阅 · 因/略/工/料」，点开回卷宗原组。三数改引 `ledgerThree` 常量，数值仍是 4,500 / 4,200 / 300；不新增账目、科目、结论或报部选择。

**风闻行迹（FE-094 · v0.92）：** 情报台账「听说」筛选页加 C-105 三站窄条：当前站「听说 · 列入听说未核实」，可回街市茶楼，下一站只指向章末「仍无凭据」；只读 `state.log.rumor` 与既有 P-006，不新增传闻、来源、核实状态或事实。

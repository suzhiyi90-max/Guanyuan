## 二、设计规格

### 6.22 场景美术接口与「画在纸上」（FE-033）

**目的：** 让美术由图片承担，代码只负责纸面层级与交互，不再用 SVG 手绘现场。

- **C-47 场景美术板：** `src/sceneArt.ts` 以 `ScenePlateId → { src, alt, credit, position, scale, pending, prompt }` 登记全部图位；`ScenePlate` 只读取配置，带 `onLoad` 淡入、`onError` 留白回退、旧纸洗色、压暗、底图署名与「抄样底图 · 待专图替换」标记。换图只改一行 `src`，组件与交互层不动。减少动效下淡入直接完成。
- **S-11 世界事件：** 四类事件按 `worldEventPlateOf` 复用既有四张场景照片，明确标「底图 · 借用既有场景素材」；事件暂停、两选项、谁在场与你知道什么全部不变。
- **章首 / 夜结算 / 章末（FE-036）：** 图位 `prologue-night` / `chapter-close` 带 `fallbackSrc`：专图未到自动退回 `study-night.jpg` / `county-office-dawn.jpg`，并标「专图待补 · 暂借既有实景」；放入专图即自动替换。
- **S-09 / S-19（FE-035）：** 街市图位 `market` 借用青石镇街市图并标「借用」，抵达图位 `arrival` 接东堤实景；两者都只改 `sceneArt.ts` 的 `src`，组件与交互层不动。
- **S-20 四样张：** 渡口 / 驿铺 / 青石镇 / 桑家庄撤除 SVG 线稿，改接美术板；四张专图已于 v0.29 接入（`ferry.png` / `station.png` / `town.png` / `manor.png`），此前以抄样局部作底的 `pending` 状态全部撤销。锚点、三层在场、原账房/情报/上宪/人物回调与雨线光层全部保留在画境之上。
- **风闻行迹 / 今日动线（FE-094 / FE-095）：** 两条都是既有画境上的**纸签与朱线**——风闻三站只写字，今日动线只列已到场所，均不新增场景图、路线图、里程或人物。S-01 / S-05 / S-06 / S-09 / S-14 / S-19 / S-20 共用同一套纸签与驿路样式；当前站朱砂，其余墨色，390 单列。两块都不代码补画纸纹、界格或印章。
- **纪律：** 不伪造地点人物传闻或营业状态；四张专图由用户生成后接入，描述词与接入方式留档于**附录 G**。
- **响应式：** 1440 三栏舆图 / 双栏场景，1024 紧凑，390 全屏纵向；三档均无横向溢出，标题不逐字折行。
- **印刷（FE-121 / FE-124 · v1.19 / v1.22）：** 章末、文书、账房、证据链的「印此页」都不上纸纹、不上画境板：`@media print` 把对应表面及其子树的 `background-image` / `background-color` 退到白纸，画境板整块不上纸，县印与料账条保留必要颜色。八张装帧纸原样不动，只为屏幕服务；纸上不铺纸，是印刷取舍，不是缺图，也不因此新增或重跑任何图位。

## 附录 J　美术资产一键处理流程（FE-052）

**为什么：** 用户每批生成的图都带「AI生成 / 妙呀AI」角标水印，纸样平铺会让水印每 420px 重复一次。按 FE-012 / FE-049 的邻域重建做法，把清理沉淀为常驻工具，不再每次临时写脚本。

**一键命令（在 `app/` 下）：**

```
npm run art                  # 处理新增 PNG（默认清左上 / 右下两角）
npm run art -- --all         # 强制全部重处理
npm run art -- --check       # 只报告将处理哪些图，不写文件
npm run art -- --corners=4   # 四角都清（生成器换了角标位置时）
npm run art -- --frame       # 卡框安全模式：只处理 card-frame-*.png
npm run art -- --frame --all # 同上，但强制重处理（算法调整后复跑）
```

**标准流程：**

1. 把用户生成的图放进 `app/public/assets/`，文件名与图位 `src` 对齐。
2. 跑 `npm run art`：新增图自动清理水印，已处理图按 SHA-256 清单跳过。**卡框类图（有完整绫边 / 45° 斜接 / 细墨线）必须命名为 `card-frame-*.png` 并改用 `npm run art -- --frame`**：默认整块邻域重建会把下边绫边与斜接一起抹掉（实测右下绫带保留率 73.9% → 24.3%）。
3. 在 `src/sceneArt.ts`（场景画境）或 `src/paperArt.ts`（纸面图位）登记 / 改 `src` 一行，去掉 `pending`；**组件与交互层不动**。
4. `npm run build` + 1440 / 1024 / 390 三档截图复核：正文对比度、画境裁切、无横向溢出。
5. 在第十四节快照 / 结果、附录 F changelog 与附录 G / H / I 登记接入状态；需要新美术时先把中文描述词交用户生成。

**工具约定：**

- 只处理 `*.png`；三张底图 / 样张白名单跳过（`yongji-county-base.png`、`yongji-county-map-preview.png`、`A_refined_antique_Chinese_coun_2026-11-01T14-52-38.png`）。
- 默认清左上 + 右下两角，各占 `15%W × 11%H`；取画面内侧相邻同尺寸块覆盖，内侧 10px 羽化。只清理生成标识，不生成 / 不补画任何内容。
- 幂等清单 `app/scripts/art-manifest.json` 记录处理后文件的 SHA-256；内容不变即跳过，重跑用 `--all`。
- **卡框安全模式（`--frame`）**：只扫描 `card-frame-*.png`。整块按材质平移覆盖两处角标矩形——绫带取同向绫带、纸心取同向纸心；平移源若比该段底材中位亮 18 / 暗 25 以上，改用中位色，避免把源里的高光或暗花带到水印处；45° 斜接带不覆盖，带内只把「亮于邻域中位 15」的水印点换成邻域中位色（清白点、不留暗斑）。全程只用图内像素，不补画。验收（官四至六 / 官一至三 / 绅 / 商 / 幕 / 役 六张）：改动限定在两个角标矩形内（矩形外 0 px）、左上斜接结构变更 0.6–2.2 灰阶、六张右下「妙呀AI」均清至 1–2px 白点。**已知副作用**：左上转角可能出现 1 处 6×18px 纹理接缝（源区纹理与目标区差异大时），属整块平移的取舍；若图本身边宽 / 线色 / 纸心不合规，仍应重出，不靠工具修。
- `--check` 模式下脚本强制不走幂等跳过，所列「待处理」**不等于** hash 失配；判断真实占用须直接比对 `art-manifest.json` 的 SHA-256，或用不带 `--check` 的实跑确认跳过数。
- 复用既有 `playwright`，一次启动浏览器批量处理，不新增依赖。**实跑：首次全量 14 张 3.4s；重跑扫描 14 张、跳过 14 张。**
- 工具是资产层，不进 UI 规则；不启用新规则、不写存档、不改任何业务 props / 回调。

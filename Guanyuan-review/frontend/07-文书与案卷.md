## 二、设计规格

### 6.2 S-02 案卷/文书

**目的：** 让文书成为玩法，而不是阅读障碍。

```
┌──────────────────────────────────────────────┐
│ 呈文 · 初稿         [对勘 V-002] [贴签] [记疑]│
├──────────────────────────────────────────────┤
│  某县为报事……                                │
│  ……堤身渗水四十步，请拨料抢修……              │
│  ……（界格/竖排，可切横排释文）                 │
│                                              │
│  [朱批] 委员覆勘，料价再核                    │
│  骑缝印 · 签押 · 三月十七                     │
├──────────────────────────────────────────────┤
│ 证据钉：E-001 账册 · E-007 探挖 · V-001 初稿  │
│ 疑点：呈文说“渗水”，探挖说“闸底淘空”          │
└──────────────────────────────────────────────┘
```

**四种视图：**

1. **卷宗：** 四类文书签与呈文—府札—附纸—题销流转链；只读在卷状态，原入口回查，无据留白。
2. **原件：** 竖排、界格、朱批、印、签押；场景热点默认。
3. **释文：** 横排、标点、可复制；移动可读，桌面可切。
4. **对勘：** 左右两版 V-001/V-002，差异高亮（删/改/留空），不自动判真假。

**规则：** 一页 ≤400 字；长文分页；证据钉可点开；不显示“真相”，只显示文本与证据。卷宗目录不新增文书、签发、副本、持有人、流转或题销规则。
**入卷链（FE-045）：** 卷宗下方加 C-61「四体入卷链」只读纸，按 8.4 把批 / 详文 / 禀帖 / 揭逐条标为 在卷 / 候答 / 拟稿 · 未入卷 / 未届；档位只取 `officialActions`、`draftsOf(state)` 可用性与既有委牌、勘报、批答、具结，不生成文书正文、不自动流转、不写入卷；「回拟稿 / 回上宪 / 回呈文」全部复用原回调。C-57 拟稿页脚增设常驻「回卷宗 · 查此体入卷与否」（无稿空态下亦可达），标「界面 · 只读串联」。
**回查焦点与纸面（FE-046 / FE-048）：** `.document-panel` 挂 `data-focus-id="document-original"`，由情报回查、权界纸回原处与 C-61 回卷宗触发 C-62 朱砂焦点；原件视图叠朱丝栏笺、释文/对勘/卷宗叠旧宣纸纤维（图未到退回素纸）。焦点与纸样都不改文书内容、版本差异与选证顺序。

**指路锚点（FE-087 · v0.85）：** `FocusTarget` 增 `period-track / main-nav / today-log` 三个只读锚点，供初到三签「指给我看」落到顶栏时段条、六个一级入口与三行日志；只落焦点与朱砂环，不改文书、不写存档。

**卷内书签带（FE-084 · v0.82）：** 释文与对勘这两张「向下读」的长纸，右缘挂一条窄丝带（C-95）：位置随滚动比例走，点一下移一屏、按住可拖、聚焦后方向键 / PageUp / PageDown / Home / End 可移；`role="scrollbar"` 带 `aria-valuenow`。竖排原件是横向长卷，**不挂**竖丝带。丝带只读滚动位置，不改文书内容、版本差异与选证顺序。

**折页与回跳（FE-081 / FE-082 · v0.81）：** 立志纸的「存档案卷」（C-92）复用本章的折页语言：右缘骑缝只作装帧（既有 `seam-half-seal.png`，不作印信）、纸背走 `--paper-grain` 420px 平铺，不新开题签专图。S-02 四视图的跨屏回跳由 C-93 记下离开时的滚轴位置，回来按原位放回——原件、释文、对勘、卷宗各自记各自的位置，只复原滚动，不改视图、不改文书内容、不写存档。

**声音挂点（FE-089 · v0.87）：** 四视图页签挂静态 `data-sound="paper:tab"`，只供未来音频层读取；不改 `onModeChange`、视图状态、证据选中与文书内容。文书本身仍不发声，S-02 的阅读位仍只由 C-95 书签带标记。

**批阅尺与同源批阅签（FE-093 · v0.91）：** 左缘 30px 批注栏升为四段「批阅尺」：竹尺图位（`review-ruler.png` 720×1280 已接入，加载 `data-ruler="art"`；缺图才退回 CSS 素尺并标「素尺」）、朱砂游标、点 / 拖 / 方向键 / Home / End 移焦；`viewMemory` 记 `document-focus`，源选中时可选 `focusHint` 覆盖，普通开卷回上次批阅组。S-05 / S-06 / S-10 挂 C-104b「上次批阅 · 因/略/工/料」小签，只回原组，不改选证顺序、文书内容与判定。≤700px 隐藏竖尺，保留原有批阅步进。

### 6.2.1 文书卷末落款与回卷首（FE-122 · v1.20）

文书面板与底部操作栏之间加一条 `.document-colophon`「卷末落款 · 文书四视图」：`--paper-band` 卷末纸带 + 右侧「回卷首 Alt ↑」。点按或 `Alt + ↑` 只把 DOM 焦点送回 `.document-folio-strip` 的卷首题签，1.2s 朱砂回声自撤；**不切页签、不改批阅焦点、不写存档**。既有 `Alt + ←/→` 批阅步进、`focusOn('document-original')` 路由与 Escape 全局关闭叠层一律不动。390 题签行隐藏时，回卷首落到文书标题 `#document-title`，仍是同一层回声。

### 6.2.2 文书印此页与批阅焦点（FE-124 / FE-125 · v1.22 / v1.23）

文书工具栏在页签与关闭之间加「印此页」，走 `printSurface('document')`：A4 白纸只留标题、当前视图与朱批栏；页签、批阅尺、合卷索引、卷末落款、来源钉与「去看改动」不上纸，选中证据以朱砂下划线示意。竖排原件在纸上与右侧朱批栏并排，释文 / 对勘照原排；当前是卷宗就印卷宗。

**焦点：** 文书的页签、批阅尺、纸签巡览各自已有单一停靠；FE-125 统一了 `a` 与 `summary` 的焦点环，不改 `Alt + ←/→` 批阅步进、`focusOn('document-original')` 路由与 Escape 全局。

### 6.2.3 卷宗封面布面与题签（FE-127 · v1.25）

卷宗封面从「纯 CSS 绿板 + 布面压字」改为一册可读的实物：底材接 PS-21 卷宗布面（`paperArt.casefolder`，深青灰布、四角包角、左缘书脊压痕），缺图保留素布面并标待补，图到位整幅覆盖。

- **题签：** 卷名移出布面，放进独立竖签——PS-15 卷页题签纸转 90°，绫边落到左右，`writing-mode: vertical-rl` 两列右起；朱印退到签右上。窄封面（≤1100）收 86×120、朱印与小注退场、登记行拆两行；390 题签横排一行、四枚小格退场。
- **在卷四类：** 登记行补 `壹贰叁肆` 四枚小格，按四条既有可用状态落朱印（已入卷实、未届虚线），`1 / 4` 计数不变；**只读投影，不是按钮**。
- **装订线：** 从正文容器移回封面本体，线、孔与包边回到左侧书脊，修掉 1024 下压住说明文字。
- **印刷：** 封面退回白纸细框，题签横排 16pt 黑字，四枚小格转朱砂线框，朱印 22mm 静态落右下；布面、包角、缝线与待补小注都不上纸。

### 6.25 S-24 文书三体（FE-040 叠层）

- **三种文书：** 详文（签押后，呈上宪的正式汇报）、禀帖（府札到后，私下短札）、揭（已揭参后的参劾稿）；未满足条件的分签置灰并写明原因，不静默隐藏。
- **只据既有事实：** 渗水四十步、闸底淘深、委牌料夫、会勘、具结、批答；缺一项即留白；页眉标「拟稿 · 未入卷」。
- **交互：** 竖排原件与横排释文互切；右栏「此稿所据」四行（委牌/勘报/批答/具结）并给回委牌、回上宪入口；拟稿不耗时段、不具名、不写存档。
- **入口：** S-15 事务盘「拟详文 · 三日内补报」；不新增一级入口。

### 6.2.4 卷宗目录整页印刷与回那处滚轴（FE-131 / FE-132 · v1.29 / v1.30）

**印目录（C-142）：** 卷内目录头加一枚「印目录」纸签（7px serif + 12px 打印图标，悬停 / 焦点转朱、焦点环同 C-136），走 `printSurface('dossier-registry')`。纸上单页 A4：纸眉「永济县署 · 东堤河工卷宗 ／ 界面 · 只读投影」+「卷内目录」大题 + 四条横排成表（朱砂序号 / 类型 / 题名 / 引称 / 状态右对齐）；选中条只留左缘 2px 朱线。封面 / 流转链 / 查验栏 / 页签 / 批阅尺 / 按钮与「方向键移签」不上纸；非目录兄弟节点 `display:none`（visibility 隐藏仍占纸高）。无标记时 Ctrl+P 不回退目录。四条文案与状态语义逐字未改。

**回那处滚轴（C-143）：** 从账房 / 情报 / 章末 / 案头点「上次批阅」进文书时，App 会话 ref 记来处滚轴；文书内「回那处」换表面后复用 `restoreScrollTo` 复原滚轴，并落一枚 1.2s 归位纸角（与 `returnToSpot` 同源 `echoArrived`）。只存会话内存、刷新即散、不写存档；`reviewTrail.ts` 外存与既有签名未动。

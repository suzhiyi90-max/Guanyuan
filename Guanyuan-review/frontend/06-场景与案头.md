## 二、设计规格

### 6.1 S-01 今日案头

**目的：** 让玩家在 10 秒内知道“今天该先处理什么”。

```
┌──────────────────────────────────────────────┐
│ 第 3 日 · 暮 · 本时段已用  汛期 12 日  [志向印] │
│ 体面线：可见消费 ≈ 月入 60%  [详情]            │
├──────────────────────────────────────────────┤
│ 待决 3 件                                    │
│ □ 呈文：堤身渗水（书办）        [读] [问]     │
│ □ 粮商请见：旧欠 300          [见] [拒]     │
│ □ 士绅帖子：接风宴             [赴] [代]     │
├──────────────────────────────────────────────┤
│ 进行中：抢护 · 工头 · 第 4 日晨完成（占用 2 段）│
├──────────────────────────────────────────────┤
│ 今日三行                                     │
│ 办成：……                                     │
│ 卡在：……                                     │
│ 有人在传：……                                 │
├──────────────────────────────────────────────┤
│ [查账 0] [私访 1段] [写禀帖 1段] [回内宅] [结束今日]│
└──────────────────────────────────────────────┘
```

**组件：** C-02 时段条、C-04 待决卡、C-05 三行日志、C-08 权限/行动坞、C-15 体面线、C-21 志向印、C-22 长动作条、C-39 权界纸（摘要）、C-40 互动坞（三条）、C-48 在场可做题签、C-50 验收条、C-153 在场名帖与接谈纸（FE-145 · 设计定稿 · 待施工）。
**规则：** 待决不超过 5 件；超过则折叠为“其他”；不显示未接触的隐藏事件；**每段只有 1 个实质动作，0 费读取/寒暄不计；长动作占段并显示完成时段；界面任何位置都不出现「行动点」计数。**
**待决（FE-038）：** 急务纸下方加 C-56「今日待决」：只列尚可做的呈文对勘、上宪回文、委牌、接风帖、题销，逐条编号并给一句为什么；已办项折成一行「已办 N 项」，不占版面；点开回原处，不生成新事。
**验收与掌上（FE-034）：** 已验收时，案头在急务纸下方出现 C-50 验收条（现场小图 + 品第 + 症状 + 因果纸入口），未验收不显示；960px 以下案头侧纸不再消失，改为场景右缘的「案头」纸签，打开与桌面同源的同内容抽屉（同一套 props，不另写一份）。
**在场（FE-033）：** 场景左上方加 C-48「此刻在场」纸签，列地点·时辰 / 在场 / 可做。在场只取当日既有公开日程的 `present`，无日程显示「未详 · 不补写」；可做直接列该场景已有的热点，不生成新动作。移动端收敛为顶部窄条，不覆盖热点。
**则例（FE-032）：** 案头侧纸顶行标「界面 · 投影 / 非规则」并挂 C-45 依何条小签，点开 S-12 的 6.7.1 条。
**权界（v0.11/FE-031）：** 案头侧纸按**当前场景**切换有效身份——签押房「正印官」、东堤「河工主持人」、夜书房「官·私第」；只列 能/可/该 各一条摘要与三条原入口，点击展开 S-21。场景一换，身份与可做之事随之改写，不新增权力值。

### 6.1.2 初到三签（FE-083 · v0.81）

**形态：** 案头标题下压一张 334px 宽小纸（390 随掌上案头抽屉同源），纸背走 `--paper-grain` 420px 平铺、左缘 2px 朱线、右上折角。三行朱框汉字编号：

1. **一段只做一件实事** —— 读、看、翻卷、走动不占时段；问人、亲勘、签押才占。
2. **六个入口各管一件事** —— 今日看场面，案卷读文书，事务看几条线在走。
3. **三行日志替你记住** —— 成 / 卡 / 传，夜结算时照见这一天。

**出现条件：** `prologueDone` 为真（已立志进入第一日）且本机偏好 `guide` 未记真；点开志向纸（overlay `goal`）时让位，不压立志纸。

**两条收起路径：** 「知道，不再提示」写 `guanyuan.prefs.read.v1` 的 `guide`，永久收起；「先收起」折成一枚 4px 书签条（`初到 · 三件事`），点条可再展开。折叠只是组件本地状态，两份实例各自折叠。

**不改：** 不生成待办、不推进时段、不落锚点、不改任何既有回调；文案只解释既有界面，不补写人物、事件、传闻与账目。

### 6.1.12 在场名帖与接谈纸（FE-145 · v1.48 · 已施工）

**问题。** C-48「此刻在场」现在只显示当日 `worldEvents.present` 的一行字符串；无公开日程的日子一律「未详 · 不补写」。县衙签押房、东堤、夜书房这三个本来就有常驻人物的场景，画面上因此一个具名的人也没有，也没有从场景里开口的入口——人物互动必须先离开场景、进「人情」、再从名册进人物卷。

**意图。** 把「在场」从一行状态文本改成一排名帖：有具名者在场时逐个列出、可点；点开一张**接谈纸**（只在本屏，不新增 `OverlayId`），在纸内完成「寒暄 / 问三句 / 正式问一回 / 私下说」。接谈纸的第一等信息不是人物数值，而是**公开度**：当众说话，在场者听得见；独对私话，不出此室。

**边界先行：这不是 NPC 日程系统。** 在场只由两件事决定：**已声明的当值位次**（名册职掌 × 时段，含具名与未具名两层）与**当日公开日程**。不做移动模拟、不做随机、不给未具名者姓名与面目；不在场的人不会因为「应该在场」被写进来。

规则：

1. 名帖只列 `people` 里有姓名的六人；衙役、书办、堡夫、船帮、夫役等**不列名、不可点，但计入公开度**（见上表）。不推断他们的姓名、面目或立场。
2. 当日公开日程若与当前场景**同名**（`event.scene === scenePlaces[scene]`），把 `present` 中出现姓名或职掌别名的人并入：别名含 `县丞 / 主簿 / 幕友 / 堡夫头 / 工头 / 粮商 / 士绅`。`reason` 用「公开日程 · {title}」，`source='schedule'`；同人只留一条，**日程优先**。
3. 排序：日程人物在前；其余按品级 / 职掌（县丞 → 主簿 → 幕友 → 堡夫头），同级按名册顺序。
4. 无具名者：若未具名在场 > 0，显示「无可谈之人 · 门外{未具名}（不列名）」；若两者皆无，保留现有「未详 · 不补写」与来源行。不显示空名帖、不显示「0 人」。
5. 投影只读：不写任何状态、不读新字段；`day` / `period` 变即重算。
6. 公开度：`others = 具名在场 - 当前人物`，`ambient = 未具名在场数`；`others.length + ambient > 0` 即当众，否则独对。**未具名者只参与公开度，不进入名帖、不进入“另有 N 人”的具名列表。**

- 第 1 日 午 · 县衙：林绍棠、王慎之 + 书办 2 → **当众**
- 第 1 日 暮 · 县衙：王慎之 + 0 → **独对**
- 第 1 日 夜 · 县衙：0 + 0 → 回退「未详」
- 第 1 日 晨 · 东堤：赵九河、顾逢源 + 夫役 3 · 堡夫 2 → **当众**
- 第 1 日 暮 · 东堤：赵九河 + 堡夫 1 → **当众**
- 第 1 日 夜 · 东堤：赵九河 + 0 → **独对**
- 第 1 日 夜 · 书房：顾逢源 + 0 → **独对**
- 第 3 日 晨 · 县衙：王慎之、林绍棠 + 日程并入顾逢源，+ 书办 2 · 衙役 1 → **当众**
- 第 8 日 晨 · 东堤：赵九河 + 日程工头（去重），+ 夫役 3 · 堡夫 2 → **当众**
- `state.plan` 存在时，东堤 午 / 暮 增加林绍棠（会勘）

**设计节奏（有意为之）：** 白天县衙 / 东堤当众，暮后县衙独对、夜里东堤与书房独对。正式问一回会把时段推进一段，所以「午前当众问过、暮后独对私话」或「东堤问过、夜里书房私话」是自然路径；这不是 bug，是让公开度真正影响玩法。

#### 名帖（在场卡）

- 「在场」行改为纵向名帖列表，每枚 34px 高：`Portrait` 22px（闻名走剪影）+ 姓名 10.5px 宋体 + 职掌 8px + 右端 4px 深度点（闻名灰 / 相识黛 / 共事朱）。
- 卡头右端显示具名人数 `N 人`；名帖下方若有未具名在场，加一行 8px 灰字：`门外：书办 2 · 衙役 1（不列名）`；卡脚改为「依名册职掌与公开日程 · 未具名者只计公开度」。
- 单枚名帖是 `button`，`aria-haspopup="dialog"`，`aria-label="与{姓名}接谈（{理由}）"`。
- **单一 Tab 停靠**：只有活动项 `tabIndex=0`，↑↓ / Home / End 移动焦点并同步 `tabIndex`，Enter / Space 开纸；与 C-136 / C-152 同一口径。
- 悬停 / 聚焦：左侧 2px 朱线、整枚上移 1px；不改变名帖尺寸，不做头像放大。
- 无具名者：未具名 > 0 显示「无可谈之人 · 门外…」，两者皆无保留旧文案与来源行；整块不出现空列表。

#### 接谈纸

居中**纸面弹窗**（不是 `DrawerFrame`，不新增 `OverlayId`）：`min(560px, 94vw)`，`max-height: min(86dvh, 880px)`，内部滚动。

1. **纸头：** 肖像 44 + 姓名 + 职掌 + 品级；右端「合上」图标。视深（闻名 / 相识 / 共事）仍用既有 `revealDepthOf`，不新增档位。
2. **此刻：** `县衙 · 签押房 · 晨` ｜ `当值：主簿 · 掌账库，常在签押房`；若是日程并入，第二行改「公开日程 · {title}」。
3. **公开度带（第一等）：** 见下节。
4. **问三句：** `能不能 / 愿不愿 / 敢不敢` 三枚小签，展开显示 `person.questions` 的 answer 与 basis；`aria-expanded`；不耗时段、不改状态。
5. **谈三法：** 「寒暄一句」（0 费，读）→「正式问一回」主按钮 →「私下说」次按钮（仅独对可用）。
6. **纸脚：** 「看人物卷」（复用既有 `PersonPanel`）、「合上」、来源声明「只据既有名册职掌与公开日程；未具名者只计公开度，不列名、不入回声」。

#### 公开度与回声（核心）

`others = 具名在场 - 当前人物`；`ambient = 未具名在场数`；`mode = others.length + ambient > 0 ? 'company' : 'alone'`。

- **当众（company）：** 朱砂细带。有两种写法：
  - 有具名他人：`当众 · 另有 1 名具名者：王慎之；门外书办 2 · 衙役 1（不列名）`
  - 只有未具名：`当众 · 门外书办 2 人（不列名）`
  后接「你说的话，他们听得见；台账仍只记『问过』，不记原话。」带底 `#a33a2b0d`，边 `#a33a2b33`，字 `#8d3527`。
- **独对（alone）：** 黛青细带：「独对 · 只你与他」+「私话不出此室；不入回声、不入台账。」带底 `#2f48580d`，边 `#2f485833`，字 `#2f4858`。
- **未具名者纪律：** 只给人数与身份类别（书办 / 衙役 / 夫役 / 堡夫），不给姓名、不给面目、不推断立场；他们不能成为名帖，也不进入「另有 N 名具名者」。
- **不新增回声事实：** 「当众」只解释为什么同一句话会被记住，**不向 S-22 加行、不改 `echoesOf`**；私话不写任何状态，因此必然不入回声。若实现方要让它进入 S-22，必须先改存档 schema，属停止条件。
- **文案纪律：** 用「听得见 / 可能被记住」，不用「一定会传开」；用「只在此室」，不用「绝对保密」。不把公开度折算成风评、好感或信任数值。

#### 接谈选项（权力之内）

1. **寒暄一句（读，0 费）：** 展开 `person.quote`（公开言谈）或一句中性应答，只作场面话；**不改状态、不入台账、不入回声**。当众时注明「旁人只当客套」；独对时注明「只在此室」。这是给「闻名」人物也能开口的最低门槛。
2. **问三句（读）：** 三个问题全部取既有 `person.questions`；只展开答案与依据，不新增台词。
3. **正式问一回（写）：** 调既有 `askPerson`。首次耗一段，重复 0 费；台账只记「问过」，不记原话。当众时按钮加「当众」小签，toast 写「在场者都听见了；台账只记『问过』，不记原话」；独对时加「独对」，toast 写「只在此室；台账只记『问过』」。
4. **私下说（仅独对，读）：** 两个子项——
   - **问一句私话：** `revealDepthOf !== '闻名'` 才可用，显示 `person.fear`，前缀「你听出他真正怕的是：」；否则禁用，提示「先正式问一回，才谈得上私话」。
   - **把话挑明：** `person.tokens.hook > 0` 才可用，显示 `person.hookNote`；否则禁用，提示「手里没有可挑明的凭据」。
   - 两项均标「不入台账 · 不入回声 · 不改关系值」，只存组件内会话态（用于「已说过」），卸载即失。
   - **节奏：** 「问私话」要求 `revealDepthOf !== '闻名'`，而正式问会推进一段；所以通常先在白天当众问过，暮 / 夜再到独对场景谈。这个「先公开、后私下」的顺序是有意设计，不做「问完立刻私话」的捷径。
5. **当众禁用私下说：** 整块置灰 + 锁图标 + 一句「当众 · 私话说不得」（当众由具名他人或未具名当值构成），不给替代入口。
6. **不做「请托 / 调夫 / 签押」按钮：** 这些是命令动词，已有委牌、权界纸、六房值房三个正式表面；接谈纸只做寒暄、问与私下说，避免在场景里开第二个命令入口，也避免绕过 `confirmPlan` 与权界判定。

#### 接口（零破坏）

- `ScenePresence` 只加两个**可选** props：`onAsk?: (personId: string) => void`、`onOpenPerson?: (personId: string) => void`；不传则名帖保持只读，旧行为同 FE-033。
- 接谈纸的 `parleyId` 由 `ScenePresence` 内部持有，不升到 `App`，不新增 `OverlayId`。
- 新增 `presentPeopleOf` 与 `ambientPeopleOf`（返回 `{ text, count }`；无人时 text 为空串、count 为 0）；`scenePresenceOf` 可多返回 `people / ambient`，但 `place / present / presentSource / things` 四字段必须原样保留。
- 不改 `askPerson` / `spendAction` / `revealDepthOf` / `echoesOf` / `PersonPanel` 签名；人物卷走既有 `openPerson(id)`。
- 不新增存储 key、npm 依赖、一级入口、美术图位。

#### 视觉

- 名帖：底 `#f7efdfe0`，1px `#c9b99f`；悬停 / 聚焦左侧 2px 朱线 + 上移 1px；姓名 / 职掌按上节字号。

- ≥1220：在场卡 252px；接谈纸 560px。

#### 空态与降级

- 无具名且无未具名：旧文案与来源行原样保留，不显示列表。
- 无具名但未具名 > 0：显示「无可谈之人 · 门外{书办 / 衙役 / 夫役}（不列名）」，不显示「未详」。
- 时段推进导致人物离场：接谈纸立即关闭（不显示过期对象），可 toast「人已不在此处」。
- `presentPeopleOf` 返回空 / 抛错：只影响名帖区，场景、热点与「可做」照常；不得整屏崩。
- 首次进入 / 无存档：按第 1 日晨推导，县衙 2 枚名帖 + 门外书办 2 · 衙役 1。

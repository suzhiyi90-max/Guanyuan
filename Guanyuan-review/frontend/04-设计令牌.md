## 四、设计令牌（Design Tokens）

> 所有值都是提案；M1 先用最小集，M2 再扩。前端不得硬编码颜色/字号。

### 4.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--paper-0` | `#FBF7EE` | 主纸面 |
| `--paper-1` | `#F3EBDD` | 卡片/次级纸 |
| `--paper-2` | `#E8DCC6` | 按压/选中底 |
| `--paper-3` | `#D8C7A9` | 分隔/旧纸边 |
| `--ink-0` | `#1C1A17` | 正文/标题 |
| `--ink-1` | `#2E2A24` | 次级标题 |
| `--ink-2` | `#5A5145` | 辅助文字 |
| `--ink-3` | `#8A7E6C` | 禁用/水印 |
| `--cinnabar` | `#A33A2B` | 印章/批语/当前 |
| `--cinnabar-dark` | `#7E2A20` | 印章阴影/危险 |
| `--indigo` | `#2E4756` | 夜/远山/冷信息 |
| `--celadon` | `#778A7B` | 通过/平静 |
| `--gold` | `#B08A57` | 重要节点细线 |
| `--warning` | `#8A5A2B` | 警示 |
| `--danger` | `#8C2F2F` | 危险 |
| `--success` | `#4F6B57` | 完成 |

**对比度：** 正文 `--ink-0` on `--paper-0` ≥ 12:1；辅助 `--ink-2` ≥ 6:1；朱砂正文 ≥ 4.5:1；暖金只用于 ≥18px 或装饰。

### 4.2 字体

| Token | 字体 | 用途 | 许可 |
|---|---|---|---|
| `--font-doc` | 思源宋体 / Source Han Serif SC | 文书、标题、账册 | OFL，需确认打包 |
| `--font-ui` | 思源黑体 / Source Han Sans SC | UI 标签、按钮、表格 | OFL |
| `--font-letter` | 霞鹜文楷 / LXGW WenKai | 书信、批语、私信 | OFL，需确认 |

**字号（桌面/移动）：**

- 正文 16/28、16/26；文书 17/30；小字 13/20；标题 24/34；大标题 32/42。
- 中文正文每行 28–34 字；最大阅读宽度 680px；文书页 720px。
- 数字：UI 用等宽数字（`tabular-nums`）；文书用汉字数字；必要时提供“释文”对照。
- **最多三套字体**；不再加书法字体。禁止用未授权字库/系统“华文行楷”等做商用。

### 4.3 间距与栅格

- 8px 基准：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 桌面：左导航 88px；中栏 720–880px；右栏 320px；最大 1440px。
- 移动：左右 16px；卡片间距 12px；底部导航 64px。
- 圆角：2px（纸边）/ 4px（按钮）；不用 16px 大圆角卡片。
- 阴影：`0 1px 0 rgba(28,26,23,.08), 0 8px 24px rgba(28,26,23,.06)`；只做纸层，不做悬浮玻璃。

### 4.4 图标

- 24px 网格，1.5px 墨线；对象化：印、笔、账、封、灯、轿、秤、仓、门、书信、算盘、茶。
- 不用通用“齿轮/房子/心形”现代图标；不用彩色填充图标。
- 图标必须有文字标签；不靠图标单独表意。

### 4.5 动效

| 动作 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 纸落下 | 240ms | ease-out | 新文书入场，位移 8px + 淡入 |
| 印章落下 | 180ms | cubic-bezier(.2,.7,.2,1) | 缩放 1.04→1 + 轻阴影，不震屏 |
| 墨迹强调 | 200ms | ease-out | 只给关键词/数字，不做全屏 |
| 面板切换 | 180ms | ease-out | 淡入/轻移，不做 3D 翻页 |
| 减少动效 | 0ms | — | 跟随系统 `prefers-reduced-motion` |

**禁止：** 翻书页 3D、粒子常驻、视差滚动、按钮弹跳、红色闪烁。动画不改变业务状态。

### 4.6 断点

| 断点 | 布局 |
|---|---|
| ≥1440 | 左导航 + 中栏 + 右栏 |
| 1024–1439 | 左导航 + 中栏；右栏抽屉 |
| 768–1023 | 顶部栏 + 单栏；右栏模态 |
| <768 | 底部导航 + 单栏；文书全屏；礼簿横向滚动/卡片化 |
| 最小 390 | 正文 16px；触控目标 44px；无横向滚动（表格除外，需明确提示） |

## 二、设计规格

### 6.19 S-19 舆图 / 县治城郭（M2 纸面预览）

- **三尺度：** S-19 分一县舆图、县治城郭、具体场景；城郭图只做地点索引，不做常驻小地图、自由行走或室内平面图。
- **城郭地点：** 城门、衙署、街市、茶楼、内宅、夜书房、桑宅、码头八处；每处同时有文字标签、认知档位与来源；未接触处保留空态。
- **街市同源：** 街市六处与 S-09 共用同一数据投影；城郭点选同步 S-09 地点、来源与关联网账，回查不耗时段、不伪造抵达。
- **在场边界：** 查验纸按「地点 / 时辰 / 在场人物 / 可做之事」呈现；固定在场、定时来客、无名场面人无来源即留白，不随机生成路人、好感、传闻、消费或地方事件。
- **回查：** 只回到既有街市、内宅、账房、人物、夜宴或场景；跨地行程仍由 FE-025 样纸预览，S-19 全部 M2 纸面投影不写业务存档。
- **美术（FE-033）：** 一县舆图与县治城郭改用既有 `yongji-county-base.png` 清底图（无烘焙文字），城郭为同一抄样的局部放大；原来的手写 SVG 山水与城墙撤除。节点签、路段、认知档位、来源、折页与图例全部保留在画境之上，并明确「节点签只作索引，不作精确定位」。路线文字加浅纸色描边以压住画境对比。抵达样张（FE-035）撤掉 `arrival-landscape` 的手写 SVG 山水，改接既有东堤实景，竖排题签与三个返回入口不变。

### 6.20 S-21 权界纸（FE-031 叠层）

**目的：** 让玩家在一张纸上回答「我能做、可以做、该不该做，以及不同人怎么理解这件事」，而不是把权力写成一条数值。

```
┌──────────────────────────────────────────────────────┐
│ S-21 权界纸 · 只组织既有状态                           │
│ 权与名，都有边界。                                     │
├──────────────────────────────────────────────────────┤
│ 有效身份 = 人物 × 职位 × 场合                          │
│ 正印官 · 永济县知县                                    │
│ [本县签押][东堤河工][夜书房][委牌在手][府衙审查]        │
├───────────────────────────┬──────────────────────────┤
│ 能 / 可 / 该 三层纸        │ 此刻可做 · 互动坞          │
│ 能 做得到吗  可 许不许做   │ 八动词主干：问查托请压保赏荐│
│ 该 该不该做                │ 3–6 个动作：对象/身份/留痕 │
│ 每条带状态与来源            │ /原入口；受阻项给替代路径  │
├───────────────────────────┴──────────────────────────┤
│ 越权留痕：朱砂边线 + 骑缝 + 事件流小签                 │
│ 四类受众回声：[疑点][礼簿][抢护][验收]                  │
│ 四种印象：名望 / 信任 / 畏惧 / 合法性（四签分列）        │
└──────────────────────────────────────────────────────┘
```

- **入口：** 顶栏「权」、S-01 案头侧纸「展开权界纸」、各屏权界摘要。仍是叠层，不加一级入口。
- **能/可/该：** 五个场合各自的六条（每层两条）与 2–3 条禁为权，全部由 `src/power.ts` 从 `GameState` 派生；禁为权每条必给替代路径。
- **互动坞：** 八动词为计数主干，「召/详/征」只作身份权能标签，不构成第九个社交动词；动作只作**原入口索引**，不代执行耗时动作，不写存档。
- **越权留痕：** 只列本局已发生的边界（压案、揭参、无会勘签押、只记未并置的疑点）；无事时保留空态，不伪造示例。
- **回声与印象：** 四类受众（上司/同僚/士绅/百姓）按焦点切换；无来源一律「未详 · 不推断」。四种印象各为离散标签+来源，不合并、不设进度条。
- **则例分界（FE-032）：** 权界纸页脚明确标「界面 · 投影」并挂 C-45「查则例」小签；本页永不标规则，规则只进 S-12。
- **响应式：** 1440 双栏、1024 单栏＋三列权利束、390 全屏纵向；标题不逐字折行，移动端收敛墨色、阴影与纸纹。

### 6.20.1 回卷首与印刷边界（FE-121 / FE-122 · v1.19 / v1.20）

「回卷首」在文书 / 账房 / 章末 / 案头四处统一为 `Alt + ↑`，只移 DOM 焦点、1.2s 自撤、不写存档；**Escape 仍由 `App.tsx` 全局独占关闭叠层，任何新增交互不得抢占或改监听**。案头卷首是栏顶日期，单独回 `.aside-topline` 并滚回 0。印刷侧只改 `@media print`：纸上只留正文与卷首题签，界面索引 / 回原处 / 回卷首 / 栏首小签不上纸；不新增规则表面，S-12 仍是唯一「规则 · 摘录」。

### 6.20.2 印刷与焦点的权界（FE-124 / FE-125 · v1.22 / v1.23）

「印此页」只在文书 / 账房 / 证据链 / 章末四处，按钮只调 `printSurface()`；不新增叠层、入口或业务路径。纸上只印正文与必要印信，界面索引、回原处、回卷首、栏首小签与来源导航不上纸。焦点侧只把纸签族收成单一 Tab 停靠，方向键与点击回调不动；S-12 仍是唯一「规则 · 摘录」表面。

### 6.20.3 在场公开度与回声边界（FE-145 · v1.48 · 已施工）

接谈纸把「谁听得见」做成第一等信息，但**不新增任何回声事实**。这条边界必须先立，否则实现时很容易把「当众」写成一个新的风评来源。

- **当众 / 独对由两层人数决定：** `others = 在场具名者 - 当前人物`，`ambient = 未具名在场数`；`others.length + ambient > 0` 即当众，否则独对。未具名者（书办、衙役、夫役、堡夫）**只计公开度，不列名、不可点、不推断姓名与立场**；他们不是「可能有别人听见」的模糊来源，而是按场景 / 时段写死的当值人数。
- **当众是解释，不是记录：** 公开带只说「你说的话，他们听得见；台账仍只记『问过』，不记原话」；未具名者只出现在人数说明里，不进入回声行、不生成传闻。它**不向 S-22 加行、不改 `echoesOf`、不生成传闻、不提高风评**。同一句正式问话，台账里仍只记「问过」，不记内容。
- **独对是保证，不是数值：** 私话不写 `asked` / `giftEntries` / `clues` / `log`，因此必然不入回声；只存组件内会话态（「已说过」标记），卸载即失。不得把「私下说过」折算成信任、人情或把柄。
- **文案纪律：** 用「听得见 / 可能被记住」，不用「一定会传开」；用「只在此室」，不用「绝对保密」。公开度不是知识四档的新一档，也不是新的关系轴。
- **停止条件：** 若实现方要按公开度改 `echoesOf` 或写入新字段，必须先改存档 schema，**停止并回报**，不得在实现里夹带。

### 6.21 S-12 则例册（FE-032 叠层 · 唯一标「规则」的表面）

**目的：** 把「为什么不能」写成可查的条文，同时把**规则**与**界面投影**彻底分开，避免玩家把纸面查验误认成规则。

```
┌──────────────────────────────────────────────────────┐
│ S-12 则例册 · 规则摘录                 [规则 · 摘录]  │
│ 为什么不能，写在纸上。                                 │
├───────────┬──────────────────────────┬───────────────┤
│ 卷目 六卷 │ 卷一 时段与耗时           │ 本局对应       │
│ 时 权 痕  │ 壹 四时段各一动作         │ 此刻 第四日·暮 │
│ 知 账 声  │ 贰 发起不等于办成         │ 本时段 …       │
│           │ 叁 夜结算与次日晨         │ 当前阶段 …     │
│           │ 正文 / 释文 / 依据条款      │ [界面 · 投影]  │
└───────────┴──────────────────────────┴───────────────┘
```

- **入口：** 顶栏「例」；各处 C-45 依何条小签可直达对应条文；C-46 为什么不能条的「查则例」同样直达。仍是叠层，不加一级入口。
- **六卷十六条：** 时段与耗时 / 权限与身份 / 动词与留痕 / 知识四档 / 账与证据 / 回声与受众。每条含正句、横排释文与**总纲条款依据**，全部为摘录，不新增 D 级条目、不启用新规则或新结算。
- **本局对应：** 右栏只读 `log`、`clues`、`comparisons`、`asked`、`unlocked`、`plan`、`officialActions`、`giftEntries`、`outcome` 与 `taskStageOf`，无依据处留白；与 FE-031 的受众回声共用同一「有据才写」纪律。
- **为什么不能：** 委托缺保正具结、夜宴未入夜两处给出 C-46（原因 + 替代路径 + 查则例 + 骑缝），不改原确认流程、时段与结果。
- **键盘与动效：** 卷目与条文都支持方向键/Home/End，选中共用墨底与朱印；翻卷与侧纸过渡全部接 `useReducedMotion`；390px 卷目改双列、三段纵向连续阅读，标题不逐字折行。
- **投影归属（FE-084 / FE-086 · v0.84）：** 卷内书签带（C-95）只读滚动位置，标「界面 · 只读」；场景热点仍只是既有动作的入口，位置重排与底缘压条不改任何判定与时段。S-12 仍是唯一「规则 · 摘录」表面。
- **新表面归属（FE-081 / FE-083 · v0.81）：** 「存档案卷」只读既有状态并复用 `resetGame`，标「界面 · 只读」；「初到三签」只解释既有界面、不生成待办，标「界面 · 投影」。两者都不是规则表面，S-12 仍是唯一标「规则 · 摘录」的地方；导出不改本档，清档不新增规则。
- **声音挂点归属（FE-089 · v0.87）：** 则例卷目与条文挂静态 `data-sound="paper:leaf"`，只派发提示事件、不接音源、不产生声音；阅览「声」组、归位纸角、最近看过都是界面投影，S-12 仍是唯一「规则 · 摘录」表面。
- **今日动线归属（FE-095 · v0.93）：** S-19 舆图与 S-20 地点场景各加一条 C-106 驿路签，只读会话内 `placeTrail` 的「去过哪几处」，不记里程、耗时、好感，不新增路线、节点或抵达判定；点站只回既有舆图 / 场景 / 街市，标「界面 · 投影」。S-12 仍是唯一「规则 · 摘录」表面。

### 6.23 S-22 因果纸（FE-034 叠层）

**目的：** 让「为什么是合式不是合龙」有据可查，而不是一句考语；只拆已经发生的结算，不预告另一条路。

```
┌──────────────────────────────────────────────────────┐
│ S-22 因果纸 · 只读已发生的结算        [依 10.5]  [×]  │
│ 结果不是一句话。                                       │
├────────────┬────────────────────────┬────────────────┤
│ 果 / 验收  │ 因 / 得失              │ 据 / 回查       │
│  合式      │ 投入 1得0失  [委牌 →]  │ 委牌 有据 回原处 │
│ 第十日题销 │ 资源 1得0失  [料账 →]  │ 料账 有据 回原处 │
│ 症状……     │ 阻力 0得3失  [批答 →]  │ 批答/旧欠/日程   │
└────────────┴────────────────────────┴────────────────┘
```

- **入口：** S-01 验收条、S-15 验收块、S-10 题销册；不新增一级入口。
- **只读：** 因按 `outcome.factors` 原 `label` 分组（投入/资源/阻力），不新增分类、不重算分数；据固定为委牌、料账、批答、旧欠、日程五条，缺则「留白」，回原处复用既有回调。
- **空态：** 未验收时果为「未届」、因为空纸，明示题销未届，不预写结果。
- **掌上案头：** 960px 以下案头侧纸改由场景「案头」纸签打开，内容与桌面同源；390px 因果纸纵向连续阅读。
- **动效：** 入退场与依据切换接 `useReducedMotion`；纸面无新增循环动画。

### 6.10.1 舆图双停靠与焦点环（FE-144 · v1.42）

城郭八处按钮与舆图节点纸签单一 Tab 停靠（方向键 handler 既有）；路段 g[role=button] 选中停靠、未选中首枚留 Tab 入口，方向键 / Home / End 换选中并移焦点（svg 内 rAF focus，不改结构）。焦点环：城郭 / 节点 outline 朱砂；svg g 不渲染 outline，路段用 hit 路径朱砂描边（2.4 / dasharray 2 1.4）。选中语义与既有回调不动。

# 观远 · 发行与上架（TapTap）

> **模块设计单** ｜ 观远 · 互动视觉原型 ｜ **v1.60**（2026-11-11）
> 本轮只定发行形态与上架路径，零代码、零打包、零提交。规则与数值仍以 `设计总纲.md` 为准；本文只回答「以什么形态发、要什么资质、按什么顺序」。

---

## 一、结论

**首发形态：TapTap Windows PC 客户端（Tauri 套壳），挂「开放测试 / 试玩」，不挂正式上线。**

理由三条，缺一不可：

1. **BYOK 只能在客户端成立**。用户自填模型 key，浏览器受 CORS 与存储限制，H5 / 小游戏都过不去；PC 客户端走 Rust 侧请求，key 进系统凭据管理器。
2. **布局已经是对的形状**。左 dock + 宽屏内容区就是桌面形态，PC 首发不需要重做交互。
3. **试玩不需要版号**。单机、免费、无内购，走开放测试即可先拿到真实反馈；正式上线与内购再排版号。

**H5 的定位：宣传页 + 无 AI 试玩。** 保留左 dock 与文书表面的可感知体验，不接模型、不做 BYOK，作为下载前的「摸一下」。

## 二、形态对比

| 形态 | 模型直连 | key 存储 | 与现有代码距离 | 结论 |
|---|---|---|---|---|
| **PC（Tauri / Windows）** | 可以，Rust `reqwest` 不受 CORS | 系统凭据管理器 | 套同一份 `dist`，改入口与打包 | **首发** |
| H5 / WEB | 多数厂家被 CORS 挡 | localStorage 明文 | 直接部署 | 只做无 AI 试玩 |
| Tap 小游戏 | 同 H5，且要按小游戏规范改造 | 同 H5 | 引擎/容器约束多 | 不做 |
| APK | 原生层可转发，但要重做触屏 | Keystore | 390 布局只是降级版 | 暂不做 |

## 三、资质矩阵（按 TapTap 现行规则）

| 游戏情况 | 需要 | 上线形式 |
|---|---|---|
| 联网 + 有内购 | 版号 + 软著 + ICP + 防沉迷 + 隐私 | 正式上线 |
| 联网 + 无内购 | ICP + 防沉迷 + 隐私 | 开放试玩 |
| 不联网 + 有内购 | 版号 + 软著 + 防沉迷 + 隐私 | 正式上线 |
| **不联网 + 无内购（本项目）** | **防沉迷 + 隐私 + 适龄提示 + AI 生成声明** | **开放试玩** |

- 「正式上线」开放下载或内购必须有 ISBN；无版号只能以开放试玩 / 测试 / 预约形式上架。
- PC 免费测试：防沉迷必接，版号不要求，软著建议上传；付费测试必须有版号。
- 具体以开发者后台「计算所需资质」结果为准，本文只作预判。

## 四、上架路径

1. **入驻**：实名 TapTap 账号 → 开发者中心 → 认证开发者（个人可入驻，免费）。
2. **资质**：隐私政策（可访问 URL）、防沉迷（接 TapTap 启动校验 SDK）、适龄提示、AI 生成内容声明。
3. **物料**：图标、≥4 张截图（9:16 或 PC 横版，**不得带其他平台水印**）、简介、标语、标签。
4. **包体**：PC 客户端上传，配置版本与更新规则；先走「内部测试」自测兼容性，再「开放测试」。
5. **提审**：1–3 天；被拒常见原因是截图水印、包体不完整、缺隐私/防沉迷、玩法同质化。
6. **正式上线 / 内购**：确认商业化后再排版号（企业主体、软著、ISBN，周期数月）。

## 五、BYOK 的审核风险

平台可能对「游戏依赖用户自备第三方付费 API」有异议。三条应对，缺一条都可能被驳回：

1. **离线完整可玩**：无 key 走本地叙事，主线、判定、存档全在本地；审核看到的是完整游戏，不是空壳。
2. **商店页明示**：「AI 叙事需自备模型 API；游戏本身不收费、不代收费用、不提供 key」。
3. **提审前先问**：在开发者群或工单直接确认 BYOK 是否允许，别等驳回再改。

## 六、打包与发布

- **壳**：Tauri 2.x，复用 `app/dist`；Win10+ 自带 WebView2；安装包目标 20MB 级，资源另计。
- **请求**：Rust 侧转发 SSE，前端不直连厂家；key 不进前端内存之外的任何持久层。
- **签名**：代码签名证书；签名文件与私钥离线备份，丢失将无法发版更。
- **更新**：Tauri updater + 版本清单；资源热更与客户端更新分开。
- **存档**：写 `%APPDATA%/Guanyuan/`，带 `schemaVersion` 与迁移；导出/导入 JSON 必备。
- **崩溃与埋点**：本地日志 + TapDB；日志脱敏，不记 key、不记 prompt 全文。

## 八、风险与未决

- **版号**：只在正式上线 / 内购时需要；若确定商业化，须提前数月启动，不能等上线后补。
- **BYOK 政策**：平台态度未确认，属最高不确定性；M3 前必须问清。
- **AI 生成声明**：美术为 AI 生成，商店资料与游戏内都要声明；卡框等图上的平台水印必须先清。
- **未成年人**：第三方 API 有额外风险，需年龄提示与家长指引。
- **包体**：现有 44 张 PNG 约 100MB，直接打包不可接受；M2 必须先压到 20–30MB。

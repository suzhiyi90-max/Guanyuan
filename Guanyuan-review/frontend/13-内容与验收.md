## 八、内容、排版与文案

### 8.1 五种文本

| 类型 | 字体 | 排法 | 语气 |
|---|---|---|---|
| **公文** | 思源宋体 | 竖排 + 界格；可切横排释文 | 克制、程式化、少形容词 |
| **批语/朱批** | 霞鹜文楷 | 朱砂、短句、可贴在文书上 | 上司口吻，简短、可被引用 |
| **书信/私信** | 霞鹜文楷 | 横排/竖排均可 | 私人、带情绪、可说谎 |
| **账册** | 思源宋体 | 横排表格/四柱 | 数字准确、术语稳定 |
| **UI 文案** | 思源黑体 | 横排 | 清楚、短、不古风腔 |

**界面说明的边界（FE-083 · v0.81）：** 初到三签、存档案卷说明一类「教怎么看」的文字，只解释既有界面与操作代价（读、看、翻卷、走动不占时段；问人、亲勘、签押才占），不复述史实、不预告结果、不补写人物事件；「知道」只记本机偏好，不改存档。

### 8.2 数字

- **文书内：** 汉字数字（肆仟伍佰两），保留历史质感。
- **UI 内：** 阿拉伯数字（4,500 两），等宽，便于对账。
- **对照：** 文书旁可点“释文”显示阿拉伯数字；不在原文上直接改字。
- **差额：** 只标“差额 300”，不标“贪了 300”。

### 8.3 姓名与官职

- 列表用“短称”（姓名/职衔简称）；详情用全称。
- 长官职换行，不缩小字号；提供 tooltip。
- 不用缩写造词；不把“知县”写成“县令”。
- 人物未知身份显示“？”，不显示“神秘人”之类现代游戏词。

### 8.4 AI 文本

- AI 只做表达层；每句事实性文本必须有 ID 或标“传闻/推测”。
- UI 默认不显示 ID；点“依据”可展开证据链。
- AI 不道德说教；不生成现代词汇/网络梗/表情符号。
- 文本超长时截断 + “展开”；不撑破卡片。
- 关闭 AI 时，模板文本必须完整可玩。

### 8.5 内容长度

| 位置 | 上限 |
|---|---|
| 待决卡标题 | 24 字 |
| 待决卡摘要 | 60 字 |
| 人物卡一句话 | 40 字 |
| 文书页 | 400 字/页 |
| 批语 | 40 字 |
| 礼簿行 | 一行一礼；备注 ≤20 字 |
| 考语 | 一句 ≤40 字 |
| 行状 | 一页 ≤300 字 |

## 十一、M0/M1/M2 交付与验收

### 11.1 M0（纸面，零代码）

- 1 张案头纸、2 份文书（V-001/V-002）、1 张人物卡、1 张礼簿、1 张考语纸。
- **三层验证包（v0.6）：** 章首目标卡、事务卡（≤3）、接触记录卡、章末尾声卡、B+ 时间规则卡、H7 观察表；五路线（政绩/清名/关系/自保/家业）各一套。
- 灰度打印；黑白也能读出层级。
- 3 名测试者；3 秒测试 + 文书找数 + 礼簿找高风险 + 章末目标对账。
- 通过标准：≥2/3 能说出“今天先办什么”；≥2/3 能在 20 秒内找到两个数；≥2/3 能指出一处矛盾；**≥2/3 能说出“本时段做了什么、长动作何时完成”**。
- **H7 加测（40 分钟）：** 五路线中四条成立；每条 ≥2 方案；≥1 次 NPC 自主；≥1 次非行动后果；≥1 次失败恢复；≥1 个长尾。未通过不改代码，只改设计（总纲 18.1）。

### 11.2 M1（可玩纵切片）

- 6 个 P0 屏：S-01/S-02/S-03/S-04/S-06/S-07。
- 章首/章末 S-14（M1 薄片）：目标卡 + 目标对账 + 退路一屏；不铺完整生涯。
- 最小中观 S-15：案卷第二标签，活跃 Case ≤3、阶段、下一检查点；不做完整任务树。
- 4 个叠层：S-05/S-10/S-11/S-13；家人事件用 S-11，不开放完整 S-08。
- 22 个核心组件（C-01..C-16 + C-19..C-23 + C-25）；C-17 用占位；C-18 空状态必做；C-24 仅 M2；token 最小集；桌面 + 移动。
- 无 AI 可玩；关闭模型服务不阻塞。
- 验收：
  - 3 秒测试 ≥4/5；
  - 文书找数 ≤20 秒 ≥4/5；
  - 礼簿找高风险 ≤15 秒 ≥4/5；
  - 权限解释 ≥4/5 能说出“为什么不能”；
  - **B+ 时间：≥4/5 能说出本时段是否已用、长动作何时完成；界面无行动点计数；**
  - **目标：≥50% 能说出自己这一局的目标与开局不同（H7 薄片）；章末对账不评分、不说教；**
  - 知府审查：S-13 至少两类动作改变县级结果，≥4/5 能说出改的是工期/定性/料源/责任/考语；
  - 移动 390 无横向滚动；
  - WCAG AA 关键项通过；
  - 审美 rubric 平均 ≥4/5。

### 11.3 M2（内容版）

- Art Bible、3 张样板人物、4 个空间背景、动效/声音规范。
- 完整 S-08/S-09；S-15 完整版；S-16 政令牌（牌票形态、只能挣得）；人物卡工业化；礼簿/账册扩展。
- S-17 生涯/继承为 M3；M2 只预留字段与纸面样板。
- 资产可追溯（P-14）；字体/图像授权登记。

### 11.4 审美 rubric（1–5 分）

| 项 | 1 分 | 5 分 |
|---|---|---|
| **历史可信** | 明显穿越/影楼风 | 材质、称谓、物件经得起看 |
| **层级清晰** | 不知道先看哪 | 3 秒抓到当前决策 |
| **克制** | 红金满屏/装饰抢戏 | 朱砂只给印/批/关键 |
| **材质一致** | 纸/木/玻璃混搭 | 纸墨印木布统一 |
| **可读性** | 长文难读/对比不足 | 中文长文舒服、可扫读 |

**任何一项 1 分，M1 不通过。**

## 十二、风险与设计债

| 风险 | 症状 | 缓解 |
|---|---|---|
| **古风皮** | 只有纹样，没有官场结构 | 先做纸/文书/印，再做插画 |
| **文字墙** | 一屏几百字，玩家跳过 | 一屏一决策；≤400 字/页；渐进展开 |
| **仪表盘化** | 全是数字/图表 | 用账册/对勘/三数，不用折线图 |
| **抽卡化** | 人物卡稀有度/收集 | 官阶≠精美度；不做抽卡 |
| **移动端不可读** | 竖排+小字+横向滚动 | 横排释文；16px；卡片化 |
| **颜色过重** | 红金满屏 | 朱砂 ≤5%；暖金只做细线 |
| **字体侵权** | 用了未授权字库 | 只用 OFL；法务确认 |
| **AI 文案溢出** | 卡片撑破/事实混乱 | 内容 schema；长度上限；fact/flavor 分离 |
| **UI 泄密** | 显示玩家未知秘密 | knowledge gate；未知遮罩 |
| **动效过度** | 翻页/粒子/闪烁 | 微动效；reduced motion |
| **性能** | 纸纹/大图卡顿 | CSS 纹理；懒加载；预算 |

**设计债登记（v0.2）：**

1. 移动端礼簿表格的横向滚动方案未定（卡片化 vs 固定列）。
2. 长官职（>20 字）在 390px 的换行规则未做压力测试。
3. 色盲模式下朱砂/暖金/黛蓝的区分未验证。
4. 字体打包与授权未最终确认。
5. 竖排文书的标点/数字/英文混排规则未定。
6. 礼簿“高风险”提示的措辞可能过强，需纸面测试。
7. 无 AI 模板文本的覆盖率未统计。
8. `Goal` 已设计 S-14/C-21（v0.6）；仍需 M0 验证章首 5 分钟是否成立；未通过不进入正式主界面。
9. B+ 长动作跨时段的表达已由 FE-021 收敛：S-04 以「发起到执行到验收」时长纸声明，S-15 以晨午暮夜时段带和十日世界时钟投影；只占既有执行窗口，不退回“行动点”隐喻，不改耗时规则。
10. 章末尾声一屏能否同时容纳「目标对账 + 机会 + 退路 + 长尾」未做压力测试；390px 需拆页。
11. 接触记录（C-23）容易变成全知面板；必须挂玩家知情边界，未知显示「？」。
12. 政令牌（C-24）必须像牌票/令，不能像抽卡稀有卡；不做收集册与稀有度。
13. 事务盘 ≤3 的溢出与「不办也推进」提示未定；不能做成任务清单。
14. 人物面板「成长页」完整规格仍待 M0/H7 后推进；S-18 两册材质、收录深度与本地检视已由 FE-019 落地为 M2 预览，完整品类、典藏数据和可核验前代来源仍待后续接入。成长规则来自 `人物系统完善设计-v0.1.md`（已同意）与 `成长系统设计提案-v0.1.md`（候选），不得以预览替代规则验收。

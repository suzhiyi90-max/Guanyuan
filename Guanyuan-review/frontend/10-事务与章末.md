## 二、设计规格

### 6.4 S-04 委托/计划预览

```
┌──────────────────────────────────────────────┐
│ 委托：抢护（示例）                           │
│ 人：工头（能力 4 / 可用）                     │
│ 料：8–10 垛    夫：30–50    期限：3–4 日      │
│ 发起：1 段 · 执行：2 段 · 预计 第4日晨 完成    │
│ 监督：县丞会勘 / 书办点卯                     │
├──────────────────────────────────────────────┤
│ 合法性：合法（先抢后报）                      │
│ 缺口：料 2 垛 · 银 12 两 · 需保正具结          │
│ 风险：闸底仍在；保固只覆盖埽工/护岸            │
├──────────────────────────────────────────────┤
│ [改条件] [换人] [确认]                        │
└──────────────────────────────────────────────┘
```

**规则：** 只提示风险，不预告结果；缺口可点开解释；确认前二次核对预算/期限；**时间用「发起成本 + 执行时长 + 预计完成时段」表达，不用倒计时或行动点；长动作占段后不可再插入同段动作。**
**则例（FE-032）：** 时长纸上方标「界面 · 投影」并挂依何条小签；表单条件不足时先出 C-46 为什么不能条（含替代路径与查则例），再接三层纸。
**权界（FE-031）：** 时长纸下方固定一张 C-39 能/可/该 三层纸（拨料与雇募＝能；三百两以内先行与保正具结＝可；会勘共担与三日内补详＝该），随表单实时改写，取代原四条勾选。选「仅工头监作 · 暂无会勘」时，该栏转为「有险」并出现 C-41 越权条（朱砂边线＋骑缝＋留痕小签）；不改签押条件、二次确认与验收结果。

### 6.10 S-10 考语/行状

- 一页纸：四格（守/才/政/年）+ 实迹 + 风评标签 + 一句考语 + 行状。
- 考语例：“勤勉，然调度未纯。”“才具尚可，河工未固。”
- 行状引用真实事件/承诺/家人；不编造；可分享长图。
- 规则：不显示生成权重；不显示分数；玩家可读、可引用、日后被翻出。
- **则例（FE-032）：** 章末头部挂依 10.5 小签；夜结算纸挂依 9.3 小签，均只回条文、不改结算。
- **收卷（FE-036）：** 「留下的账」页加 C-54 收卷画境（案上合卷与晨光，专图未到时暂借县衙晨光实景），题一句「册子合上以后，县衙照旧开门」。
- **因果（FE-034）：** 题销册得失之后加「展开因果纸」，与 S-15、S-01 共用同一份 `outcome.factors` 与据清单，不改章末结论。
- **印象与回声（FE-031）：** 考语页在实迹与风评之后固定 C-43 四种印象（每条带来源），「留下的账」页固定 C-42 验收回声；名望与合法性可以互相矛盾，不折算成一个总评。

### 6.11 S-11 事件暂停

- 模态：发生了什么、谁在场、你知道什么、三个选项、代价提示（不是结果预告）。
- 不自动计时；不抢焦点；可回到案头再决定（若规则允许）。
- 规则：事件暂停不改变世界状态，只冻结时间。

**事件日（FE-066）：** 事件卡头十日日期签可到世界时钟查验该日，只换查验日、不触发事件；详见 6.32。

### 6.12 S-13 知府审查（M1 叠层）

**目的：** 把「上面能卡我，但不能替我办」做成可操作的界面，而不是多读几份公文。

```
┌──────────────────────────────────────────────┐
│ 上宪来文 · 知府批                             │
│ 准 / 驳 / 查 / 饬 / 存                        │
│ 批语：委员覆勘，料价再核                       │
├──────────────────────────────────────────────┤
│ 可做：委员覆勘 / 调卷 / 传询 / 考语 / 揭参     │
│ 不能：批银 / 改委河厅 / 直接革职               │
│ 影响：工期 / 定性 / 料源 / 责任 / 考语         │
├──────────────────────────────────────────────┤
│ [批] [委员] [调卷] [传询] [考语] [揭参/压案]   │
└──────────────────────────────────────────────┘
```

**入口：** S-01「上宪来文」、S-02 批语、委员到县事件。
**五动作：** 批驳、委员覆勘、调卷/传询、考语、揭参/压案；每个动作显示「他能做/不能做/改变什么」。
**则例（FE-032）：** 「他不能批银 · 不能改委河厅 · 不能直接革职」边界行挂依 6.7.2 小签。
**考语口径（FE-039）：** S-13 的考语措辞与 S-10 章末统一：验收已下时以结果为先（合龙/合式/苟延以下三档），未验收才按计划与会勘判；避免同一局出现两句不同的考语。
**身份与留痕（FE-031）：** 来文上方加 C-39 身份条——此处演示**上宪座位**（知府·府衙），能批驳/覆勘/调卷，可转详加结但不批银、不径改河厅之委；并明示「县尊若站在府衙只是属官」。揭参与压案卡片内嵌 C-41 越权条（朱砂边线＋骑缝＋留痕小签），只呈现既有代价，不改二次确认与动作结果。S-13 仍以原批答六法作文书坞，不另设第二套动作。
**规则：**

1. M1 至少真实触发两类（建议：委员覆勘 + 调卷/传询）。
2. 不显示知府全知；他只依据自己的 K、批语、账册与幕友。
3. 批语入卷；揭参是高风险动作，二次确认；压案会留把柄。
4. 审查结果改变的是县级变量（工期/定性/料源/责任/考语），不是新增阅读量。

### 6.13 S-14 志向 / 章末尾声（M1 章节边界）

**目的：** 让玩家在章首自己定目标，在章末看到目标如何被公事、私事和时间改变；失败不是 GAME OVER。

**章首（5 分钟，纸面/薄片）：**

```
┌──────────────────────────────────────────────┐
│ 第一章 · 到任        书斋夜坐                 │
│ 你这一任，最想留下什么？                      │
│ ○ 政绩（保住东堤，拿到好考语）                │
│ ○ 清名（不沾陋规，账目干净）                  │
│ ○ 关系（站稳河厅/府/士绅）                    │
│ ○ 自保（不出事，平安离任）                    │
│ ○ 家业（私囊/家人/退路）——M1 只薄片           │
│ 自定义：________________（一句话，≤24 字）     │
│ 什么会让你改目标？________________            │
│ [定下]（不占十日时段）                        │
└──────────────────────────────────────────────┘
```

**章末（与 S-10 考语同页）：**

```
┌──────────────────────────────────────────────┐
│ 第十章 · 尾声        你的目标对账             │
│ 政绩：抢护成 / 闸底未修 —— 做到一半           │
│ 清名：拒了 2 礼 / 收了 1 程仪 —— 已有裂缝      │
│ 关系：县丞会勘 / 士绅记恨 —— 一进一退          │
│ 留下：一段埽工、一份揭、一个把柄               │
│ 下一任？[候补] [幕友] [乡绅] [教读] [归隐]     │
└──────────────────────────────────────────────┘
```

**规则：**
1. 章首 Goal 不占十日时段；只记录类型、一句话、优先级、复核点、可见性（私有）。
2. 章末逐条对账：做到/没做到/被什么改变；**不评分、不给“正确目标”**。
3. 机会（Opportunity）在章末以「风闻/举荐/空缺」呈现，必须附来源；不随机刷新。
4. 失败退路是选择，不是惩罚页；每条退路显示保留什么、失去什么。
5. 志向印在章节内可回看，但不显示隐藏进度条；NPC 不知道玩家 Goal（除非玩家说出）。

**页序脊（FE-067）：** 章末四页左缘固定页序脊与骑缝，半印待图、不以代码补画；详见 6.32。

**页缘书签带（FE-084 · v0.82）：** 章末四页的 `.career-page` 比屏高时，右缘挂一条窄丝带（C-95），随页内滚动定位；只读滚动位置，不改四页内容、页序与对账。

**存档案卷（FE-081 · v0.79）：** 立志纸底部压角折页（C-92）：黛墨「存」印 + 四行只读现状（志向 / 私囊 / 疑点 / 抢护）+ 两枚处置（导出底稿 · 只读下载；清空重立志 · 两段落印，8 秒不按自撤）。清档复用既有 `resetGame`，不设多档位、不改存档结构；页脚常写「本机一档 · 无云端」。

**三向对读与同源批阅签（FE-092 / FE-093 · v0.91）：** 「留下的账」页以 C-103 整页承接账 / 疑 / 礼：账列 4,500 / 4,200 / 300 报部待定，疑列 `state.clues` 最近两条与来源，礼列 `state.giftEntries` 最近两笔与私囊余数；三列各给回账房 / 回情报 / 回礼簿。页顶挂 C-104b「上次批阅」小签，点开回卷宗原组。只读、不评分、不新增账目或礼数；三栏对读纸专图已接入，缺图时才退回旧纸并标「暂借旧纸」。

**章末风闻行迹（FE-094 · v0.92）：** 「留下的账」页在整页对读之外加 C-105 竖排三站：街市茶楼「转述 · 只听见有人这样说」→ 情报「听说 · 未核实」→ 章末「风评 · 仍无凭据」。当前站禁点，街市 / 情报两站可回原处，末站不改写成事实；只读 `state.log.rumor`，不新增传闻、证据或判定，也不替代三向对读。

### 6.14 S-15 事务盘（M1 最小 / M2 完整）

**目的：** 让「同时办几件事」成为策略，而不是任务清单堆叠。

```
┌──────────────────────────────────────────────┐
│ 事务（2/3）                    [+ 开新案]     │
│ ● 河工案 · 办 · 工房 · 第10日验收             │
│   抢护（执行中，第4日晨） · 题销（未起）       │
│   偏差：料少 2 垛 / 书办说“够用”               │
│ ○ 接风宴 · 谋 · 人情 · 无期限                 │
│   已赴 / 礼簿 3 笔 / 欠士绅 1                  │
│ 提示：不办也会推进；第8–9日暴雨                  │
└──────────────────────────────────────────────┘
```

**规则：**
1. 活跃 Case ≤3；超过时不给「+」，要求先结/搁置，并显示搁置后果。
2. 生命周期：起 → 查 → 谋 → 办 → 验 → 结；每案当前阶段只有一个。
3. 任务异步：显示执行人、下一检查点、预计完成时段；**不把「提交委托」显示成「已完成」**。
4. 不办也推进：每案显示「若不管，下一次变化在何时」；不显示精确结果。
5. 偏差必须可见（人/料/钱/期限/信息），归因不预设腐败。
6. M1 只做河工案 + 1 条世俗/词讼支线；完整任务树、六房分工、政令牌留 M2。
7. **则例（FE-032）：** 十日世界时钟标题挂依 9.1 小签，回到「发起不等于办成」条文。
8. **因果（FE-034）：** 验收块保留品第、症状与前三条得失，其余折为「另有 N 条在因果纸」，并给「展开因果纸」入口；不重算分数、不预告另一条路。
9. **回声与留痕（FE-031）：** 右栏在世界时钟之后固定 C-42 抢护回声（上司看勘报、同僚看会勘栏、士绅不涉土源即留白、百姓按 P-009 工食口供给「怨」）；委牌无会勘时，任务卡内出现 C-41 无会勘条。

**十日时钟（FE-066）：** 接受事件卡深链查验日；事件日显示状态，待决时才给事件卡入口；详见 6.32。

### 6.14.1 跨屏回跳（FE-080 · v0.78）

凡从章末四页、三行日志、世界事件卡跳去别处，都在底部左缘留一枚 `回 · 上一处` 纸签：只记「来处名称 + 当时 overlay + 当时 section」，点一下回到原表面并自收起；切一级入口即清空。纸签不恢复滚动位置与内部焦点，不推进时段、不触发事件、不写存档。390 下移到 12px / 74px，叠层打开时隐藏（`data-overlay`）。

### 6.14.2 回跳复原（FE-082 · v0.80）

**补的是 6.14.1 自己写下的那句「不恢复滚动位置」。** `returnSpot` 增两项：`detail`（来处小节名）与 `scrollTop`（离开时来处的滚轴位置）。滚轴认法：叠层内取第一个真正可滚的纸卷（`.drawer-scroll` / `.document-panel` / `.career-page` 等），退到案情区则认 `.workspace`；都没有就记 0。

**纸签两行：** 首行仍是「回 · 来处」（章末四页 / 三行日志 / 世界事件卡），次行写小节——章末八类落点分别写「案卷 · 原件 / 证据链 / 事务盘 · 十日时钟 / 上宪批答 / 礼簿 / 情报台账 / 账房 · 三数 / 因果纸」，三行日志写「事务盘 · 十日时钟 / 案卷 · 原件 / 情报台账」，事件日写「第 N 日 · 十日时钟」。

**复原：** 回跳后自 70ms 起、每 60ms 重试至多 16 次，落点误差 ≤2px 即停；只复原滚动，不复原内部焦点、页签与筛选档，也不推进时段、不写存档。

### 6.14.3 页签记忆与归位纸角（FE-090 · v0.88）

事务盘「在办 / 政令 / 六房」三视图走既有 `viewMemory`，离开再回不丢页签；事件日深链仍在 `clockRequest` 时强制回「在办」，只换查验日、不改日程。回跳纸签点击后，落点左下换一枚 1.2s「已归位 · 小节」纸角（纯文字 + 折角 + 2px 朱线，不画印），减少动效即时；只说明看见了，不推进时段、不写存档。

**声音挂点（FE-089 · v0.87）：** 事务盘三视图页签挂静态 `data-sound="tab:affairs"`，章末四页挂 `data-sound="page:turn"`；只供未来音频层读取，不改视图、页序、批答与结算。

### 6.14.4 章末卷末落款、印刷校样与事务盘空态（FE-121 ~ FE-123 · v1.19 ~ v1.21）

章末每一页底部加 `.career-colophon`「卷末落款 · 章末四页」，与文书 / 账房 / 案头同族；点按或 `Alt + ↑` 只把焦点送回章末大题签、1.2s 自撤，不切页签、不关章末。印刷只改 `@media print`：正文、卷首题签、四格、实迹、对账、三向对读与卷末落款上纸；页签、页序脊、合卷索引、回原处 / 回卷首小签、栏首小签、画境板、`C-16 考语纸` 编号与暂借标记不上纸。A4 版心约 680px 会触发 ≤700 断点，print 规则强制四格 / 对账两列、行状两栏、对读三栏，并补 `break-inside` / `orphans` / `widows`。事务盘「并置牌案」空态套 `.empty-slip`，句子未改；带动作的大空态不套小签。

### 6.14.5 章末焦点秩序（FE-125 · v1.23）

章末的顶部四页签保留 roving `tabIndex`（仅当前页 0），右侧页序脊的 4 枚按钮退出 Tab 序列——它和顶部页签是同一功能，键盘用户不必再穿一遍；鼠标点击仍照旧切页。风闻当前站补 `aria-current="location"`；卷末落款与回卷首的焦点环沿用既有朱砂。Escape、`Alt + ↑` 与既有焦点路由一条未改。

### 6.14.6 章末印全卷（FE-129 · v1.27）

「印此页」旁新增「印全卷」（桌面）：四页正文共用同一份 `renderRecordPage`，印全卷把考语 / 行状 / 志向对账 / 留下的账并到屏上隐藏的印刷叠层，每页开头一行小页眉「第 N 页 · 某某」、一页一纸；点按后约 0.9s 送打印，`afterprint` / 兜底计时即拆叠层、撤标记，屏上始终只见当前页。页签、页角折签、卷末落款照旧不上纸；「印此页」单页路径原样保留，`Ctrl+P` 不受影响。

**边界：** 不改四页文案、页序与判定；行状实迹的展开仍以屏上所选为准；390 头部容不下，不提供「印全卷」。

### 6.14.7 印刷族收口与回那处滚轴（FE-131 / FE-132 · v1.29 / v1.30）

### 6.14.8 夜结算画境与三行回查（FE-135 · v1.33）

### 6.15 S-16 政令牌（M2）

- 形态：**牌票/令**，不是稀有卡；无边框发光、无星级、无抽卡动画。
- 来源：只能由事件/考语/关系/章末结算挣得；每章/季 1–2 张；可排序、可组合、有生效时段。
- UI：牌面写「能做什么/何时失效/代价」；不写稀有度；不进入收集册。
- 规则：政令牌不替代权限链；不能凭空批银、越权、改事实。

### 6.16 S-17 生涯 / 继承（M3）

- 一页「卷宗合上」：家族、门生、著作、碑记、口碑、旧案六格；只显示已发生事件。
- 继承不是数值转生：下一任能遇到旧案、旧人、旧碑；不能直接继承官职/银两。
- 规则：Legacy 只消费事件流；不编造未发生的功绩；不做“转生刷点”。

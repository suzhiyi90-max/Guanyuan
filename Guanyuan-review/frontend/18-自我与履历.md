## 一、模块范围

- **覆盖范围：** 玩家自我汇总表面 S-25「自我 · 履历」：身份印带、权 / 财 / 望三组属性投影、积累墨点带、卷末落款；底栏第八枚叠层触发钮「自」。
- **涉及屏幕：** S-25（候选，叠层）。
- **设计命题：** 身份感 / 权力感 / 成就感来自**已发生之事的汇总与装裱**，不来自新数值：官身小像 + 竖签 + 只盖已发生的印带给出身份；能 / 可 / 该三层给出权力；墨点积累给出成长（积累不是进度条）。
- **状态：** 见下方「实现清单」；规则与数值以《设计总纲》与 M1 事实图谱为准；本表面一律标「界面 · 投影 / 只读」。

## 二、设计规格

### 6.18 S-25 自我 · 履历（FE-146 · v1.45 · 已施工）

**入口（用户指定放底栏最下边）：** 底栏第八枚按钮「自」（`UserRound` 图标 + 10px 标签），与情报钮同类的**叠层触发钮**：`onClick` 置 `overlay='profile'`，不占六分节一级入口、不改六入口顺序与回调、不加 nav-notice 计数。390 八枚均分 ≈48px/枚，命中 ≥44 由既有 `(hover:none)` 规则保；桌面底栏同排末位。`aria-label="打开自我履历"`。

**表面形态：** 竖幅履历 folio（`profile-folio`，C-154），宽 `min(760px, 96vw)`、390 全屏 `100dvh` 滚动；底材 PS-28 `profilebase`（cssFallback：缺图保留素纸 + 旗标 + 右下暂借小注，小注 bottom 48 让开合上钮）；`useOverlayDialog` 焦点 trap；Escape 走全局关闭；**不进打印族**（print 下 `display:none`，印刷方向已收口不再扩）。

**段一 · 身份印带（C-155）：** 左 PS-29 官身小像框（竖 3:4，缺图 fallback 素框 + 「官身小像待补」小注，不代码画人像）；右竖签「永济县知县」（既有文案）+ 横排三小签：任内「第 N 日 / 十日之任」（`state.day`）、洪峰「第 9 日汛 / 余 M 日」（既有 `9 - state.day` 口径）、当前场景身份（`powerContexts` 当前 context 名）。**志向印**复用既有 goal-seal 字印（`goals[goalId].seal`），未立志留素印位标「尚未立志」。**印带只盖已发生**：立志（`goalId`）/ 抢护发起（`plan`）/ 验收（`outcome`）三枚条件印，无则留白不补刻；印只作装帧投影、不作判定。

**段二 · 权 · 能/可/该：** `entitlementsOf(state, 当前context)` 三层各一行计数 + `verbCounts` 动词摘要（既有派生函数，只读）；三行作官牍条层叠装裱；行末「回权界纸」签复用 `focusOn('power-folio')` 路径（先 `setOverlay(null)` 再开权界，同抽屉内跳转纪律）。

**段三 · 财 · 银与料：** `privateFunds` 两、`material` 三数（应到 / 在途 / 未发口径同 S-06）、`giftEntries.length` 笔、体面线既有摘要函数投影；「回账房」「回礼簿」签复用既有 locate / 分节跳转。

**段四 · 望 · 四印象：** `impressionsOf(state)` 四行（名望 / 信任 / 畏惧 / 合法性）既有标签逐字投影；考语品第取 `outcome.grade`，`outcome` 为 null 标「未届考语」留白（不预写）；「回考语」「回权界」签。

**段五 · 积累 · 墨点带（C-156）：** 六组墨点 = 入卷 `officialActions.length` / 记疑 `clues.length` / 并置 `comparisons.length` / 接触 `asked.length` / 证据 `unlocked.length` / 处事 `handledEvents.length`；每组墨点封顶 10 枚 + 数字签（超出只加数字不加点），组签可点回源（S-14 / S-05 / S-06 / S-03 / S-05 / S-11 既有入口）；**墨点随玩而积、刷新不散（来自存档既有字段），不是进度条、不折算数值**。

**卷末：** 落款 + 「回卷首 Alt ↑」复用 C-133 同源回声；合上钮「合上履历」右下。

**交互秩序：** 五段锚签（身份 / 权 / 财 / 望 / 积累）单一 Tab 停靠 + 方向键 / Home / End 巡览（C-136 族）；回源签只换表面与焦点、不推进时段、不写存档；减少动效直达；触控命中 ≥44（hover:none）。

**不改：** 六分节入口、业务数值、时段耗时、热点回调、动作结果、阶段判定、存档结构；零既有 props / 回调签名改动；不新增存储 key（阅读记忆仍只在内存）；S-12 仍是唯一规则表面。

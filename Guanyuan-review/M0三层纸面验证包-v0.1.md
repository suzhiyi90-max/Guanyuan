## 二、主持人规则卡（B+）

1. **每段 1 个实质动作。** 实质＝产生新证据/承诺/债/文书/资源变化/暴露/任务，或推进任务/期限。
2. **一次社交动作＝与一人在一场景一轮交谈；** 多句不算多次；换人/换主题且产生新证据或承诺才算新动作。
3. **0 费：** 看已读文书、看人物卡、重复已得口供、场景内寒暄（无新信息/承诺）。
4. **长动作占段：** 声明 N 段，期间不插入另一实质动作；任务执行异步，发起后可做别的。
5. **等待/模型延迟/事件暂停不推进世界。**
6. **结算顺序（10.6）：** 命令校验→原子提交→推进时段→到期任务→环境/制度→NPC 日程→认知传播→期限/债务→事件导演→夜间/跨日→视图刷新；同刻稳定排序；重放不重复扣。
7. **责任共担（6.6）：** 先抢后报+程序齐备→共担/减轻；隐瞒/越权/无留痕→独担；定性权在上级。
8. **越权拦截给替代路径**（拆分/请批/换名义/找人代行），不给红叉。
9. **NPC 会自己行动**（见第三节）；玩家不处理，世界仍推进，但不无故惩罚。
10. **阅读税：** 决策数 ÷ 新增文书数 ≥1；单场景 ≤2 页。

## 五、卡片模板

### 5.1 目标卡（Goal，章首）
```
类型：政绩 / 清名 / 关系 / 自保 / 家业 / 自定义
一句话：我要……（≤24 字）
优先级：1–3    视野：本章
成功信号：……（可观测，非数值）
失败信号：……
复核点：第 5 日 / 章末 / 重大事件后
可见性：私有（NPC 不知，除非你说出）
状态：active → revised / achieved / failed / abandoned
```

### 5.2 事务卡（Case，≤3 活跃）
```
案名 / 类型（河工/词讼/世俗）  阶段：起→查→谋→办→验→结
主办 / 协办    期限 / 下一检查点
任务：执行人 · 发起成本 · 执行时长 · 预计完成时段
偏差：人/料/钱/期限/信息（不预设腐败）
若不管：下一次变化在何时（不办也推进）
```

### 5.3 接触记录卡（Exposure）
```
谁 · 何时 · 何渠道（亲见/转述/文书/推断/传闻） · 接触到什么（F/P/E/V）
接触理由    已读? 已懂? 已信?（分开，不自动推论）
玩家可见性：仅玩家可知的接触；未知显示「？」
```

### 5.4 礼簿 / 账册
- 礼簿：日期/送者/礼物/估值/事由/见证/回礼/状态（未回/已回/高风险）。
- 账册：账面 4,500 / 实收 4,200 / 差额 300；料 30/10/10；报部二选一。

### 5.5 尾声 / 退路卡（章末）
```
目标对账：做到 / 没做到 / 被什么改变（不评分）
留下：工程/文书/债/把柄/口碑（长尾）
若溃口/参劾：退路 1–2（幕友/乡绅/教读/归隐）——保留什么 / 失去什么
```

## 七、五路线桌面复跑（v0.6.2）

> 每条给出：目标、≥2 方案、关键日段日志（B+）、NPC 自主、非行动后果、失败+恢复、长尾、考语、资源差。实质动作数为整十日合计；其余时段由 0 费读取/场景对话填充。

### 7.1 路线 A · 政绩优先

**Goal：** 堤成 + 可写进考语的实迹；不因 300 被参。
**方案 A1（抢护做平）：** 亲勘→抢护→300 做平→保固。成本低、风险在保固/审计。
**方案 A2（抢护自曝）：** 亲勘→抢护→自曝 300→请还。成本在关系/工期，守格更稳。两方案在「守」措辞与粮商反应上实质不同。

| 日/段 | 行动 | 成本 | 反应/约束 | 结果 |
|---|---|---|---|---|
| D1 晨 | 亲勘 40 步 | 1 段 | 书办紧张 | F-001 |
| D1 午 | 问专家 | 1 段 | 要你亲挖 | 闸底嫌疑 |
| D1 暮 | 探挖 | 1 段 | 工头确认 | E-007 |
| D1 夜 | 接风宴 | 1 段+20 两 | 士绅/粮商/县丞 | 旧欠/坟地线索 |
| D2 晨 | 召县丞/主簿 | 1 段 | 县丞要会勘 | 20 堡夫/5 河兵 |
| D2 午 | 写详文报险 | 1 段 | 知府批/委员 | V-004；责任留痕 |
| D2 暮 | 募夫 50 | 1 段+25 两 | 保正具结 | 夫到位 |
| D3 晨 | 启动抢护（长动作） | 发起 1 段·执行 2 段 | 工头；8–10 垛 | 任务异步开始 |
| D3–D8 | 巡堤/监督/委员 | 每日 1–2 段 | 暴雨 D8；委员 D5 | 进度/损耗 |
| D9 | 洪水 | — | 抢护顶住 | 堤在 |
| D10 | 验收/题销/考语 | 1–2 段 | 做平 or 自曝 | 保固一年 |

- **实质动作 ~24**（≤40，不过紧/不过空）。
- **NPC 自主：** D3 玩家忙抢护未理粮商 → 粮商扣最后 10 垛（EV-06）。
- **非行动后果：** D4 玩家未拜士绅 → 士绅传「官堤占坟」谣言，风评−。
- **失败+恢复：** 若委员延迟+料不足→抢护受阻→D9 溃口（EV-12）；因报险+会勘+具领留痕齐备，按 6.6 共担/减轻；尾声卡给「揭主簿追赔 / 借银补修 / 降调留任」三选一，非重试。
- **长尾：** 保固一年内冲决加重；离任审计翻 300；粮商债。
- **考语（7.2）：** 做平「才具开展，操守平常」；自曝「才具开展，操守尚可」。
- **资源：** 私囊 60→40；公帑 −25 两（夫食）；料 −8–10 垛；300 未还（A1）/请还（A2）。

**Goal：** 查明并揭报 300；不背黑锅；堤尽量保。
**方案 B1（先揭后工）：** D2 揭报→主簿反咬→抢护紧。清名快、工期险。
**方案 B2（先工后揭）：** 抢护成→D8 揭报→证据稳。工期稳、清名晚、被议「养痈」。两方案在工期/关系/措辞上不同。

|---|---|---|---|---|
| D1 晨 | 亲勘 | 1 段 | — | F-001 |
| D1 午 | 查账 | 1 段 | 主簿知你在查 | E-001 |
| D1 暮 | 问书办 | 1 段 | 怕担责 | E-002 线索 |
| D1 夜 | 查借领状 | 1 段 | 主簿警觉 | 300 去向 |
| D2 晨 | 问主簿 | 1 段 | 否认/试探 | P-003 |
| D2 午 | 找粮商 | 1 段 | 要债 | E-003 |
| D2 暮 | 写揭报 | 1 段 | 知府可能压案 | V-015 草稿 |

- **实质动作 ~22。**
- **NPC 自主：** D4 玩家专注核账 → 主簿自行改借领状（被接触记录卡抓到，Exposure 留痕）。
- **非行动后果：** D5 玩家未安抚士绅 → 士绅上控「苛查扰民」。
- **失败+恢复：** 知府压案+报复→工期延误→溃口；清名不能免参，但揭报留痕使「守」不被抹黑；尾声卡「以幕友身份继续查弊 / 教读著书立说」，清名转化为门生/著作长尾。
- **长尾：** 清名被引用；主簿仇恨；升迁慢；离任审计干净。
- **考语：** 「守洁可风，才具平常，调度未免拘谨。」
- **资源：** 私囊 60（不宴不礼）；公帑 −25 两；可能 −300（退赔）；料 −8–10 垛。

- **NPC 自主：** D6 玩家未续人情 → 粮商按 Intention 找士绅抬价（关系网内部自行博弈）。
- **非行动后果：** D7 玩家未践「修渠」承诺 → 士绅记一笔，风评「圆/滑」。
- **失败+恢复：** 网络反悔/士绅上控/粮商断料→溃口；债主反噬；尾声卡「以乡绅身份调解捐输 / 合伙行账」，关系网换账本继续。
- **长尾：** 人情债、礼簿、Secret/Hook、风评「奢/圆」；下次调任/修渠/婚嫁被索取。
- **考语：** 「才具开展，颇事应酬，操守不无可议。」
- **资源：** 私囊 60→25；借 300；公帑 −25 两；料 −8–10 垛；人情债 2–3 笔。

### 7.4 路线 D · 保全自身（v0.6.2 闭合）

**Goal：** 责任分明、不被参；堤溃也不背全锅。
**方案 D1（程序共担）：** 早报险→拉县丞会勘→主簿具领→请委员→保守抢护。责任摊开，政绩低。
**方案 D2（明哲保身）：** 只报险不冒进→把难题推河厅→记录留痕。更安全，考语「无担当」更重。两方案在责任摊开程度/考语/机会上不同。

| 日/段 | 行动 | 成本 | 反应 | 结果 |
|---|---|---|---|---|
| D1 晨 | 读呈文 | 0 段 | — | 知渗水 |
| D1 午 | 写详文报险 | 1 段 | 知府批/委员 | V-004；留痕 |
| D1 暮 | 请委员会勘 | 1 段 | 知府派员 | 责任分担 |
| D1 夜 | 不赴宴 | 0 段 | 士绅不满 | 风评− |
| D2 晨 | 县丞会勘/主簿具领 | 1 段 | 签字留痕 | 共担链成立（6.6） |
| D3 | 启动保守抢护 | 发起 1 段·执行 2 段 | 工期紧、不冒进 | 进度慢 |
| D3–D8 | 记录/复核 | 每日 1 段 | 暴雨 D8 | 留痕完整 |
| D9 | 洪水 | — | 堤险/溃 | 结果 |
| D10 | 考语/题销 | 1–2 段 | 责任分担 | 「谨慎，然无担当」 |

- **实质动作 ~18。**
- **NPC 自主：** D4 玩家不接触粮商 → 粮商扣料放风；县丞按 Intention 先报河厅（责任链再增一环）。
- **非行动后果：** D6 玩家未催料 → 在途 10 垛延误，工期更紧（世界自走）。
- **失败+恢复（关键闭合点）：** 若溃口，因报险+会勘+具领+委员留痕齐备，按 **6.6 共担/减轻**，不独坐知县；知府定性为「公罪/共担」而非「私罪/侵欺」；尾声卡「降调留任 / 候补 / 幕友」可继续。**自保路线不再依赖未补规则。**
- **长尾：** 安全但无政绩；机会少；清名/懦名；闲职。
- **考语：** 「办事谨慎，然担当未足，才具尚待历练。」
- **资源：** 私囊 60；公帑 −25 两；料 −8–10 垛；不接礼；300 不碰。

### 7.5 路线 E · 家业（M1 薄片，不计入四条门槛）

**Goal：** 借河工建私产/联姻/人情；不破产；堤尽量保。
**方案 E1（收礼周转）：** 收士绅/粮商礼→私囊+→雅贿。风评奢/贪、把柄多。
**方案 E2（拒礼保身）：** 拒礼→靠家用/门包节流。私囊紧、风评清。M1 只有 1 家人事件+礼簿，**不能完整验证**；置产/内宅/贪腐链 M2。

- **实质动作 ~15；NPC 自主：** 仆人收门包虚报（D7，内宅 Intention）。
- **非行动后果：** 玩家不管家用 → 妻族招摇，风评−。
- **失败+恢复：** 礼簿暴露/被参→抄没风险；尾声卡「归隐著述 / 商合伙」（M2/M3 才完整）。
- **长尾：** 礼簿/Secret/贪腐链；家族。
- **考语：** 「才具尚可，操守平常。」
- **资源：** 私囊 60→15；公帑 −25 两；料 −8–10 垛。
- **结论：** 薄片成立、可跑，但**不作为 H7 四条门槛之一**；M2 完整验证。

## 十、玩家 M0 执行脚本（交真人，turnkey）

**分组：** 3 组 × 3 人；每组跑 2 条路线（共 6 次）+ 1 次「无目标」对照。
**每条 40 分钟：** 5 分钟定 Goal（章首卡）；30 分钟跑十日（B+ 规则卡 + 七人 Intention + 事件卡）；5 分钟复盘（尾声卡）。
**主持人：** 只扮 NPC 与规则，不替玩家选目标；允许说谎/拒绝/拖延；照 Intention 推进自主行动。
**记录表：** 日/段 · 玩家行动 · 成本 · 约束 · NPC 反应 · 世界变化 · 账/关系/风评 · 备注。

**复盘 7 问：**
1. 你的目标是什么？什么时候改过？
2. 你有两种以上方案吗？为什么选这个？
3. 哪个 NPC 拒绝/拖延/自己行动了？
4. 你哪天没行动？世界发生了什么？
5. 结果和另一条路线有什么不同？
6. 如果溃口，你还能怎么玩？
7. 你想再玩哪条路线？为什么？

**玩家通过标准（总纲 18.1）：** ≥2/3 能说出目标与代价；四条路线成立、每条 ≥2 方案；≥1 自主/非行动/恢复/长尾；场景锚点 3–6，不出现菜单大厅。**玩家未通过 → 改设计，不写代码。**

## 八、人物分类与社会关系网络补充验证（v0.14 候选，零代码）

> 本节只增加纸面验证任务，不增加人物数量，不把尚未证实的关系写成世界事实。所有关系必须回到当前场景事实、事件、文书或明确设定来源；没有依据的格子标「未知/待设定」，不得为了图谱完整而补造。

### 8.1 先拆清四种东西

主持人给玩家看人物名帖后，要求其分别识别：

1. **人物是谁：** 独立个体，不等于某一类别。
2. **人物有什么身份：** 社会身份、制度资格、家庭出身、组织归属、当前处境可以并存。
3. **人物与谁有什么关系：** 同一对人物可有多条关系，且双方态度未必一致。
4. **人物属于什么组织：** 组织成员身份与个人交情、正式职务分开。

本局七人配置是测试样本，不得称为七种人物分类。六类身份粗分仅用于 M1 权力权限校验，不构成社会分类总表。

### 8.2 人物网络事实盘

以既有七人 Intention 表及知府影卡为样本，主持人先从总纲、M1 事实图谱和本验证包抽取已明确的身份、职务、目标、利益、承诺、事件接触与信息来源，再填下表。不得把「目标相近」直接写成盟友，不得把「同场出现」直接写成朋友，不得把「利益冲突」直接写成政敌。

| 人物 | 已明确的当前身份/职务 | 已明确目标/利益 | 已确认关系与来源 | 未知/待设定 |
|---|---|---|---|---|
| 县丞 | 佐贰官 | 保河厅关系、不担责 | 逐条引用既有设定/事件 | 家族、师承、同年等无依据信息 |
| 主簿 | 主簿/钱谷经手 | 掩盖 300、保位 | 逐条引用既有设定/事件 | 与其他人物的私交、宗族关系 |
| 粮商 | 粮商 | 收回 300、做生意 | 债务/供料事实须核对证据 | 派系、师承、亲缘 |
| 士绅 | 地方士绅 | 保坟、保面子 | 宴席、捐输、坟地争议等事实 | 与其他人物的亲属/秘密关系 |
| 专家 | 河工专业人士 | 判断被采纳、保名声 | 献策、勘验等已发生互动 | 官场师承与同年关系 |
| 工头 | 工头/执行者 | 工钱、性命、被看见 | 河工委托与执行关系 | 组织成员和私人关系 |
| 知府（影） | 上级官员 | 本府不出参案、考成 | 报险、批示、委员与审查链 | 未被设定的私人关系 |

### 8.3 关系边分类练习

对每条候选关系必须填写：关系类型、方向、事实状态、来源事件/文书、谁知道、玩家是否知道、有效时间、可能影响的行动。至少辨别以下差异：

- 职务上的上下级 ≠ 私人信任；
- 欠银/欠情 ≠ 盟友；
- 同场赴宴 ≠ 私交；
- 同属一个组织 ≠ 立场一致；
- 一方认为对方可靠 ≠ 对方也信任此人；
- 传闻中的关系 ≠ 已确认关系。

没有来源的关系不得进入已确认网络，只能列为设计待决项。

### 8.4 NPC-NPC 自主交往桌面推演

选择一段玩家不主动接触人物的时段，按既有 Intention 表推演一次人物之间的自主行动。主持人必须记录：

| 字段 | 必须回答 |
|---|---|
| 行动者与目标 | 谁主动联系谁，为什么选这个对象 |
| 行动动机 | 对应哪项目标、利益、承诺或风险 |
| 渠道 | 同场、拜访、书信、中间人或正式文书 |
| 成本与风险 | 时间、资源、旁听、泄露、延误等 |
| 对方认知 | 对方知道什么、误解什么、是否相信 |
| 回应 | 接受、拒绝、拖延、转交、附条件或欺骗 |
| 结果事件 | 关系、承诺、资源、认知或任务发生了什么变化 |
| 玩家可见性 | 玩家何时、通过什么来源得知 |

自主行为不得以「剧情需要」为唯一理由；没有明确动机或可追溯结果的行动不计入通过。

### 8.5 远距通信测试

沿用已有「玩家在江苏、目标在北京」的通信设计作为机制样例，不把它加入当前一县 M1 内容。分别推演书信、中间人和正式公务文书，检查是否区分发出、途中、送达、阅读、理解、回应与回复送达；等待期间继续推进世界。未获知目标位置时，必须先查找或通过中间人询问，不得直接瞬移联系。

### 8.6 玩家理解度评分

测试后让玩家不看资料回答：

1. 这两个人是什么关系？依据是什么？
2. 为什么甲愿意帮乙，但乙未必愿意帮甲？
3. 这个人有几种身份？哪一种身份在当前场景生效？
4. 谁知道这件事？谁只是听说？
5. 为什么消息没有立即传遍所有人？
6. 玩家不找他们时，他们会不会自己行动？

通过标准：玩家能区分身份、关系、组织、认知四层；能解释至少一条关系不对称和一条消息传播路径；不会把七人误解成七种人物类别。出现误解时先改模型和呈现，不以增加说明文字掩盖。

### 8.7 M0 结论门槛

- 本节为设计候选和纸面测试任务，不等于玩家实测。
- 未完成至少 3 组真人测试前，不宣称社会关系网络可理解、社交核心玩法成立。
- M1 不实现全量身份字典、全社会关系网或全人口 NPC 自主模拟；只实现支撑河工纵切片的最小闭环。

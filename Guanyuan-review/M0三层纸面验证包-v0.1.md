## 二、主持人规则卡（B+）

1. **每段 1 个实质动作。** 实质＝产生新证据/承诺/债/文书/资源变化/暴露/任务，或推进任务/期限。
2. **一次社交动作＝与一人在一场景一轮交谈；** 多句不算多次；换人/换主题且产生新证据或承诺才算新动作。
3. **0 费：** 看已读文书、看人物卡、重复已得口供、场景内寒暄（无新信息/承诺）。
4. **长动作占段：** 声明 N 段，期间不插入另一实质动作；任务执行异步，发起后可做别的。
5. **等待/模型延迟/事件暂停不推进世界。**
6. **结算顺序（10.6）：** 命令校验→原子提交→推进时段→到期任务→环境/制度→NPC 日程→认知传播→期限/债务→事件导演→夜间/跨日→视图刷新；同刻稳定排序；重放不重复扣。
7. **责任共担（6.6）：** 先抢后报+程序齐备→共担/减轻；隐瞒/越权/无留痕→独担；定性权在上级。
8. **越权拦截给替代路径**（拆分/请批/换名义/找人代行），不给红叉。
9. **NPC 会自己行动**（见第三节）；玩家不处理，世界仍推进，但不无故惩罚。
10. **阅读税：** 决策数 ÷ 新增文书数 ≥1；单场景 ≤2 页。

## 五、卡片模板

### 5.1 目标卡（Goal，章首）
```
类型：政绩 / 清名 / 关系 / 自保 / 家业 / 自定义
一句话：我要……（≤24 字）
优先级：1–3    视野：本章
成功信号：……（可观测，非数值）
失败信号：……
复核点：第 5 日 / 章末 / 重大事件后
可见性：私有（NPC 不知，除非你说出）
状态：active → revised / achieved / failed / abandoned
```

### 5.2 事务卡（Case，≤3 活跃）
```
案名 / 类型（河工/词讼/世俗）  阶段：起→查→谋→办→验→结
主办 / 协办    期限 / 下一检查点
任务：执行人 · 发起成本 · 执行时长 · 预计完成时段
偏差：人/料/钱/期限/信息（不预设腐败）
若不管：下一次变化在何时（不办也推进）
```

### 5.3 接触记录卡（Exposure）
```
谁 · 何时 · 何渠道（亲见/转述/文书/推断/传闻） · 接触到什么（F/P/E/V）
接触理由    已读? 已懂? 已信?（分开，不自动推论）
玩家可见性：仅玩家可知的接触；未知显示「？」
```

### 5.4 礼簿 / 账册
- 礼簿：日期/送者/礼物/估值/事由/见证/回礼/状态（未回/已回/高风险）。
- 账册：账面 4,500 / 实收 4,200 / 差额 300；料 30/10/10；报部二选一。

### 5.5 尾声 / 退路卡（章末）
```
目标对账：做到 / 没做到 / 被什么改变（不评分）
留下：工程/文书/债/把柄/口碑（长尾）
若溃口/参劾：退路 1–2（幕友/乡绅/教读/归隐）——保留什么 / 失去什么
```

## 七、五路线桌面复跑（v0.6.2）

> 每条给出：目标、≥2 方案、关键日段日志（B+）、NPC 自主、非行动后果、失败+恢复、长尾、考语、资源差。实质动作数为整十日合计；其余时段由 0 费读取/场景对话填充。

### 7.1 路线 A · 政绩优先

**Goal：** 堤成 + 可写进考语的实迹；不因 300 被参。
**方案 A1（抢护做平）：** 亲勘→抢护→300 做平→保固。成本低、风险在保固/审计。
**方案 A2（抢护自曝）：** 亲勘→抢护→自曝 300→请还。成本在关系/工期，守格更稳。两方案在「守」措辞与粮商反应上实质不同。

| 日/段 | 行动 | 成本 | 反应/约束 | 结果 |
|---|---|---|---|---|
| D1 晨 | 亲勘 40 步 | 1 段 | 书办紧张 | F-001 |
| D1 午 | 问专家 | 1 段 | 要你亲挖 | 闸底嫌疑 |
| D1 暮 | 探挖 | 1 段 | 工头确认 | E-007 |
| D1 夜 | 接风宴 | 1 段+20 两 | 士绅/粮商/县丞 | 旧欠/坟地线索 |
| D2 晨 | 召县丞/主簿 | 1 段 | 县丞要会勘 | 20 堡夫/5 河兵 |
| D2 午 | 写详文报险 | 1 段 | 知府批/委员 | V-004；责任留痕 |
| D2 暮 | 募夫 50 | 1 段+25 两 | 保正具结 | 夫到位 |
| D3 晨 | 启动抢护（长动作） | 发起 1 段·执行 2 段 | 工头；8–10 垛 | 任务异步开始 |
| D3–D8 | 巡堤/监督/委员 | 每日 1–2 段 | 暴雨 D8；委员 D5 | 进度/损耗 |
| D9 | 洪水 | — | 抢护顶住 | 堤在 |
| D10 | 验收/题销/考语 | 1–2 段 | 做平 or 自曝 | 保固一年 |

- **实质动作 ~24**（≤40，不过紧/不过空）。
- **NPC 自主：** D3 玩家忙抢护未理粮商 → 粮商扣最后 10 垛（EV-06）。
- **非行动后果：** D4 玩家未拜士绅 → 士绅传「官堤占坟」谣言，风评−。
- **失败+恢复：** 若委员延迟+料不足→抢护受阻→D9 溃口（EV-12）；因报险+会勘+具领留痕齐备，按 6.6 共担/减轻；尾声卡给「揭主簿追赔 / 借银补修 / 降调留任」三选一，非重试。
- **长尾：** 保固一年内冲决加重；离任审计翻 300；粮商债。
- **考语（7.2）：** 做平「才具开展，操守平常」；自曝「才具开展，操守尚可」。
- **资源：** 私囊 60→40；公帑 −25 两（夫食）；料 −8–10 垛；300 未还（A1）/请还（A2）。

**Goal：** 查明并揭报 300；不背黑锅；堤尽量保。
**方案 B1（先揭后工）：** D2 揭报→主簿反咬→抢护紧。清名快、工期险。
**方案 B2（先工后揭）：** 抢护成→D8 揭报→证据稳。工期稳、清名晚、被议「养痈」。两方案在工期/关系/措辞上不同。

|---|---|---|---|---|
| D1 晨 | 亲勘 | 1 段 | — | F-001 |
| D1 午 | 查账 | 1 段 | 主簿知你在查 | E-001 |
| D1 暮 | 问书办 | 1 段 | 怕担责 | E-002 线索 |
| D1 夜 | 查借领状 | 1 段 | 主簿警觉 | 300 去向 |
| D2 晨 | 问主簿 | 1 段 | 否认/试探 | P-003 |
| D2 午 | 找粮商 | 1 段 | 要债 | E-003 |
| D2 暮 | 写揭报 | 1 段 | 知府可能压案 | V-015 草稿 |

- **实质动作 ~22。**
- **NPC 自主：** D4 玩家专注核账 → 主簿自行改借领状（被接触记录卡抓到，Exposure 留痕）。
- **非行动后果：** D5 玩家未安抚士绅 → 士绅上控「苛查扰民」。
- **失败+恢复：** 知府压案+报复→工期延误→溃口；清名不能免参，但揭报留痕使「守」不被抹黑；尾声卡「以幕友身份继续查弊 / 教读著书立说」，清名转化为门生/著作长尾。
- **长尾：** 清名被引用；主簿仇恨；升迁慢；离任审计干净。
- **考语：** 「守洁可风，才具平常，调度未免拘谨。」
- **资源：** 私囊 60（不宴不礼）；公帑 −25 两；可能 −300（退赔）；料 −8–10 垛。

- **失败+恢复：** 网络反悔/士绅上控/粮商断料→溃口；债主反噬；尾声卡「以乡绅身份调解捐输 / 合伙行账」，关系网换账本继续。
- **长尾：** 人情债、礼簿、Secret/Hook、风评「奢/圆」；下次调任/修渠/婚嫁被索取。
- **考语：** 「才具开展，颇事应酬，操守不无可议。」
- **资源：** 私囊 60→25；借 300；公帑 −25 两；料 −8–10 垛；人情债 2–3 笔。

### 7.4 路线 D · 保全自身（v0.6.2 闭合）

**Goal：** 责任分明、不被参；堤溃也不背全锅。
**方案 D1（程序共担）：** 早报险→拉县丞会勘→主簿具领→请委员→保守抢护。责任摊开，政绩低。
**方案 D2（明哲保身）：** 只报险不冒进→把难题推河厅→记录留痕。更安全，考语「无担当」更重。两方案在责任摊开程度/考语/机会上不同。

- **实质动作 ~18。**
- **NPC 自主：** D4 玩家不接触粮商 → 粮商扣料放风；县丞按 Intention 先报河厅（责任链再增一环）。
- **非行动后果：** D6 玩家未催料 → 在途 10 垛延误，工期更紧（世界自走）。
- **失败+恢复（关键闭合点）：** 若溃口，因报险+会勘+具领+委员留痕齐备，按 **6.6 共担/减轻**，不独坐知县；知府定性为「公罪/共担」而非「私罪/侵欺」；尾声卡「降调留任 / 候补 / 幕友」可继续。**自保路线不再依赖未补规则。**

- **考语：** 「办事谨慎，然担当未足，才具尚待历练。」
- **资源：** 私囊 60；公帑 −25 两；料 −8–10 垛；不接礼；300 不碰。

### 7.5 路线 E · 家业（M1 薄片，不计入四条门槛）

**Goal：** 借河工建私产/联姻/人情；不破产；堤尽量保。
**方案 E1（收礼周转）：** 收士绅/粮商礼→私囊+→雅贿。风评奢/贪、把柄多。
**方案 E2（拒礼保身）：** 拒礼→靠家用/门包节流。私囊紧、风评清。M1 只有 1 家人事件+礼簿，**不能完整验证**；置产/内宅/贪腐链 M2。

- **实质动作 ~15；NPC 自主：** 仆人收门包虚报（D7，内宅 Intention）。
- **非行动后果：** 玩家不管家用 → 妻族招摇，风评−。
- **失败+恢复：** 礼簿暴露/被参→抄没风险；尾声卡「归隐著述 / 商合伙」（M2/M3 才完整）。
- **长尾：** 礼簿/Secret/贪腐链；家族。
- **考语：** 「才具尚可，操守平常。」
- **资源：** 私囊 60→15；公帑 −25 两；料 −8–10 垛。
- **结论：** 薄片成立、可跑，但**不作为 H7 四条门槛之一**；M2 完整验证。

## 八、人物分类与社会关系网络补充验证（v0.14 候选，零代码）

> 本节只增加纸面验证任务，不增加人物数量，不把尚未证实的关系写成世界事实。所有关系必须回到当前场景事实、事件、文书或明确设定来源；没有依据的格子标「未知/待设定」，不得为了图谱完整而补造。

### 8.1 先拆清四种东西

主持人给玩家看人物名帖后，要求其分别识别：

1. **人物是谁：** 独立个体，不等于某一类别。
2. **人物有什么身份：** 社会身份、制度资格、家庭出身、组织归属、当前处境可以并存。
3. **人物与谁有什么关系：** 同一对人物可有多条关系，且双方态度未必一致。
4. **人物属于什么组织：** 组织成员身份与个人交情、正式职务分开。

本局七人配置是测试样本，不得称为七种人物分类。六类身份粗分仅用于 M1 权力权限校验，不构成社会分类总表。

| R-05 | 粮商 ↔ 县衙/官府（组织/公账主体，非知县个人） | 供料交易与旧欠债权 | 官府欠粮商 300 两；粮商扣留最后 10 垛作为催款手段 | 已确认（经济/契约事实） | F-004、F-005；E-003、E-006；P-004 | 粮商知道旧欠与扣料；知县起初不知道扣料；主簿知道旧欠但不代表粮商知道主簿挪移 | 还款、赊供、继续扣料、协商垫供；债权不得转写为粮商与知县的私人恩怨 |
| R-06 | 河工专家 → 知县（仅当 P-007 已在场景中说出时） | 专业意见/技术陈述事件 | 单向陈述；不等于长期师友、雇佣或信任关系 | 说法有来源；是否已发生及具体场次须按事件记录 | P-007；E-007、E-008、E-012 | 专家知道闸底淘空；知县开局并不知道，收到陈述/查验后才更新认知 | 提供抢护/汛后拆修判断；知县可采纳、质疑或要求复核 |
| R-07 | 工头 → 知县（仅当 P-009 已在场景中说出时） | 现场证言/材料质量报告事件 | 单向陈述；不等于私人信任关系 | 说法有来源；是否已发生及具体场次须按事件记录 | P-009；E-004、现场复秤/点验 | 工头知道料垛虚松；其他人物是否知道取决于实际报告与查验 | 触发复秤、点验、调整材料用量；不能让其他 NPC 自动获得工头的知识 |
| R-08 | 河工专家 ↔ 工头 | 共同知晓闸底淘空的现场认知重叠 | 认知重叠是双向可确认；私人关系方向未知 | 已确认共同知情；**未建立社交关系边** | F-002；E-007、E-008 | 两人都知道 F-002；彼此是否交流、是否信任未知 | 可在共同勘验时互相印证；不能自动认定师徒、同僚、盟友 |
| R-09 | 地方士绅 → 茶楼传闻网络 → 粮商/河工书办 | 民谣/传闻传播，不是稳定人际关系 | 源头指向士绅/茶楼；粮商与书办是听闻者；具体中间传播人和先后顺序未定 | 传闻存在；具体传播路径待查 | F-014、P-006；E-015；M1 图谱 2.5 认知表 | 士绅知其源头；粮商、书办听过；玩家是否听闻取决于接触与调查 | 影响风评、调查线索与回应；每次转述必须记录来源与失真，不可全局广播 |

**特别裁决：**
- R-05 的债务主体是县衙/官府公账，不得偷换成“粮商个人欠知县人情”或“粮商与主簿串通”。
- R-06、R-07 是可能发生的陈述/接触事件，不是长期关系；只有实际触发并留下事件记录后，才能进入关系时间线。
- R-08 只表示两人对 F-002 具有共同认知，不表示两人彼此熟识或信任。
- R-09 是消息传播链；除非补出具体中间人/场所接触事件，不得把士绅与粮商、书办画成直接朋友或同盟。
- R-04 是当前唯一明确写出的私人/地方交往线索，但缺少事件和证据绑定；在补证前只能显示“有往来（性质未明）”，不能推演其具体利益交换。

### 8.4 当前没有依据的关系：保持未知

以下关系在当前 M1 图谱中没有充分依据，均不得自动生成：

- 县丞—主簿：除同属县级衙门工作链外，私人交情、串通、竞争均未知。
- 主簿—粮商：主簿知道旧欠、粮商持有票据，不等于两人私下接触或合谋。
- 主簿—士绅：是否通过士绅放风、是否有利益交换，未知。
- 县丞—粮商：未知。
- 士绅—粮商：粮商听过民谣不等于与士绅直接交往；传播中间人未知。
- 专家—县丞/主簿/士绅/粮商：除各自知道什么之外，具体接触、师承、雇佣、信任均未知。
- 工头—县丞/主簿/粮商/士绅：除施工现场事实外，雇佣、隶属、私交与利益关系需按委牌、保结、点卯或口供补证。
- 七人任何人的亲属、姻亲、座师门生、同年、同乡、同门、商帮、宗族、派系身份：当前没有明确证据，不进入已确认网络。
- 七人之间的“好感度”“忠诚度”“影响力”总分：不建立；具体债务、信任、畏惧、依赖、声誉与政治支持分别建模。

### 8.5 关系边分类练习

对每条新增候选关系必须填写：关系类型、方向、事实状态、来源事件/文书、谁知道、玩家是否知道、有效时间、可能影响的行动。至少辨别以下差异：

- 职务上的上下级 ≠ 私人信任；
- 官府欠款 ≠ 知县个人欠人情；
- 欠银/欠情 ≠ 盟友；
- 同场或共同知情 ≠ 私交；
- 同属一个机构 ≠ 立场一致；
- 一方认为对方可靠 ≠ 对方也信任此人；
- 传闻源头/听闻者 ≠ 直接朋友或同盟；
- 有往来 ≠ 贿赂、庇护、亲属或派系关系。

没有来源的关系不得进入已确认网络，只能列为设计待决项。

### 8.6 NPC-NPC 自主交往桌面推演

选择一段玩家不主动接触人物的时段，按既有 Intention 表推演一次人物之间的自主行动。主持人必须记录：

| 字段 | 必须回答 |
|---|---|
| 行动者与目标 | 谁主动联系谁，为什么选这个对象 |
| 行动动机 | 对应哪项目标、利益、承诺或风险 |
| 渠道 | 同场、拜访、书信、中间人或正式文书 |
| 成本与风险 | 时间、资源、旁听、泄露、延误等 |
| 对方认知 | 对方知道什么、误解什么、是否相信 |
| 回应 | 接受、拒绝、拖延、转交、附条件或欺骗 |
| 结果事件 | 关系、承诺、资源、认知或任务发生了什么变化 |
| 玩家可见性 | 玩家何时、通过什么来源得知 |

自主行为不得以“剧情需要”为唯一理由；没有明确动机或可追溯结果的行动不计入通过。桌面推演可以提出假设动作，但必须标为“测试假设”，不得回写成已经发生的 M1 世界事实。

### 8.7 远距通信测试

沿用已有“玩家在江苏、目标在北京”的通信设计作为机制样例，不把它加入当前一县 M1 内容。分别推演书信、中间人和正式公务文书，检查是否区分发出、途中、送达、阅读、理解、回应与回复送达；等待期间继续推进世界。未获知目标位置时，必须先查找或通过中间人询问，不得直接瞬移联系。

### 8.8 玩家理解度评分

测试后让玩家不看资料回答：

1. 这两个人是什么关系？依据是什么？
2. 为什么甲愿意帮乙，但乙未必愿意帮甲？
3. 这个人有几种身份？哪一种身份在当前场景生效？
4. 谁知道这件事？谁只是听说？
5. 为什么消息没有立即传遍所有人？
6. 玩家不找他们时，他们会不会自己行动？

通过标准：玩家能区分身份、关系、组织、认知四层；能解释至少一条关系不对称和一条消息传播路径；不会把七人误解成七种人物类别。出现误解时先改模型和呈现，不以增加说明文字掩盖。

### 8.9 M0 结论门槛

- 本节为设计候选和纸面测试任务，不等于玩家实测。
- 未完成至少 3 组真人测试前，不宣称社会关系网络可理解、社交核心玩法成立。
- M1 不实现全量身份字典、全社会关系网或全人口 NPC 自主模拟；只实现支撑河工纵切片的最小闭环。

### 8.10 空白人生：科举开局与社会关系驱动器纸面链（新增核心验证）

本验证与 8.2–8.9 的 M1 河工七人固定样本**分开运行**。河工七人只验证关系模型在中期任官场景中的复杂性；新人生存档不得预置这七人，也不得把河工关系矩阵当作玩家的初始社交关系。

**开局快照：**

| 对象 | 初始值 |
|---|---|
| 玩家 | 初入科场的读书人；年龄、籍贯、家境、教育背景按开局规则确定 |
| 玩家个人关系矩阵 | 空 |
| 玩家接触簿 / Exposure | 空 |
| 玩家人情簿 | 无往来记录、无债、无把柄；如开局选择家庭背景，单独载入有来源的家庭事实 |
| 玩家已知人物 | 空；只有开局明确给定的家庭成员/监护人例外 |
| 世界人物库 | 可以有考官、士子、官员、地方人物与组织，但未接触者不显示为玩家联系人 |
| 世界历史 | 可以存在 NPC 既往关系，但不得注入玩家可见信息；需有来源和时间线 |

**纸面推演链：**

1. **报名/资格核验：** 由玩家选择是否报名、准备何种应试路径；资格、时间、费用和地域规则决定能否进入考试。可能接触书院、保结人、同乡或代办者，但不保证出现。
2. **入场与同场：** 按考场规则生成有限候选人物。玩家可以观察、听闻、短暂交谈或完全不互动。只生成实际发生的 Exposure；同场不等于相识。
3. **考试与候榜：** 结算考务事件与时间；考官、同场士子各自有身份、目标和认知边界。AI 可提出候选行动，但不得预言考试结果或把未发生的交往写成旧识。
4. **放榜：** 结果由规则结算。若玩家与其他士子确属同一科次同一榜单，建立客观“同年”关系；若未中，不能凭空建立同榜关系。放榜也不自动意味着双方已见面或互信。
5. **后续交往：** 玩家可选择拜见、递帖、赴宴、游学、再试、谋生、拜师或暂不联系。每项行动按渠道、时间、资源、身份和目标人物回应结算。
6. **关系形成：** 只有满足类型条件并提交事件后，关系边才进入确认矩阵；否则保留为闻名、Exposure、传闻或未知。
7. **人生分岔：** 中举、落第、再试、改途、入幕、游学、经商/谋生等分支均可继续；任何一条都不得被 AI 强制拉回“必然中举—必然入仕”。

**AI 驱动器每轮输出卡：**

| 输出 | 必填内容 |
|---|---|
| 候选人物 | 临时/正式 Person ID、生成原因、身份依据、时间地点、去重键 |
| 候选行动 | 行动者、目标、意图、动机、渠道、成本、风险、预期结果 |
| 规则校验 | 通过/拒绝/待补条件；所用制度规则与前置事实 |
| 事件提交 | 唯一 Event ID、参与者、发生时间、事实变化、证据来源 |
| 矩阵差异 | 新增/变化/终止的关系边；没有变化必须返回“无关系变化” |
| 认知差异 | 玩家及各 NPC 新知道、相信、误信或仍不知道的内容 |
| 叙事依据 | 仅引用已提交事件与当前观察者可知信息 |

**必须复跑的反例：**

- 同场但未交谈：不得自动生成相识/朋友。
- 同榜但从未见面：可以有客观同年关系，但接触簿不能写“曾把酒言欢”。
- 玩家落第：不得自动生成同年关系；可以保留同场接触或对某位考官/士子闻名。
- AI 连续重试同一事件：不得重复创建人物、关系或债务。
- 玩家不经营关系：网络可以长期稀疏；世界中的其他 NPC 仍按自身动机行动。
- NPC 之间存在师门或旧交：玩家未获知前，关系不得出现在玩家关系视图和玩家对话上下文。

**通过标准：** 从空白存档运行到放榜与后续选择，所有新增人物和关系均可回查到事件；同榜、相识、师承、私人信任等关系不混淆；AI 输出不合规时仍可按规则推进；至少出现一次“无关系变化”的合法回合；玩家失败后仍有可继续的人生路径。本纸面测试通过不等于功能已实现，也不替代至少三组真人测试。

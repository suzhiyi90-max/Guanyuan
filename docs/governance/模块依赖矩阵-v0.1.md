# 模块依赖矩阵 v0.1

- 状态：治理索引已纳入 main；模块边界用于治理和审查，不自动批准尚未裁决的基础规则。
- 原则：模块是领域责任边界，不要求一一对应技术服务。所有模块共享唯一权威世界状态和因果事件流。
- 方向：基础身份/权限/时间/事件/认知契约 → 领域规则 → 状态与事件提交 → 认知/投影 → UI/AI 表达。UI、行状和 AI 不得反向创建业务事实。
- M1 边界：一县、七人、十日、一汛；背景人物可聚合，不以扩充模块为由扩大核心角色数量。

## 依赖规则

1. MOD-AUTH 和 MOD-TIME 是基础契约；领域模块调用它们，不自行重写权限或时间算法。
2. MOD-COMMAND 是唯一业务提交边界；权威状态变化必须与对应事件原子提交。
3. MOD-EVENT 是被动追加式事件存储与回放基础，不反向调用命令、时间或领域模块；它接收完整事件封套并按明确顺序记录。
4. MOD-COG 只能基于真实事件、证据和可达性生成认知变化；它不反向改写客观事实。
5. MOD-BIO、MOD-VIEW、MOD-AI 是下游消费者；不能成为领域状态的权威写入者。
6. MOD-DIRECTOR 的随机选择必须带可复现输入；生成的新事件只能进入未来结算点。
7. 远距沟通使用现有动作、时间、位置可达性、文书和认知契约，不单独创建另一套“消息真相”或“第五种信息视角”。
8. 仕途只消费已发生的绩效、文书、评价与空缺事件；不得绕过职位资格、权限和程序。

## 2026-10-29 候选补充（M0 审查）

以下条目是把 M0 纸面原型（A–H）暴露的边界补进模块契约的候选建议；未批准前不改变上表职责。

| 模块 | 补充边界 | 对应 ADJ/场景 | 不得做的事 |
|---|---|---|---|
| MOD-TIME | 四时段是唯一时间单位；不维护并行行动点；每动作声明 `timeCostPeriods` 与失败策略 | ADJ-001/002/003；M0-A | 不同时扣行动点与时段；不因模型延迟推进 |
| MOD-COMMAND | 命令日志、业务对象、预算、事件、`worldVersion` 同一事务；`commandId`/`taskId`/`eventId` 分离 | ADJ-009/010/011；M0-D | 不把命令日志写在事务外；不让模型输出直接提交 |
| MOD-DELEG | 发起 1 时段与执行时长分开；受理/拒绝/延迟/部分完成是不同状态；预算预留不占玩家时间 | ADJ-004/005；M0-B | 不把执行 2 时段再扣给玩家；不把发起当成功 |
| MOD-ECON | `reservation` 对象：reserved/actual/released/reported 四列；账面/实收/报部是三种口径 | ADJ-004/006；M0-B/F | 不把预留当支出；不重复扣款 |
| MOD-SCHEDULE | 任务占用执行人时，NPC 日程顺延并记事件；紧急事件可中断任务 | ADJ-005/027；M0-B/G | 不让同一人同段执行两件事；不补写离场结果 |
| MOD-DOC | 新增 DOC-002：文书有版本/持有人/签押/流转事件；文书是证据，不是权限 | ADJ-025；M0-B/C/D | 不以“有文书”替代权限链；不让文书写入事实 |
| MOD-COG | Fact/Claim/Evidence/Exposure/Belief/Memory/Rumor 分开；四档是玩家台账投影 | ADJ-014/015/021/022；M0-F/H | 不把接触当相信；不把传闻升级为事实 |
| MOD-DIRECTOR | 新事件只排 `triggerAt` 未来结算点；随机按事件 ID 派生 | ADJ-017/018/020；M0-G | 不插入当前段；不依赖遍历顺序 |
| MOD-BIO | 行状只消费已提交事件，每条带 `sourceEventIds`；纠错发新版本 | ADJ-026；M0-G/F | 不把行状当事实源；不让 AI 新增事实 |
| MOD-AI | 前置过滤 + 输出 schema + 后置 ID 校验；模型只出表达/候选意图 | ADJ-016；M0-F/E | 不宣称“结构性消灭幻觉”；不直接改状态 |

**依赖方向复核：**

- MOD-COG 仍只从 MOD-EVENT 消费，不反向调用 MOD-SOCIAL/MOD-ECON。
- MOD-DOC 是 MOD-AUTH 的证据消费者，不成为权限源。
- MOD-DELEG 与 MOD-ECON 通过 `reservation` 对象解耦，避免“预算改任务/任务改余额”的双向写。
- MOD-DIRECTOR 只写未来事件，不写当前段已结算事件。
- MOD-BIO/MOD-VIEW/MOD-AI 仍是下游，不新增权威写入口。

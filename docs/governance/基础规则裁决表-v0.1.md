### ADJ-002 单动作耗时、失败耗时与疲劳

| 字段 | 内容 |
|---|---|
| 决策 ID | ADJ-002 |
| 冲突位置 | 4.5 只写“1 时段”；未写失败是否耗时；9.1 行动点由身体状态决定；9.3 疲劳恢复；附录 A 无失败成本参数 |
| 当前正式口径 | 普通动作 1 时段；失败成本未定义；疲劳是否改耗时未定义。玩家无法预判“失败一天”还是“失败不花时间”。 |
| 候选选项 | **A. 每动作声明 `timeCostPeriods` 与 `failureTimeCostPolicy`**；前置失败 0，提交后失败按动作声明；疲劳只改信息质量。**B. 失败一律 0 成本**；**C. 失败一律扣 1 时段**。 |
| 影响分析 | A 最可测，但需要为每个动作写失败策略；B 鼓励试错，玩家可用失败探路；C 惩罚重，但会让玩家不敢行动。A 与 BC-T-02/BC-E-03 一致。 |
| 纸面案例 | 场景 A-F1：D1晨压主簿，前置失败；A3a（0 成本）还能问粮商，A3b（1 时段）错过粮商。场景 D4/D5：前置失败不扣钱，提交后失败扣 1 时段并释放预算。 |
| 推荐意见 | **A**。默认值：纯读取 0；问/查/访问/验工/发信/托/请/压/保/赏/荐 1；明确等待 1/时段；睡眠占夜段。失败策略逐动作声明，未声明视为设计不完整。 |
| 风险与代价 | 动作表维护成本高；玩家可能利用“前置失败 0 成本”反复试探，需要拒绝日志与社交后果（打草惊蛇）。 |
| 史料要求 | 无。疲劳对信息质量的影响可参考幕友日记/官员日记中的“酒后失察”“连夜看册漏行”，但只作 B 级氛围，不作硬规则。 |
| 验收条件 | 每个会改变世界状态的动作都有 `timeCostPeriods` 与 `failureTimeCostPolicy`；查看类操作可 0；模型/网络等待不计游戏时间；同一动作重放不重复耗时。 |
| 状态 | 候选—待裁决 |
| 影响范围 | 4.5、8.2–8.3、9.1–9.3、10.5、附录 A/B；全部耗时动作 |

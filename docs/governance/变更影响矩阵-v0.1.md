# 变更影响矩阵 v0.1

- 状态：治理索引已纳入 main；本矩阵用于变更追踪，不单独构成领域规则。
- 目的：任何基础规则变化都能反向定位到全部受影响章节、模块、参数、示例、史料依据和验收项。
- 使用方式：先查“变更主题”行，再按列复核所有标记位置；未修改的引用也要写明“不需改动及原因”。
- 权威边界：矩阵仅为索引，不构成规则；正文定义以 main 上已批准的《设计总纲》为准。

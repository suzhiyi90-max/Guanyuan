# 变更影响矩阵 v0.1

- 状态：治理索引已纳入 main；本矩阵用于变更追踪，不单独构成领域规则。
- 目的：任何基础规则变化都能反向定位到全部受影响章节、模块、参数、示例、史料依据和验收项。
- 使用方式：先查“变更主题”行，再按列复核所有标记位置；未修改的引用也要写明“不需改动及原因”。
- 权威边界：矩阵仅为索引，不构成规则；正文定义以 main 上已批准的《设计总纲》为准。

## 变更检查清单（每个 PR 必须执行）

- [ ] 是否明确规则 ID 和唯一权威定义位置？
- [ ] 是否检查了矩阵中所有直接与间接受影响章节？
- [ ] 是否同步了参数表、附录示例、人物/职位表和文书示例？
- [ ] 是否区分产品裁决状态与史实核验状态？
- [ ] 是否保持依赖单向：基础契约 → 领域规则 → 事件/状态 → 认知/投影 → UI/AI？
- [ ] 是否检查重复提交、拒绝、超时重试、同刻事件、跨日和随机复现？
- [ ] 是否更新了验收判据及未覆盖风险？
- [ ] 是否说明未修改的相关章节为何不受影响？
- [ ] 是否明确该改动是候选、已批准、已进入 main、已实现还是已验收？

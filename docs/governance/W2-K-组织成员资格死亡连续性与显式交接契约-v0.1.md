# W2-K 组织成员资格死亡连续性与显式交接契约 v0.1

状态：W2-K 施工契约；基线为 W2-J `work/w2-j-estate-asset-inventory`。

## 1. 目标

明确人物死亡对组织成员资格的时间边界，并为组织在死亡后明确任命/吸收新成员提供可追溯引用。成员资格是 person-bound interval；死亡终止死者本人继续履行成员资格的能力，但不自动终止组织，也不自动指定接任者。

## 2. 死亡时成员资格闭合

1. 对已死亡人物的每条 Membership，校验其 validFrom、validTo 对应事件及事件时点。
2. 成员资格在死亡前已结束的，保留原结束事件，不回写死亡事件。
3. 死亡前已开始且仍持续至死亡时点的成员资格，必须以 DeathRecord.causeEvent 作为 validTo。
4. validTo=open 或结束事件晚于死亡时点，均拒绝。
5. 若结束时点与死亡时点相同，结束事件必须就是死亡事件；不允许以另一个同刻事件替代死亡事件。
6. 死亡时点或事件时间无效、缺失、彼此不一致时，拒绝验证。

## 3. 显式组织交接

MembershipDeathHandoff 只建立以下可审计引用：

- sourceMembership：死者原成员资格；
- deceased / deathEvent：死者及其死亡事实；
- successorMembership：组织另行建立的新成员资格；
- handoffEvent：新成员资格的明确生效事件。

校验要求：

1. 原成员资格属于死者，并以死亡事件结束，且在死亡前已经开始。
2. 新成员资格必须是独立记录，属于同一组织，但成员人物必须不同。
3. handoffEvent 必须存在、时点有效且严格晚于死亡时点；新成员资格 validFrom 必须等于 handoffEvent。
4. 新成员在交接时点必须存活；按历史时点判断出生与死亡边界。
5. 同一原成员资格不得重复交接；同一目标成员资格不得被多个交接记录重复认领。
6. 新成员的 role 与 obligations 必须由新成员资格自身明确记录；不从死者成员资格自动复制，也不要求相同。
7. 交接只表示组织建立了新的成员资格，不证明死者的私人义务、债务、财产或其他关系转移。

## 4. 不做事项

- 不自动选择继任者，不按亲属、师生、同乡、派系或组织内部等级推断；
- 不自动继承职位、投票权、表决权、财产、债务、私人义务或秘密；
- 不因成员死亡而解散组织、改变组织目的或修改其他成员记录；
- 不自动复制 role、obligations，也不自动把未履行义务转给继任者；
- 不修改 Person.death.estateSettlements 的 membership 域状态；
- 不接 W3 Event Ledger、AI 写入、存档迁移、G1 runtime 或 UI。

## 5. 验收

- 死者所有成员资格的有效区间都不越过死亡时点；
- 死亡时仍有效的成员资格必须由死亡事件闭合；
- 死亡前已经结束的成员资格保留原事件；
- 交接必须引用同组织内独立的新成员资格；
- 交接事件严格晚于死亡，新成员资格起点与交接事件一致；
- 继任者在交接时点存活；
- 不从旧成员资格推断新成员资格的角色或义务；
- 重复引用、缺失人物/成员资格/事件、组织不一致和时间倒置均拒绝；
- 验证只读，不改写组织、成员资格或死亡结算状态；
- W1-A 至 W2-J 回归、W2-K 专项测试、Review index、Patch whitespace、Production build、Playwright Smoke 与截图归档全部通过。

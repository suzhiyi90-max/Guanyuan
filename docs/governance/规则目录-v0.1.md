## 变更登记要求

每次修改任何一条规则，PR/变更说明至少包含：

1. 规则 ID 与原权威定义位置。
2. 变更前/后语义及变更原因。
3. 受影响模块、章节、参数、示例、史料依据和验收项。
4. 依赖方向检查：是否引入反向依赖或第二权威源。
5. 未修改的相关引用位置及“不需修改”的理由。
6. 状态：候选、用户已确认、已进入 main、已实现、已验收。各状态不得互相替代。

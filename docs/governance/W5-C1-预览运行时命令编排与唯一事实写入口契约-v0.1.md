# W5-C1 预览运行时命令编排与唯一事实写入口契约 v0.1

## 1. 基线与范围

- 基线：W5-B `work/w5-b-runtime-event-catalog-projection`，验收 SHA `14809ee1b407a98604cc3611427ad0d295f51e37`。
- 本片把当前预览的非 AI 世界动作接入统一 Orchestrator。
- 本片只建立内存态 EventLedger 与 GameState 只读投影；不实现 SaveRepository、IndexedDB/localStorage adapter、SavePackage 导入导出或旧档迁移。
- AI 生成事件的 CandidateLog、validation receipt 与 ai-candidate fact 提交留给 W5-C2；在 C2 完成前，AI 事件选项不得直接改变 GameState，也不得绕过账本写入。

## 2. 唯一事实源

运行时链路固定为：

`UI Intent → Runtime Orchestrator → frozen Registry validation → appendLedgerEvent → full replay → read-only GameState projection → UI`

约束：

1. Orchestrator 是唯一可以调用 `appendLedgerEvent` 的运行时模块；UI 与 React hook 不直接 append。
2. React state 只保存最近一次不可变 GameState projection，不是事实源。
3. EventLedger 与 projection 在一次 dispatch 中原子替换：先生成候选新 Ledger，再完整重放；只有 replay 成功才提交二者。schema、append 或 reducer 失败时，旧 Ledger 与旧 projection 均保持不变。
4. 相同 `clientRequestId` 的同内容重试返回既有 event（duplicate）；同一幂等键内容不同返回 conflict；不同 requestId 的语义重复由 reducer 拒绝，不能形成第二条事实。
5. `requestWorldTime` 与 `committedAt` 取 dispatch 前的当前世界时刻；一次同步玩家命令不推进时间。行动成本与跨日仍只由既有 reducer/engine 规则产生。
6. 所有玩家事实使用 `source=player-command`、`actor=player`；具体 intentKind 稳定且显式，不由 UI 文案生成。

## 4. 世界生命周期与旧 v1 档案

- 每个新运行时分配独立 WorldId，并从 genesis 建立空 Ledger 与初始 projection。
- `resetGame` 表示创建一个新 WorldId 与新空 Ledger，不删除历史世界的事实流。
- W5-C1 期间 Ledger 只驻留内存；正式持久化由 W5-D 接入。
- 不自动读取、不覆盖、不删除 `guanyuan.save.v1`。既有 v1 数据视为 legacy draft，不得伪装成事件历史。
- 当前会话投影可继续由用户显式导出为非恢复性底稿；导出物不得标记为 W4 SavePackage。
- UI 必须明确显示“当前会话、尚未持久化”，不得继续显示“本机一档”或暗示刷新后可恢复。
- Narrative settings、secrets、cache 与候选文本仍留在独立 NarrativeStore；不混入世界 Ledger。

## 5. AI 事件临时边界

- W5-C1 不允许 AI GeneratedEvent 继续通过旧 `executeCommand` 直接 setState。
- AI 选项在 C2 完成前返回明确的 `ai-candidate-flow-not-integrated` 拒绝，不写 Ledger、不改变 projection；正式世界事件优先规则保持。
- W5-C2 将为 AI 选项建立候选 payload schema、CandidateLog 状态迁移、`candidate.validated` receipt 与 `source=ai-candidate` 事实事件，并在 reducer 中重放其效果。
- C2 必须升级 Preview Registry 版本，不得修改已冻结的 v0.1 schema。

## 6. 验收矩阵

- 创建世界：空 Ledger head=0、genesis projection 与初始 GameState 一致。
- 所有表列非 AI intent 均通过唯一 Orchestrator 写入，hook 不再直接 setState 世界事实。
- Registry schema 不匹配、非法 payload、未知 kind、非法前置条件、重复动作、replay reducer 失败均拒绝且不改变 Ledger/projection。
- 相同 requestId 同内容重试返回 duplicate；相同幂等键不同内容返回 conflict。
- 行动成本、人物接触、证据解锁、宴席后果、世界事件、跨日与官员批答投影保持 W5-B/既有行为口径。
- 重置创建新 WorldId，不删除旧 v1 key；NarrativeStore keys 不受影响。
- Smoke 必须验证无 v1 自动恢复、清档后新世界、导出仅为 projection draft、AI 选项不绕过 Ledger。
- 双 CI、Review index、Patch whitespace、Production build、Playwright Smoke、双侧截图归档均通过后，C1 才验收。

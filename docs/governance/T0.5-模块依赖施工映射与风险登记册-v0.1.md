## 四、施工纪律

1. 每个工作包先做现状审计，再形成契约差异，再修改文档/代码；不得先写实现再补规则。
2. P0 契约未裁定前，不开展依赖它的新增玩法或数据结构扩张。
3. 已有 W5 存档账本与 genesis replay 基线不因本轮矩阵修订而重写；只在具体风险测试证明必要时做最小兼容修正。
4. PR #71–#74 互相独立，除非明确说明依赖，不把它们合并成一个“总验收”。
5. 美术由项目负责人生成；工程施工不得用临时 CSS/代码造型替代应有正式美术资产。
6. 任何候选审计意见在明确批准前都不能写成已生效规则。

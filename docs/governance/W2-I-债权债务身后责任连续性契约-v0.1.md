# W2-I 债权债务身后责任连续性契约 v0.1

状态：W2-I 施工契约；基线为 W2-H `work/w2-h-authorization-death-gate`。
依据：《世界生命与自由人生模拟系统设计规范》3.3、3.5、9.4、12.2；W2-F 死亡结算引用完整性契约。

## 1. 目标

为债务人的责任与债权人的债权在死亡后的延续提供可追溯、可校验的显式承接记录。死亡不会删除债务，也不会自动免除或转移责任。

## 2. 核心模型

新增 `DebtPartySuccession`，独立于原始 `Debt`：
- `role=creditor`：显式承接债权请求权；
- `role=debtor`：显式承接债务责任，必须有明确的责任承担事件；
- `deceased` 必须与 Debt 对应角色的原始当事人一致；
- `successor` 为明确指定的承接人；
- `shareNumerator/shareDenominator` 表示精确有理份额，支持多个承接人；同一债务、角色和死者的累计份额不得超过 1；
- `deathEvent` 必须与死者 DeathRecord 的 causeEvent 一致，事件时点必须与死亡时点一致；
- `successionEvent` 必须存在且不早于死亡时点；承接人在承接事件时必须存活。

## 3. 规则裁决

1. 债权人死亡与债务人死亡是两种不同的角色承接，不可混淆。
2. 没有明确承接记录时，原 Debt 的 creditor/debtor、principal、status 和 settlements 均保持不变；未决责任仍然存在。
3. 只登记明确发生的承接；不从亲属、配偶、子女、组织关系或资产继承自动推断债权/债务承接。
4. 允许多个承接人分担明确份额；份额采用整数分子/分母，精确累计，不使用浮点容差。
5. 未分配份额继续未决；不强行补齐为 100%。
6. 承接记录不等于债务清偿，不得把 Debt.status 自动改为 settled。
7. 原始 Debt 保留为历史债务关系，不被承接记录覆盖或改写。
8. 承接人必须在承接事件时存活；当前人物已死亡不影响其死亡前历史时点的合法承接判定。

## 4. 本切片不做

- 不定义遗产责任上限、限定继承、放弃继承、遗产不足清偿、债务优先顺位或担保物处置；
- 不计算已偿本金、利息、违约金或剩余余额；当前 Debt 尚无可验证的逐笔金额结算明细；
- 不自动选定继承人，不自动推导亲属顺位；
- 不将债务直接从 deceased 改写给 successor；
- 不产生清偿事件，不自动更新 Debt.status；
- 不实现债权人死亡后的遗产归集器、遗嘱、分家或法定继承制度；
- 不接 W3 Event Ledger、AI 候选写入、存档迁移、G1 runtime 或 UI。

## 5. 验收

- creditor/debtor 两种承接方向分别校验；
- 死者、死亡记录、死亡事件及事件时间一致；
- 承接事件存在、时间不早于死亡；
- 承接人存在且在承接时点存活；
- 多承接人份额精确累计不得超过 1，允许未分配余额；
- 原始 Debt 不被修改，无承接记录时债务仍保留；
- W1-A 至 W2-H 回归、W2-I 专项测试、Review index、Patch whitespace、Production build、Playwright Smoke 与截图归档全部通过。

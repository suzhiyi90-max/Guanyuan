# W5-E1 可验证便携存档导出契约 v0.1

## 1. 施工定位

- 基线：W5-D3-B 应用启动恢复与自动续存，验收 SHA `0b1f6124cab875453334df6b64ad96a3b540c7fa`。
- 本片把当前已持久化的人生导出为可迁移的便携存档包；导出对象必须是 SaveRepository 中已提交并验证的 package chain。
- 不再把 React 当前 projection state 包装成看似可恢复的 JSON 底稿。
- PR base 为 `work/w5-d3b-app-startup-lifecycle`，保持 Draft/Open，不合并。

## 2. 导出格式

导出文件采用独立 envelope：

- `format`: 固定标识 `guanyuan.portable-save`。
- `formatVersion`: 当前便携包格式版本 `1`。
- `exportedAt`: 导出时刻，仅为传输元数据，不参与世界事实。
- `worldId`: 人生唯一标识。
- `streamHead`: 已提交事件流头。
- `packageChain`: 完整 Full/Incremental SavePackageChain，保留 base 引用与全部校验字段。
- `envelopeChecksum`: 对规范化 envelope payload 计算的 SHA-256；不替代链内 package checksum。

不得只导出最后一个 Incremental package；不得省略 base chain；不得以 UI state、截图、叙事文本或 AI 输出重建事件。

## 3. 导出前置校验

- 只能从当前已恢复且身份一致的 WorldId 读取存档。
- 读取仓储中的完整 package chain，并使用当前 Registry/reducer 完整执行 `validateSavePackageChain`。
- 校验 worldId、streamHead、chain head、事件范围、checksum、AI validation receipts、replay 与 snapshot 一致性。
- 仓储无记录、存档尚未完成首次持久化、保存队列仍有待处理项时，不得导出“已保存”包；必须明确提示用户先等待保存完成。
- 任一校验失败均中止下载，不回退导出旧 projection JSON，不降级为部分链。

## 4. 安全与隐私

- 便携包只包含恢复世界所必需的事实账本、验证回执、schema/package 元数据与重放检查点。
- 不包含 React UI 状态、临时 AI 候选、pending/rejected CandidateLog、缓存、设备标识、访问令牌或连接凭据。
- 不向远端上传，不调用第三方存储；仅由用户主动下载到本机。
- 导出动作只读，不修改当前 session、EventLedger、SaveRepository 或存档 head。

## 5. 错误语义

- 区分 `not-saved-yet`、`save-pending`、`world-mismatch`、`chain-corrupt`、`schema-unsupported`、`checksum-failed`、`storage-error`。
- 不允许 catch 后返回空包或旧版 projection JSON。
- 下载文件名包含观远、人生日期/序号与 WorldId 的安全短标识；不得只依赖日期造成覆盖歧义。
- 导出成功提示必须表述为“便携存档包已导出”，不得称作“已备份”或暗示云端已有副本。

## 6. 本片不做

- 不实现导入、覆盖恢复、档案删除、跨设备同步或云备份。
- 不迁移旧 `guanyuan.save.v1`。
- 不改变 SavePackage / IndexedDB 内部 schema，不更改账本和 replay 规则。
- 不将便携包自动导入或自动恢复；导入将在后续独立切片设计并验证。

## 7. 验收门槛

- 有效 Full-only 与多段 Incremental chain 可完整导出，导出后 envelope 可独立解析。
- envelope checksum 可重算；任一字段篡改均拒绝验证。
- base 缺失、chain 损坏、schema 不支持、head 不一致、世界身份不一致、存档尚未写入、保存队列 pending 均不得生成下载。
- 导出前后 session、ledger head、repository streamHead 与 package chain 字节内容不变。
- UI 明确区分“本机自动存档”和“导出便携包”；导出不能冒充当前 projection JSON。
- W1—W5-D3-B 回归、Review index、Patch whitespace、Production build、Playwright Smoke、Push/PR 双 CI 同 SHA 全绿、双侧截图归档通过。

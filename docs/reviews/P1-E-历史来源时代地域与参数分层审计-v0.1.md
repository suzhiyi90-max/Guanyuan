## 一、时代与地域边界

### 已有裁决

总纲 20.2 将时代背景定为“架空晚清州县”，锚定近代冲击到来之前的封闭州县，虚构王朝名，不涉洋务、教案、外患；官制范围只做州县一层及府/道两级接口。世界生命规范 10 要求所有制度按朝代、年份、地域配置，并记录生效时间、地域范围、来源、史料置信等级、规则性质、例外、裁量主体和版本。

### 当前缺口

- M1 史实档案的表格常用“清代”“全国”“黄河”概称，没有为每项规则固定具体制度时间截面。
- 档案说明东河/南河细则不同、M1 只取黄河堤岸，但没有把首县所属河段、具体河道管理系统、适用河工则例和该县是否由河厅专管等关键适用条件收敛成一个冻结的“场景历史坐标”。
- “架空晚清”与直接引用康熙、雍正、乾隆、光绪各朝条文并非天然冲突，但必须说明哪些制度在晚清仍有效、哪些是沿革背景、哪些是跨时期保留规则、哪些只是玩法抽象。不能将某朝单条旧例自动当作晚清现行制度。
- M1 文件开头仍称“对齐设计总纲 v0.6”，而根目录权威总纲现为 v0.16；文件尾部还保留“下一步 v0.5、将修总纲 v0.5”等过时施工指令。它们已成为版本治理风险。

### 建议冻结的场景历史坐标（待项目负责人裁决）

| 维度 | 当前可确认内容 | 尚缺 |
|---|---|---|
| 时代 | 架空晚清，近代冲击前 | 具体制度截面/模拟年号与公历映射 |
| 政权 | 虚构王朝名，制度骨架参考清代 | 哪些清制作为现行规则、哪些仅为历史沿革 |
| 地域 | 黄河流域；档案提及东河/南河差异 | 首县所在省份、府、河段与河厅辖区 |
| 河工类型 | 黄河堤岸、抢护/拆修、岁修/另案 | 该河段适用的具体则例版本与工程类别 |
| 县级设置 | M1 设知县、县丞、主簿等角色 | 此县佐贰配置是否为架空县特例，人口/缺额依据 |

## 二、史料分级本身

M1 档案 0.2 的 A/B/C/D 分级方向正确：

- A：可核查制度条文；
- B：幕友书、日记、判牍、笔记、现代研究中的惯例；
- C：统计、研究推断、区域差异；
- D：玩法补全。

但“置信等级”不能替代可复核出处。每条 A/B/C 事实至少应具备：原始书名、编纂/刊刻版本、卷/门/条目、页码或稳定数字化定位、原文摘录/关键句、适用时间、适用地区、引用解释、核验人/日期。现代研究还需作者、文章/书名、出版信息、页码/注释。只有“《清史稿·职官志》”“清代河工研究”等泛称，无法完成可复核核验。

建议为证据质量另设独立状态，不要将 A/B/C/D 同时用作“史实置信等级”和“核验工作进度”：

1. 史料类别：制度原文 / 同时代实务记录 / 后世研究 / 统计材料 / 玩法设计；
2. 核验状态：未定位 / 已定位 / 已核原文 / 已核适用范围 / 有争议 / 已替代；
3. 适用范围：朝代/年段、地区/河段、身份/机构、工程类别；
4. 游戏采用状态：现行规则 / 有条件采用 / 背景参考 / 参数初值 / 不采用。

## 三、关键史实抽查

### 1. 河工 500 两界线

M1 档案把“雍正八年：汛期单工 ≤500 两为抢修，>500 两为另案”标为 A/B，但附录仍将“500 两抢修/另案界：雍正八年？原文出处与适用河段”列为待核。

本轮公开原文抽查发现：

- 《钦定大清会典则例》卷一百三十三“工部·都水清吏司·河工三”载康熙十八年题准“其费以五百两为率”，并有抢修先行修防、工完汇册题销等规则；这证明 500 两标准存在较早制度来源，但“以五百两为率”本身不能不加解释就等同于“≤500 抢修、>500 另案”的全部规则。
- 《永定河续志》所录“河道另案工程条款疏”叙述 500 两以下部核办、超过 500 两奏明办理，需进一步确认该条款的年份、适用河段及其与 M1 所选黄河河段的关系。
- 聊城大学关于黄运两河河工经费制度的研究文章称雍正八年规定汛期单项工程 500 两以内为抢修、超过 500 两为另案；这是有用的二手研究线索，但不能替代对应原始诏令/则例条文。

**裁定：** 500 两规则不能简单判错，但当前档案的朝代与适用河段证据链不闭合。需找到并定位雍正八年原文，说明其对黄河东河/南河或其他河段的适用性；若找不到，应把“雍正八年 500 两界”降为 B/C 待核，不作为跨地域硬规则。

参考线索：
- [《钦定大清会典则例》卷133（识典古籍）](https://www.shidianguji.com/zh/book/SK1149/chapter/1mjv9fbf49e7a)
- [《永定河续志》卷九相关条款](https://www.shidianguji.com/book/NLG312001071410/chapter/1ljbwitmvjswy)
- [聊城大学：黄运两河河工经费制度研究](https://www.lcu.edu.cn/ztzx/whxs/c10fef9e2f21460db735be5b9fbbbfd8.htm)

### 2. “销六赔四”赔修比例与年份

M1 档案附录把雍正五年/六年列为待核。本轮查到《永定河志》所录雍正五年十月工部议覆朱家口工程及《钦定大清会典则例》卷133相关条文，明确记载黄河一年内、运河三年内冲决，符合条件者承修官赔修四分、其余六分准予开销。

**裁定：** “雍正五年十月”已有直接原文线索，档案不应继续写“五年（1727）还是六年（1728）”悬而未决；但仍需区分“黄河一年/运河三年”的对象范围、工程完工及保题条件，不能简化为普遍赔修比例。

参考：
- [《永定河志》所录雍正五年十月议覆原文](https://www.shidianguji.com/mid-page/7520739482514358281)
- [《钦定大清会典则例》卷133](https://www.shidianguji.com/zh/book/SK1149/chapter/1mjv9fbf49e7a)

### 3. 县丞、主簿全国缺数

M1 表格写县丞约 345、管河县丞 37、主簿约 55；附录称统计口径不一。公开数字化的《大清搢绅全书》（光绪三十二年丙午冬季）列县丞 356 缺、主簿 90 缺。该来源是具体年度缺额名册，和“全国官缺/实设/某类管河缺额”的统计口径不必相同。

**裁定：** 现有数字不能直接互相判错，但“全国约数”必须注明统计对象、年份、名册/制度来源、缺额还是实有人数、是否含直隶州/厅/特殊地区。M1 若只需说明县丞、主簿并非每县必设，优先使用可复核的具体年度名册并避免写成无年份全国定值。

参考：[《大清搢绅全书》（光绪三十二年丙午冬季）](https://www.shidianguji.com/book/HY1822/chapter/1knzmma3lwnir)

### 4. 保固期限与工程类别

M1 文件写黄河堤岸一年、埽工一年，并将“运河堤岸一年（参处）/三年（赔修）”列为待拆分。卷133原文中确有黄河一年、运河三年的冲决赔修规则；同卷另有不同河段、工程类别保固年限差异。**保固/赔修/责任追究不是同一字段。** 当前档案的“埽工一年”还需核对适用工程类型和河段，不能由黄河堤岸规则外推。

### 5. 其他关键史实

以下项目仍应保留待核，不能因已有 A/B 标签就视为验收完成：

- 每垛秫秸五万斤及其规格、东河/南河差异；
- 佐贰、河厅、县丞/主簿的权限边界与实际任用条件；
- 详文、禀帖、验文、申文的行文关系与“有详必有批”具体条文；
- 雇募民夫、堡夫、河兵数量上限与适用制度；
- 养廉 400–2000 两的省份分布；
- 卓异定额与考成制度在选定晚清时间截面的有效性；
- 密考在具体年代的适用范围，不能与三年大计混为一谈。

## 四、D 类玩法参数治理

M1 档案将以下内容标 D：300 两玩法限额、4,500/4,200/300 账目配置、十日工期、50/30/10/10、18%、12 里、40 步、七人配置等。明确标 D 是正确方向，但仍缺参数登记表。

每个 D 参数至少应记录：

| 字段 | 说明 |
|---|---|
| parameterId | 稳定 ID |
| value / unit | 数值与单位，避免无单位数字 |
| scope | 场景、河段、人物/身份、工程类型 |
| effectivePeriod | 适用游戏日期/时段 |
| sourceClass | D（玩法设计），并列出史料参照但不冒充史实 |
| designReason | 为什么需要这个数值、服务何种玩法压力 |
| validationMethod | 纸面推演、可玩性测试、性能测试或历史核验 |
| status | 候选 / 当前切片采用 / 已验证 / 已替代 |
| version / owner | 变更版本与责任人 |

D 参数可以在 M1 固定切片中使用，但不得在设定集、AI 提示词或历史说明中被叙述成清代通行制度。参数变化必须记录版本和影响范围，不应悄悄改写既有事实。

## 五、历史证据与产品规则的三轴状态

本轮发现现有文档容易将“史实置信度”“规则是否采纳”“参数是否验证”混成一个状态。建议分别登记：

1. **产品规则状态：** 已确认 / 候选 / 待裁决 / 已替代；
2. **历史证据状态：** 原文已核 / 二手来源 / 统计口径待核 / 有争议 / 无来源；
3. **参数验证状态：** 未测 / 纸面验证 / M0/M1 测试 / 已校准 / 仅当前切片临时值。

工程实施和测试状态另记，不得把 CI 通过误当成史实核验通过。

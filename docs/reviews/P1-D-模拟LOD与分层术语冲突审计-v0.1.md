# P1-D 模拟 LOD 与分层术语冲突审计 v0.1

- 审计基线：总纲 `main@80398f5`（v0.16）；《世界生命与自由人生模拟系统设计规范》v0.1；《人物分类与社会关系网络系统设计规范》v0.1；当前治理矩阵 v0.2 提案。
- 性质：术语治理审计，不修改总纲、专项规范、代码或 schema；本报告不批准新规则。
- 结论：**存在一处明确的同名异义冲突、一处历史文本未同步，以及若干需要明确命名空间的相邻概念。必须在后续规范写回前统一术语，不能只全局替换 L0–L3 字符串。**

## 一、先区分四种不同的“层”

| 概念 | 现有表达 | 回答的问题 | 是否使用 L0–L3 |
|---|---|---|---|
| 玩法结构 | 宏观人生 / 中观策略 / 微观行动（三层） | 玩家在什么尺度上作选择、体验一生？ | 否 |
| 世界模拟精度（LOD） | L0 近场 / L1 关系圈 / L2 地域圈 / L3 远端世界 | 某人物/组织以何种计算频率和细节持续模拟？ | 是，四级 |
| AI 成本架构 | L0 确定性核心 / L1 模板生成 / L2 小模型 / L3 大模型 | 一项表达/解析/推理任务使用哪类技术与预算？ | **现文使用同一 L0–L3，造成命名空间冲突** |
| 场景人物呈现 | 固定在场者 / 定时来客 / 无名场面人（三层） | 玩家进入一个场景时，画面与互动如何呈现人物？ | 否 |

以上概念不是同一分类体系。玩法结构、模拟精度、AI 成本和场景呈现不得互相映射，也不能因数字相同就认为处于同一层。

## 二、权威文本逐项核对

### 1. 总纲 9.6：旧三层模拟定义（明确冲突）

当前仍写：

- L0 背景统计层：人口/经济/舆情按日聚合，不逐人模拟；
- L1 事件驱动层：重要人物按日程与目标推进，规则 + 随机表；
- L2 全模拟层：玩家所在场景，逐行动结算；
- 离场后将 L2 结果压缩为事件 + 状态摘要写回 L1。

该段是旧版三层模拟模型。它与 v0.16 的四级人物世界 LOD 不兼容：

- 旧 L0“背景统计”并非新 L0“近场”；
- 旧 L1“事件驱动”并非新 L1“关系圈”；
- 旧 L2“全模拟”并非新 L2“地域圈”；
- 旧模型没有 L3 远端世界。

不能把旧三层直接改名为新四层，也不能继续将 9.6 当作当前 LOD 定义。

### 2. 总纲 9.10 / 15.11：当前权威四级模拟定义

v0.16 已明确：

- L0 近场；
- L1 关系圈；
- L2 地域圈；
- L3 远端世界。

并规定 LOD 只影响计算频率与细节，不改变人物规则语义；人物升降级须继承状态和历史。15.11 再次引用同一四级定义。因此，9.10 / 15.11 是当前总纲内部应统一采用的 LOD 口径。

### 3. 总纲 15.1：AI 成本架构复用 L0–L3（命名空间冲突）

15.1 将 AI 技术/成本分为：

- L0 确定性核心；
- L1 模板生成；
- L2 小模型；
- L3 大模型。

该表本身是 AI 技术成本分层，与世界模拟精度完全不同；但复用 L0–L3 后，在工程沟通、配置、日志、测试、指标与 AI 提示词中会产生歧义。例如“某人物从 L2 升级到 L0”无法判断是模拟精度还是模型成本。

### 4. 总纲 15.2 / 15.3：沿用 AI 成本层缩写

15.2 使用“模板层（L1）”“模型层（L3）”；15.3 使用 L2 解析、L3 对话。它们显然指 AI 成本架构，不是人物模拟 LOD。该处应与 15.1 同步改用成本命名空间，而不是删除成本分层。

### 5. 专项规范对照

- 《世界生命与自由人生模拟系统设计规范》8.1 明确四级 L0–L3 与总纲 9.10 一致。
- 《人物分类与社会关系网络系统设计规范》7.3 使用“近景/当前场景、中景/同县域、远景/跨区域”三种叙述粒度，未使用 L0–L3 编号。它可以作为社交行为的表现/调度说明，但需明确是社交事件的聚合描述，不是另立三层世界模拟体系。
- 场景人物三层（固定/定时/无名）是表现分类，不是模拟 LOD。
- 宏观/中观/微观三层玩法是目标与行动尺度，不是人物计算精度，也不是 AI 成本等级。

## 三、建议采用的术语命名空间

以下为治理建议，须正式批准后再全局写回：

| 命名空间 | 建议名称 | 正式标签 | 说明 |
|---|---|---|---|
| SIM-LOD | 世界模拟精度 | SIM-LOD-0 / 1 / 2 / 3 | 分别对应近场、关系圈、地域圈、远端世界 |
| AI-COST | AI 技术成本档 | AI-COST-0 / 1 / 2 / 3 | 分别对应确定性、模板、小模型、大模型；正文可简称 C0–C3 |
| GAMEPLAY-SCALE | 玩法尺度 | 宏观 / 中观 / 微观 | 目标、事务、行动三尺度 |
| SCENE-PRESENCE | 场景人物呈现 | 固定在场者 / 定时来客 / 无名场面人 | 只用于场景可读性和人物出现规则 |

建议正式文本中：
- 世界模拟统一称“SIM-LOD-0 至 SIM-LOD-3”，中文简称“模拟 LOD 0–3”。
- AI 成本层改称“AI-COST-0 至 AI-COST-3”，中文简称“成本档 C0–C3”；避免继续单独写“L0/L1/L2/L3”。
- 玩法尺度始终使用宏观/中观/微观，不编号成 L0–L2。
- 场景人物呈现始终使用三类名称，不称模拟层级。

## 五、不可误改的边界

1. 不得把宏观/中观/微观玩法层改成 SIM-LOD。
2. 不得把场景人物三类呈现改成世界模拟层。
3. 不得将 AI 成本档与人物模拟 LOD 绑定，例如“远端人物必须用大模型”或“近场必用 L3”；二者是正交维度，调度策略需另行定义。
4. SIM-LOD 降低计算频率/细节，不得降低关键事实、因果、公平性、资源成本和人物决策规则。
5. 人物升降级必须继承已有状态、关系、记忆、历史与待处理事务；不得因升级重新生成一套人生。
6. M1 七人河工夹具与十日脚本不因此扩成全人口模拟；本轮只清理术语和依赖引用。
7. 本轮不启动 AI 世界运营者、事件锚点、批量内容生产架构。

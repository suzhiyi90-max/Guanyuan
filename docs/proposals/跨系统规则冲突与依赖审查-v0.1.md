## 4. 系统依赖图（概念）

主依赖方向建议固定为：

**世界时间与行动提交**
→ **确定性规则校验与结果计算**
→ **统一事件记录 / 权威状态更新**
→ **人物接触记录与认知立场更新**
→ **关系、人情债、传闻、日程与仕途的后续响应**
→ **玩家可见的情报台账、日志、考语与行状**
→ **AI 只负责把已允许展示的内容转成自然语言**

注意事项：

- 行动执行、消息送达、人物听闻和玩家看到文本是不同事件。
- 关系变化不能直接替代权限判断；人情债不能直接替代法定程序。
- 传闻传播不能替代证据核验；记忆摘要不能替代原始事件。
- 事件触发顺序由统一契约决定，不由上述依赖图的文字先后自行决定。
- AI 叙述不应成为权威事实输入；如玩家对话影响世界，必须先被解析成结构化意图，再通过规则层检查。

## 5. 本轮建议裁决顺序

### 第一优先：时间与成本
1. D-01：行动点与时段关系；
2. X-02：社交“托”与委托执行时长的边界；
3. X-03：疲劳影响行动能力、行动质量还是信息质量；
4. D-03：同边界事件顺序。

### 第二优先：认知与证据
5. D-04：knows/believes 的语义；
6. D-05：记忆、证据、传闻的边界；
7. X-13：玩家情报台账标签与人物认知状态的关系；
8. X-14：AI 事实包、来源引用与叙述生成门槛。

### 第三优先：长期社会系统
9. X-10：债务义务、情分变化、公开传播三者拆分；
10. X-11：考语、举荐、空缺、考成审计与正式任命的事件接口；
11. X-12：执行噪声与可解释性；
12. X-09：七人核心与上级影子角色的范围定义。

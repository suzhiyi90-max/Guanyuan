## 1. 本轮审查结论

新增基础契约后，时间、行动、事件、信息认知和通信之间的接口关系已经能用同一套术语描述，但仍有关键决策未获批准。本轮结论：

1. **总纲 v0.3 继续是唯一权威基线。** 新契约是提案，不得在其他设计单中被写成已批准规则。
2. **优先解决双重成本歧义。** “每日行动点 3”“每时段 1–3 行动点”和社交动作“消耗 1 时段”目前不能同时被视为定义完备的规则。
3. **时间、事件与认知要形成共同底座。** 通信、政务、日程、人物关系、人情债、行状和 AI 上下文应引用共同契约，不得各自定义时钟、事件历史或可信度语义。
4. **四种信息视角不扩成五种。** 记忆属于人物认知的压缩投影；传闻属于主张的传播链；证据属于支持/反驳主张的来源对象。
5. **当前只能完成设计审查。** 本阶段没有代码实现；不得声称代码接口、原型或游戏验收已完成。

## 3. 基础契约的统一引用规则

所有后续设计单均应遵循以下规则：

- **时间：** 引用唯一世界时钟，不得自行新增计时器。预计时间与实际时间分开。
- **行动成本：** 每个行动分别声明时间成本、资源成本、权限条件和风险；不得用一个成本字段代替其他维度。
- **事件：** 命令 ID、业务对象 ID、事件 ID 分离。当前对象状态不取代追加事件历史。
- **信息：** 主张不等于事实；接触不等于理解；理解不等于相信；相信不等于客观正确。
- **来源：** 原始材料、亲历、转述、推断和传闻必须能区分；转述保留来源链。
- **记忆：** 是有限的认知检索投影，不是第二套世界事实或完整聊天记录。
- **可见性：** 玩家只能看到有来源与权限依据的信息；内部权威状态不自动泄漏。
- **AI：** 负责解析与叙述；最终业务状态由规则结算，不由自然语言自行改变。
- **M1 范围：** 一县、七人、十日、一汛；先验证闭环，不扩展全国地图、全员逐时模拟或复杂传播网络。

## 5. 设计审查门

### Gate A：概念一致
- 同一术语在总纲与模块设计单中含义一致。
- 时间成本、资源成本、权限与风险不混写。
- 事实、主张、证据、认知、记忆和传闻边界明确。

### Gate B：因果闭合
- 行动前置条件、提交边界、结算顺序、失败与重试规则闭合。
- 同一时段边界多事件有稳定顺序。
- 重复命令不会重复产生业务后果。

### Gate C：信息边界
- 人物不会无依据知情。
- 玩家 UI 不泄露内部真值。
- 传闻不自动等于事实，也不自动全县广播。
- 旧消息不会被悄悄改写为新事实。

### Gate D：范围与治理
- 不超出 M1 范围。
- 所有未裁决事项保留状态标记。
- 未批准内容不写入权威总纲。
- 当前阶段只验收设计文档，不报告代码或游戏测试结果。
